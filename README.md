# JS Course — сайт для GitHub Pages

## Структура
```
index.html            — редирект на первый урок
css/style.css          — стили (сайдбар + контент)
pages/*.html           — все 59 уроков курса
pages/images/*         — картинки-иллюстрации к урокам
```

## Публикация на GitHub Pages
1. Загрузите содержимое этой папки в корень репозитория на GitHub
2. Settings → Pages → Deploy from a branch → main → / (root) → Save
3. Сайт будет доступен на https://ВАШ_ЛОГИН.github.io/НАЗВАНИЕ_РЕПО/

## Про картинки
Все картинки, использованные в уроках, на месте.
Двух картинок (`inheritance.png`, `oop-objects.png` в уроке "ООП") не было в присланном
архиве — вместо них сгенерированы собственные SVG-схемы (`inheritance.svg`, `oop-objects.svg`)
в едином стиле с остальным сайтом.
