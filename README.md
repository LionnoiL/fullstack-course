# Мій курс JavaScript

Цей сайт — мій особистий конспект з веброзробки: від верстки до фулстеку. Тут зібрані **HTML**, **CSS**, основи JavaScript, робота з DOM, асинхронність, події та API, **TypeScript**, **React**, **бекенд** (Node/Express, бази даних, авторизація) та супровідні теми (Git, тестування, безпека, деплой).

## Для чого цей курс

Я створив його для себе, щоб:

- систематизувати знання;
- швидко повертатися до потрібної теми;
- вивчати JavaScript поступово без зайвого шуму;
- мати простий і зрозумілий ресурс, який не відволікає від навчання.

## Зміст курсу

Наразі це **162 уроки** (теорія + практичні чекпойнти), згрупованих у **21 тематичний розділ**:

1. **HTML** — структура документа, текст, посилання й зображення, семантика, форми, таблиці, метадані/SEO, доступність.
2. **CSS** — синтаксис, селектори й специфічність, блокова модель, типографіка, позиціонування, Flexbox, Grid, адаптивність, анімації.
3. **Bootstrap** — підключення, сітка, утиліти, компоненти, форми, JS-компоненти, кастомізація (Sass).
4. **Основи** — синтаксис, змінні й типи, оператори, числа, рядки, регулярні вирази, розгалуження, цикли.
5. **Масиви** — масиви, посилання vs значення, методи масиву.
6. **Функції** — оголошення, чисті функції, область видимості, стрілкові функції, рекурсія.
7. **Об'єкти та колекції** — об'єкти, перебір, `?.` і `??`, spread/rest, деструктуризація, `Map`/`Set`, `Symbol`, ітератори та генератори.
8. **Просунуті теми** — колбеки, стек викликів, замикання, `this`, обробка помилок.
9. **ООП** — прототипи, конструктори, ES6-класи.
10. **DOM** — модель документа, навігація, створення вузлів, властивості й атрибути.
11. **Події та браузер** — події, делегування, форми, throttle/debounce, IntersectionObserver, BOM.
12. **Інструменти та збірка** — NPM, модулі, Webpack, бібліотеки, шаблонізація.
13. **Дані** — JSON, зберігання на клієнті.
14. **Асинхронність** — таймери, проміси, `async/await`, цикл подій.
15. **Мережа та сервер** — протоколи, REST API, Fetch, CORS, Node.js.
16. **Бекенд** — Express, middleware, побудова REST API, бази даних, ORM (Prisma), автентифікація, конфігурація.
17. **TypeScript** — типи, інтерфейси, звуження типів, дженерики, класи, utility- та просунуті типи, декоратори.
18. **React** — JSX, компоненти, props, стан, події, хуки, Context, роутинг, оптимізація.
19. **Next.js** — App Router, лейаути, Server/Client-компоненти, отримання даних, Route Handlers, навігація, оптимізація й деплой.
20. **Супровідні теми** — Git і командний рядок, тестування, веббезпека, деплой.
21. **Проєкти** — наскрізні проєкти (лендинг, калькулятор, To-Do, вікторина, галерея, погода, fullstack) і банк ідей.

Практичні чекпойнти («🎯 Практика: …») додано наприкінці кожного великого розділу.

## Практика

Кожен великий розділ завершується **чекпойнтом** — сторінкою «🎯 Практика», де
теорія закріплюється роботою:

- для JS-логіки — **інтерактивний редактор** прямо на сторінці: пишеш код,
  тиснеш «Запустити», авто-тести показують ✓/✗ (код зберігається в браузері);
- для верстки та фреймворків — завдання з вимогами, підказками й згорнутим
  еталонним рішенням (плюс посилання на CodePen / StackBlitz).

Інтерактивні чекпойнти містять десятки авто-перевірюваних завдань (лише в JS-логіці
їх близько 60). Окремий розділ **«Проєкти»** містить наскрізні проєкти рівня
портфоліо (лендинг, калькулятор, To-Do, вікторина, галерея, погода з API,
fullstack-нотатник) та **банк ідей** з десятками проєктів за рівнями складності.

## Інструменти учня

Прямо на сторінках уроків доступні (усі дані зберігаються локально в браузері, `localStorage`):

- **Виділення тексту** — виділи фрагмент і натисни «Виділити», щоб зберегти жовту позначку; клік по ній прибирає виділення.
- **Нотатки до уроку** — кнопка «Нотатки» відкриває панель із текстовим полем (автозбереження, окремо для кожного уроку).
- **Позначка «вивчено»** — кнопка на уроці; у меню з'являється ✓, лічильник по розділу та загальний прогрес-бар курсу.

## Структура проєкту

```
index.html            — редірект на перший урок
css/style.css         — мінімалістичні стилі сайту
js/nav.js             — єдине джерело бічного меню (розділи + прогрес)
js/course-tools.js    — виділення тексту, нотатки, позначка «вивчено»
js/practice.js        — рушій інтерактивних завдань (редактор + авто-тести)
pages/*.html          — уроки курсу
pages/images/*        — ілюстрації та графічні матеріали
```

Навігація централізована: список уроків живе лише в `js/nav.js`. Щоб додати урок,
достатньо створити сторінку в `pages/` і дописати рядок у відповідний розділ масиву
`sections` — жоден інший файл чіпати не потрібно.

## Як запустити локально

1. Відкрий папку проєкту в браузері або через локальний сервер.
2. Перейди до `index.html`, щоб потрапити на вступний урок.
3. Для зручності можна відкрити сайт через Live Server або простий локальний сервер.

Сайт повністю статичний і працює навіть з файлової системи (`file://`) — без збірки й залежностей.

## Про стиль

Сайт зроблений у мінімалістичному стилі: простий фон, нейтральні кольори, чітка типографіка та зосередження на навчальному контенті. Ніяких яскравих акцентів, лише чистий інтерфейс і логіка подання матеріалу.

## Про курс

Курс побудований як поступове вивчення веброзробки: від основ синтаксису JavaScript до практичної роботи з веб-інтерфейсами, асинхронністю, TypeScript і React. Тут не багато декоративності — лише потрібні знання, логіка та практика.

Мета курсу — не просто прочитати матеріал, а реально зрозуміти, як працює мова і як застосовувати її в реальних задачах.
