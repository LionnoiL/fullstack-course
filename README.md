# Курс JavaScript — сайт для GitHub Pages

Це навчальний сайт з базового та просунутого JavaScript для вивчення веб-розробки. Матеріал подано у вигляді окремих уроків, які можна відкривати як окремі сторінки.

## Структура проєкту

```
index.html            — редірект на перший урок
css/style.css         — стилі сайту (бокова панель + основний контент)
pages/*.html          — усі уроки курсу
pages/images/*       — ілюстрації та графічні матеріали до уроків
```

## Як опублікувати на GitHub Pages

1. Завантажте вміст цієї папки в корінь репозиторію на GitHub.
2. Перейдіть у Settings → Pages.
3. У розділі "Build and deployment" виберіть "Deploy from a branch".
4. Вкажіть гілку `main` і папку `/ (root)`.
5. Збережіть налаштування.

Після цього сайт буде доступний за адресою:
https://ВАШ*ЛОГІН.github.io/НАЗВА*РЕПОЗИТОРІЮ/

## Про курс

Курс охоплює основи JavaScript, роботу з DOM, функціями, масивами, об’єктами, асинхронністю, подіями, модулями, промісами, а також практичні аспекти веб-розробки.

Мета курсу — допомогти зрозуміти принципи програмування на JavaScript і навчитися застосовувати їх у реальних проектах.
