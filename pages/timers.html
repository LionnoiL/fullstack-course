1. Таймери

Таймери дозволяють виконати код через певний час або повторювати його з інтервалом. Це найпростіший приклад асинхронності: функція ставиться в чергу і виконується пізніше, не блокуючи решту коду.

2. setTimeout — виконати один раз згодом

setTimeout(callback, delay) запускає функцію один раз через delay мілісекунд і повертає ідентифікатор таймера.

console.log('до');

setTimeout(() => {
  console.log('через 2 секунди');
}, 2000);

console.log('після'); // виведеться РАНІШЕ, ніж рядок з таймера

Порядок у консолі: до → після → (через 2с) через 2 секунди. Це показує, що setTimeout не зупиняє виконання коду.

Додаткові аргументи після затримки передаються у функцію:

function greet(name) {
  console.log('Привіт, ' + name);
}
setTimeout(greet, 1000, 'Ada'); // через 1с: 'Привіт, Ada'

Затримка — це мінімальний, а не точний час. Якщо основний потік зайнятий, колбек виконається пізніше. Для delay = 0 код усе одно відкладається до завершення поточної роботи.

3. setInterval — повторювати з інтервалом

let seconds = 0;

const timerId = setInterval(() => {
  seconds += 1;
  console.log('Минуло секунд:', seconds);
}, 1000);

4. Скасування таймерів

Ідентифікатор, який повертають setTimeout/setInterval, потрібен, щоб зупинити таймер через clearTimeout/clearInterval.

const id = setInterval(tick, 1000);

// зупинити через 5 секунд
setTimeout(() => clearInterval(id), 5000);

Завжди очищайте інтервали, коли вони більше не потрібні (напр., при видаленні компонента). Забутий setInterval продовжує працювати у фоні й призводить до витоку памʼяті.

5. Рекурсивний setTimeout

Часто замість setInterval використовують «ланцюжок» setTimeout — це гарантує паузу між завершенням однієї ітерації й початком наступної, навіть якщо робота триває довго.

function poll() {
  console.log('перевіряю сервер...');
  setTimeout(poll, 3000); // запланувати наступний запуск після цього
}
poll();
