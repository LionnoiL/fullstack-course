1. Логічні властивості

Замість фізичних left/right/top/bottom сучасний CSS пропонує логічні напрямки, які підлаштовуються під напрям письма (напр. для мов справа-наліво). Це основа інтернаціоналізації. 

.box {
  margin-inline: auto;          /* ліво+право (в LTR) */
  padding-block: 1rem;          /* верх+низ */
  border-inline-start: 2px solid; /* «початок» рядка */
}
/* inline — вздовж рядка, block — впоперек */

2. aspect-ratio

Фіксоване співвідношення сторін — без старих хаків із padding-top: 56.25%: 

.video { aspect-ratio: 16 / 9; width: 100%; }
.avatar { aspect-ratio: 1; }   /* квадрат */

3. clamp() та адаптивна типографіка

clamp(min, ідеал, max) задає значення, що плавно масштабується між межами — ідеально для «плинних» шрифтів без медіазапитів. 

h1 {
  /* не менше 1.5rem, ~5% ширини вікна, не більше 3rem */
  font-size: clamp(1.5rem, 5vw, 3rem);
}
.container { width: min(100% - 2rem, 1200px); }

4. Темна тема

Реагувати на системну тему дозволяє prefers-color-scheme. Найзручніше — оголосити змінні для обох тем: 

:root {
  color-scheme: light dark;      /* дозволити обидві */
  --bg: #ffffff;
  --fg: #111111;
}
@media (prefers-color-scheme: dark) {
  :root { --bg: #111111; --fg: #eeeeee; }
}
body { background: var(--bg); color: var(--fg); }

Ще коротше — функція light-dark(), що обирає значення за поточною темою:

:root { color-scheme: light dark; }
body {
  background: light-dark(#fff, #111);
  color: light-dark(#111, #eee);
}

5. color-mix()

Змішування кольорів прямо в CSS — зручно для станів (hover, тіні) з одного базового кольору: 

.btn { background: #2563eb; }
.btn:hover {
  /* 80% базового + 20% чорного = темніше */
  background: color-mix(in srgb, #2563eb 80%, black);
}

clamp(), min(), max() прибирають десятки медіазапитів: багато що тепер масштабується плавно замість стрибків на брейкпоінтах. Це і менше коду, і приємніший вигляд на проміжних розмірах.
