1. Встановлення

Playwright має власний генератор проєкту, який ставить пакет, завантажує браузери й створює приклад тесту та конфіг:

npm init playwright@latest

Він спитає мову (обери TypeScript або JavaScript), теку тестів (tests/) і чи додати GitHub Actions. Браузери (Chromium, Firefox, WebKit) завантажаться автоматично.

2. Структура тесту

Тест — це виклик test() з назвою й асинхронною функцією. У неї Playwright передає фікстури, найголовніша — page (вкладка браузера).

// tests/home.spec.ts
import { test, expect } from '@playwright/test';

test('головна відкривається', async ({ page }) => {
  await page.goto('/');                         // перейти на сторінку
  await expect(page).toHaveTitle(/Мій застосунок/); // перевірка
});

Майже все у Playwright — асинхронне: дії й перевірки повертають проміси, тож майже перед кожним викликом стоїть await. Забув await — тест поводиться непередбачувано.

3. Запуск тестів

npx playwright test              # усі тести (headless, усі браузери)
npx playwright test home.spec.ts # конкретний файл
npx playwright test --headed     # з видимим вікном браузера
npx playwright test --ui         # інтерактивний UI-режим (найзручніший для дебагу)
npx playwright show-report       # HTML-звіт після прогону

UI-режим (--ui) — must-have на старті: видно кожен крок, стан сторінки в часі й помилки. За замовчуванням тести йдуть без вікна (headless) і паралельно — так швидше.

4. Конфіг

Налаштування живуть у playwright.config.ts. Найкорисніше — baseURL (щоб писати page.goto('/')) і webServer (Playwright сам підніме твій dev-сервер перед тестами).

import { defineConfig } from '@playwright/test';

export default defineConfig({
  testDir: './tests',
  use: {
    baseURL: 'http://localhost:5173',
    trace: 'on-first-retry',   // зберігати трейс при першому повторі
  },
  webServer: {
    command: 'npm run dev',     // підняти застосунок
    url: 'http://localhost:5173',
    reuseExistingServer: true,
  },
});

5. Браузери як «projects»

У конфігу браузери задають масивом projects — той самий тест ганяється в кожному. Можна тимчасово лишити один для швидкості:

npx playwright test --project=chromium

Готово — середовище налаштоване. Далі навчимося знаходити елементи й діяти з ними.
