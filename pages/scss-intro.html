1. Що таке Sass

Sass — це препроцесор CSS: мова, що розширює CSS змінними, вкладеністю, міксинами й функціями. Браузер не розуміє Sass напряму — спеціальний компілятор перетворює ваш код на звичайний .css, який уже підключається до сторінки.

$primary: #2563eb;

.button {
  background: $primary;
  &:hover { background: darken($primary, 10%); }
}

2. Два синтаксиси: SCSS і Sass

  • SCSS (.scss) — надмножина CSS: будь-який валідний CSS є валідним SCSS. Використовує дужки {} і крапки з комою. Це стандарт де-факто.
  • Sass (.sass) — старіший синтаксис на відступах, без дужок і ;.
// SCSS — далі в курсі використовуємо саме його
.card {
  padding: 1rem;
  .title { font-weight: bold; }
}

3. Навіщо він потрібен

Sass прибирає повторення й дає структуру великим стилям: змінні для кольорів, вкладеність замість довгих селекторів, міксини для повторюваних блоків, розбиття на файли. Частину цього вже вміє й сучасний CSS, але Sass дає більше й працює всюди.

Bootstrap написаний на Sass — саме тому його кастомізують через SCSS-змінні (див. урок «Кастомізація (Sass)» у розділі Bootstrap). Знання Sass відкриває глибоку кастомізацію багатьох фреймворків.

4. Встановлення і компіляція

Офіційна реалізація — Dart Sass. Найпростіше поставити через npm:

npm install -D sass
// разова компіляція
npx sass src/style.scss dist/style.css

// стежити за змінами й перекомпільовувати автоматично
npx sass --watch src/style.scss:dist/style.css

У проєктах на Vite підтримка ще простіша: достатньо встановити sass, і можна одразу імпортувати .scss-файли — збірник скомпілює їх сам.

У браузер підключають скомпільований .css, а не .scss. Файли .scss — це вихідний код для розробки; у продакшн іде результат компіляції.
