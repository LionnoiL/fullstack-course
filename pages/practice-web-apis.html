Практика: Web APIs та PWA

Зроби невеликий застосунок на Vite (Service Worker і PWA потребують HTTPS або localhost). Пройди від простого Canvas до офлайн-PWA з локальним сховищем.

Завдання 1. Малюнок на Canvas

Додай <canvas> і намалюй на ньому кілька фігур (прямокутник, коло) та підпис. Отримай 2D-контекст через getContext('2d') і використай fillRect, arc, fillText.

Рішення 
const ctx = document.querySelector('#c').getContext('2d');
ctx.fillStyle = '#2563eb';
ctx.fillRect(20, 20, 80, 50);
ctx.beginPath(); ctx.arc(160, 45, 30, 0, Math.PI * 2); ctx.fill();
ctx.fillStyle = '#000'; ctx.fillText('Canvas', 20, 100);

Завдання 2. Важке обчислення у Web Worker

Винеси повільну функцію (напр. суму чисел до 1e9 або пошук простих) у Web Worker. Надішли вхідні дані через postMessage, а результат покажи на сторінці. Переконайся, що під час обчислення кнопка/анімація на сторінці лишаються чуйними.

Підказка

Worker: onmessage = (e) => postMessage(heavy(e.data)). Сторінка: worker.onmessage = (e) => render(e.data). У Vite — new Worker(new URL('./worker.js', import.meta.url), { type: 'module' }).

Завдання 3. Нотатки в IndexedDB

Через бібліотеку idb створи базу з обʼєкт-сховищем notes. Реалізуй додавання нотатки, вивід усіх і видалення. Перезавантаж сторінку — дані мають зберегтися.

Рішення 
import { openDB } from 'idb';
const db = await openDB('notes', 1, {
  upgrade(db) { db.createObjectStore('notes', { keyPath: 'id', autoIncrement: true }); },
});
await db.add('notes', { text: 'Привіт' });
const all = await db.getAll('notes');
await db.delete('notes', 1);

Завдання 4. Форматування через Intl

Виведи ціну як гривневу валюту (Intl.NumberFormat), дату — у довгому українському форматі (Intl.DateTimeFormat) і правильну форму множини для «товар/товари/товарів» через Intl.PluralRules.

Рішення 
new Intl.NumberFormat('uk-UA', { style: 'currency', currency: 'UAH' }).format(499);
new Intl.DateTimeFormat('uk-UA', { dateStyle: 'long' }).format(new Date());
const forms = { one: 'товар', few: 'товари', many: 'товарів' };
const n = 5;
`${n} ${forms[new Intl.PluralRules('uk-UA').select(n)]}`; // "5 товарів"

Завдання 5. Власний елемент (Web Component)

Створи <user-card> через customElements.define з Shadow DOM: усередині — картка зі стилями, що не течуть назовні, і <slot> для вмісту. Використай тег кілька разів на сторінці.

Підказка

Імʼя тега — обовʼязково з дефісом. У connectedCallback: this.attachShadow({ mode: 'open' }).innerHTML = '<style>...</style><div class="card"><slot></slot></div>'.

Завдання 6. Перетворити застосунок на PWA (виклик)

Додай vite-plugin-pwa (або власний manifest.json + Service Worker): маніфест з іконками, кешування статики (cache-first), офлайн-старт. Перевір у DevTools → Application і аудитом Lighthouse, що застосунок встановлюваний і працює без мережі.

Зʼєднай усе у своєму fullstack-проєкті: нотатки в IndexedDB як офлайн-кеш, Service Worker для роботи без мережі, PWA-маніфест для встановлення. Так навчальний проєкт стає схожим на справжній продукт.
