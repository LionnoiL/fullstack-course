1. Вступ

В JavaScript функції не відрізняються від чисел, рядків або масивів - це просто спеціальний тип даних (об'єкт), який можна зберігати в змінної або передавати як аргумент в іншу функцію.

Функція вищого порядку - функція, що приймає в якості параметрів інші функції або повертає функцію як результат.

Функція зворотного виклику (callback) - це функція, яка передається іншій функції як аргумент і та, в свою чергу, викликає передану функцію.

const printMessage = function (message) {
  console.log(message);
};

const higherOrderFunction = function (callback) {
  const string = 'HOCs are awesome';
  callback(string);
};

higherOrderFunction(printMessage);

Функції зворотного виклику застосовуються для обробки дій користувача на сторінці, при виклику функцій до певного часу, при обробці запитів на сервер та ін.

2. Абстрагування повторення

Абстракція - приховування деталей реалізації. Дозволяє думати про завдання на більш високому (абстрактному) рівні.

Функції це хороший спосіб побудови абстракцій. Припустимо скрипт виконує якась агресивна дія певну кількість разів. Для цього можна написати цикл for.

for (let i = 0; i < 10; i += 1) {
  console.log(i);
}

Чи можемо ми абстрагувати «робити щось N раз» як функцію? - так, напишемо функцію, яка викликає console.log() N разів.

const repeatLog = function (n) {
  for (let i = 0; i < n; i += 1) {
    console.log(i);
  }
};

repeatLog(5);

Але що, якщо ми хочемо зробити щось крім логування чисел? Оскільки «робити щось »можна уявити як функцію, а функції - це просто значення, ми можемо передати дію як аргумент.

const printValue = function (value) {
  console.log(value);
};

const prettyPrint = function (value) {
  console.log('Logging value: ', value);
};

const repeat = function (n, action) {
  for (let i = 0; i < n; i += 1) {
    action(i);
  }
};

// Передаємо printValue як callback-функцію
repeat(3, printValue);
// 0
// 1
// 2

// Передаємо prettyPrint як callback-функцію
repeat(3, prettyPrint);
// Logging value: 0
// Logging value: 1
// Logging value: 2

Часто callback-функції анонімні і оголошуються як стрілкові функції прямо під час передачі.

const repeat = function (n, action) {
  for (let i = 0; i < n; i += 1) {
    action(i);
  }
};

const labels = [];

repeat(5, value => {
  labels.push(`Label ${value + 1}`);
});

console.log(labels); // ["Label 1", "Label 2", "Label 3", "Label 4", "Label 5"]

3. Фільтрація масиву

Напишемо функцію фільтрації елементів масиву. Перший параметр array це масив, будемо перебирати його використовуючи цикл for...of.

const filter = function (array) {
  for (const element of array) {
  }
};

Другий параметр test це callback-функція, яку буде необхідно виконати для кожного елемента масиву.

const filter = function (array, test) {
  for (const element of array) {
    test(element);
  }
};

Функція filter створює новий масив, в який буде додаватися результат виконання callback-функції test над кожним елементом масиву array. Результатом роботи функції буде масив відфільтрованих елементів.

const filter = function (array, test) {
  const filteredElements = [];

  for (const element of array) {
    test(element);
  }

  return filteredElements;
};

Якщо елемент масиву проходить тест, тобто callback-функція повертає true, він додаватися в відфільтрований масив.

const filter = function (array, test) {
  const filteredElements = [];

  for (const element of array) {
    const passed = test(element);

    if (passed) {
      filteredElements.push(element);
    }
  }

  return filteredElements;
};

Зверніть увагу, функція filter, замість видалення елементів з оригінального масиву, створює новий масив тільки тих елементів, які проходять тест. Це чиста функція, вона не змінює вихідні дані.

При такому підході ми можемо виконувати фільтрацію масиву за критерієм використовуючи всього одну функцію для перебору, а операції над кожним елементом будуть залежати від callback-функції.

const filter = function (array, test) {
  const filteredElements = [];

  for (const element of array) {
    const passed = test(element);

    if (passed) {
      filteredElements.push(element);
    }
  }

  return filteredElements;
};

const fruits = [
  { name: 'apples', quantity: 200, isFresh: true },
  { name: 'grapes', quantity: 150, isFresh: false },
  { name: 'bananas', quantity: 100, isFresh: true },
];

const freshFruits = filter(fruits, fruit => fruit.isFresh);
console.log(freshFruits); // масив з об'єктами apples і bananas
