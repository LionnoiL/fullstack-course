Чисті функції

Функція з побічними ефектами — функція, яка в процесі виконання може модифікувати або використовувати значення глобальних змінних, змінювати посилальні аргументи, виконувати операції введення-виведення і т. п.

Використовуємо звичний імперативний підхід і напишемо функцію, що множить кожний елемент масиву на значення параметра value. Ця функція буде мутувати (Змінювати) вихідний масив за посиланням.

const dirtyMultiply = (array, value) => {
  for (let i = 0; i < array.length; i += 1) {
    array[i] = array[i] * value;
  }
};

const numbers = [1, 2, 3, 4, 5];

dirtyMultiply(numbers, 2);

// Відбулася мутація вихідних Даних
console.log(numbers); // [2, 4, 6, 8, 10]

Чисті функції (pure functions) — функції, результат яких залежить тільки від значень переданих аргументів і стабільних змінних локальної області видимості, які при однакових аргументах завжди повертають один і той же результат, і не мають видимих побічних ефектів, тобто не змінюють стан програми.

Тепер напишемо реалізацію чистої функції множення елементів масиву, повертає новий масив, що не мутує вихідний.

const pureMultiply = (array, value) => {
  const result = [];

  for (let i = 0; i < array.length; i += 1) {
    result.push(array[i] * value);
  }

  return result;
};

const numbers = [1, 2, 3, 4, 5];
const doubledNumbers = pureMultiply(numbers, 2);

// Не сталося мутації вихідних даних
console.log(numbers); // [1, 2, 3, 4, 5]

// Функція повернула новий масив зі зміненими даними
console.log(doubledNumbers); // [2, 4, 6, 8, 10]
