1. Навіщо кастомізувати

Сайти «зі стандартним Bootstrap» легко впізнати. Щоб надати проєкту власного вигляду, фреймворк налаштовують: змінюють кольори, шрифти, заокруглення тощо. Найпотужніший спосіб — через Sass.

2. Швидкий шлях: CSS-змінні

Bootstrap 5 використовує CSS-змінні, які можна перевизначити у власному файлі після підключення фреймворку.

:root {
  --bs-primary: #7c3aed;
  --bs-border-radius: 0.75rem;
  --bs-body-font-family: "Inter", sans-serif;
}

3. Правильний шлях: Sass

Встановіть Bootstrap і компілятор Sass, тоді перевизначте змінні перед імпортом фреймворку — так зміняться всі похідні стилі.

npm install bootstrap sass
// custom.scss

// 1. власні значення змінних (до імпорту!)
$primary: #7c3aed;
$border-radius: 0.75rem;
$font-family-base: "Inter", sans-serif;

// 2. імпорт Bootstrap
@import "bootstrap/scss/bootstrap";
npx sass custom.scss custom.css

4. Імпорт лише потрібного

Щоб зменшити розмір, підключайте тільки використані частини замість усього фреймворку.

@import "bootstrap/scss/functions";
@import "bootstrap/scss/variables";
@import "bootstrap/scss/mixins";
@import "bootstrap/scss/grid";
@import "bootstrap/scss/buttons";
// ...лише те, що потрібно

Змінні Sass треба перевизначати до @import Bootstrap — інакше фреймворк уже скомпілюється зі своїми значеннями за замовчуванням.
