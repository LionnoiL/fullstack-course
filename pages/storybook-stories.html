1. Що таке історія

Історія (story) — це один стан компонента. Файли історій називають Component.stories.jsx і кладуть поруч із компонентом. Формат — CSF (Component Story Format): дефолтний експорт описує компонент, іменовані — окремі стани.

// Button.stories.jsx
import { Button } from './Button';

export default {
  title: 'UI/Button',
  component: Button,
};

export const Primary = { args: { variant: 'primary', children: 'Кнопка' } };
export const Ghost   = { args: { variant: 'ghost',   children: 'Привид' } };
export const Disabled = { args: { disabled: true, children: 'Вимкнена' } };

2. args — пропси історії

args — це набір пропсів, з якими рендериться компонент. Storybook автоматично робить із них інтерактивні Controls, тож пропси можна крутити прямо в UI без правок коду.

3. Керування контролами

export default {
  title: 'UI/Button',
  component: Button,
  argTypes: {
    variant: { control: 'select', options: ['primary', 'ghost', 'danger'] },
    disabled: { control: 'boolean' },
  },
};

4. Події через actions

Щоб бачити виклики обробників у панелі Actions, передають функцію-шпигуна:

import { fn } from 'storybook/test';

export default {
  component: Button,
  args: { onClick: fn() }, // кліки з'являться у вкладці Actions
};

5. Корисні аддони

  • Controls — крутити пропси наживо (вбудований);
  • Actions — лог викликів колбеків;
  • a11y — автоперевірка доступності компонента;
  • Viewport — перегляд на різних розмірах екрана.

Пиши історію на кожен важливий стан: порожній, з даними, завантаження, помилка, крайні значення. Тоді Storybook стає і візуальним тестом, і живою документацією, яка не старіє разом із кодом.
