Практика: функції

Замикання, рекурсія, функції вищого порядку. Пиши код і тисни «Запустити».

Завдання 1. Фабрика множників (замикання)

Реалізуй makeMultiplier(factor), що повертає функцію, яка множить свій аргумент на factor.

Підказка

Поверни стрілкову функцію, що використовує factor із зовнішньої області.

Рішення 
function makeMultiplier(factor) {
  return (n) => n * factor;
}

Завдання 2. Факторіал (рекурсія)

Реалізуй factorial(n) через рекурсію.

Рішення 
function factorial(n) {
  if (n <= 1) return 1;
  return n * factorial(n - 1);
}

Завдання 3. once — виклик лише раз

Реалізуй once(fn): повертає функцію, яка викликає fn лише при першому виклику, а далі повертає перший результат.

Рішення 
function once(fn) {
  let called = false;
  let result;
  return (...args) => {
    if (!called) {
      called = true;
      result = fn(...args);
    }
    return result;
  };
}
