1. Встановлення й перший стор

npm install zustand

Стор створюють функцією create. Вона повертає хук, через який компоненти читають стан і викликають дії. Стан і дії живуть разом. 

// store.js
import { create } from 'zustand';

export const useCounter = create((set) => ({
  count: 0,
  increment: () => set((state) => ({ count: state.count + 1 })),
  reset: () => set({ count: 0 }),
}));

2. Використання в компоненті

Жодних провайдерів — просто виклич хук. Компонент перемальовується, коли змінюється те, що він читає. 

function Counter() {
  const count = useCounter((s) => s.count);
  const increment = useCounter((s) => s.increment);

  return <button onClick={increment}>{count}</button>;
}

3. Селектори й ре-рендери

Передавай у хук селектор — функцію, що дістає лише потрібний шматок стану. Тоді компонент перемальовується тільки при зміні саме цього шматка. 

// ✅ підписка лише на count
const count = useCounter((s) => s.count);

// ❌ так компонент реагуватиме на будь-яку зміну стору
const { count } = useCounter();

Головне правило продуктивності в Zustand: вибирай мінімум. Один селектор — одне значення. Якщо тягнеш кілька полів одним об'єктом, зайві ре-рендери неминучі (або потрібен спеціальний компаратор).

4. Вибір кількох полів

import { useShallow } from 'zustand/react/shallow';

const { count, reset } = useCounter(
  useShallow((s) => ({ count: s.count, reset: s.reset }))
);

5. Доступ поза компонентом

Хук має методи getState і setState — зручно читати/міняти стан із будь-якого коду (утиліти, обробники подій). 

useCounter.getState().increment();
console.log(useCounter.getState().count);
