1. Що таке Bootstrap

Bootstrap — найпопулярніший CSS-фреймворк для швидкої верстки адаптивних інтерфейсів. Замість того щоб писати CSS з нуля, ви застосовуєте готові класи до HTML — і одразу отримуєте сітку, кнопки, форми, картки та інші компоненти в узгодженому стилі.

Bootstrap економить час на типових задачах і дає адаптивність «з коробки». Але базовий CSS знати обов'язково — фреймворк не замінює розуміння, а лише пришвидшує роботу. Приклади нижче для актуальної версії 5.

2. Підключення через CDN

Найпростіший старт — додати CSS у <head>, а JS-бандл перед </body>.

<!-- у head -->
<link
  href="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css"
  rel="stylesheet">

<!-- перед закриттям body (потрібен для інтерактивних компонентів) -->
<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

3. Встановлення через npm

npm install bootstrap
// у точці входу
import 'bootstrap/dist/css/bootstrap.min.css';
import 'bootstrap/dist/js/bootstrap.bundle.min.js';

4. Перший приклад

Після підключення достатньо додати класи:

<div class="container">
  <h1 class="text-primary">Привіт, Bootstrap!</h1>
  <button class="btn btn-success">Кнопка</button>
  <div class="alert alert-warning mt-3">Попередження</div>
</div>

Не зловживайте фреймворком там, де вистачить кількох рядків власного CSS. Bootstrap збільшує розмір сторінки, а сайти на ньому часто виглядають однаково — за потреби кастомізуйте (див. урок про Sass).
