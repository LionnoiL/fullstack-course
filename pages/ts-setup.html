1. Встановлення

TypeScript ставиться через npm. Зазвичай — локально в проєкт як dev-залежність:

npm init -y
npm install --save-dev typescript

// перевірити версію
npx tsc --version

2. Компіляція

Компілятор tsc перетворює .ts-файли на .js. Створимо app.ts:

const message: string = 'Привіт, TypeScript';
console.log(message);
npx tsc app.ts        // створить app.js поруч
npx tsc app.ts --watch // перекомпільовувати при кожній зміні

3. Файл tsconfig.json

Замість того, щоб щоразу передавати опції в командний рядок, налаштування зберігають у tsconfig.json. Створити його можна командою npx tsc --init.

{
  "compilerOptions": {
    "target": "ES2020",        // версія JS на виході
    "module": "ESNext",        // система модулів
    "outDir": "./dist",        // куди складати .js
    "rootDir": "./src",        // де лежать .ts
    "strict": true,            // усі суворі перевірки
    "esModuleInterop": true,
    "sourceMap": true          // .map для дебагу
  },
  "include": ["src/**/*"]
}

Тепер достатньо викликати npx tsc без аргументів — компілятор сам знайде tsconfig.json і застосує всі опції.

4. Режим strict

Опція "strict": true вмикає набір суворих перевірок (зокрема strictNullChecks і noImplicitAny). Це найважливіше налаштування — саме воно дає TypeScript реальну користь.

Завжди починайте новий проєкт зі strict: true. Вимкнути суворість пізніше легко, а от додати її у великий нетипізований проєкт — болісно.
