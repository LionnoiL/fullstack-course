1. Базові селектори

*        { }  /* усі елементи */
p        { }  /* за тегом */
.card    { }  /* за класом */
#header  { }  /* за id */
[type="text"] { } /* за атрибутом */

2. Комбінатори

.menu li     { }  /* нащадки (на будь-якій глибині) */
.menu > li   { }  /* прямі діти */
h2 + p       { }  /* сусід одразу після */
h2 ~ p       { }  /* усі наступні сусіди */

3. Псевдокласи та псевдоелементи

a:hover      { }  /* при наведенні */
input:focus  { }  /* у фокусі */
li:first-child { }
li:nth-child(2n) { } /* парні */

p::first-line { }
.box::before  { content: ""; }
.box::after   { content: "→"; }

4. Специфічність

Коли кілька правил задають ту саму властивість, перемагає правило з більшою специфічністю. Її рахують як трійку (id, класи, теги):

  • інлайн-стиль — найсильніший;
  • #id — 1,0,0;
  • .class, [attr], :hover — 0,1,0;
  • tag, ::before — 0,0,1.
/* специфічність 0,1,1 — переможе */
nav.menu { color: red; }

/* специфічність 0,0,1 — програє */
nav { color: blue; }

Уникайте #id та !important для стилізації — їх майже неможливо перекрити, і CSS перетворюється на «війну специфічності». Тримайтеся класів з низькою специфічністю.

5. Каскад і порядок

За однакової специфічності перемагає правило, оголошене пізніше у коді. Тому підключення власних стилів іде після бібліотечних.
