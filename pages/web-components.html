1. Що таке Web Components

Web Components — вбудований у браузер спосіб створювати власні HTML-теги з поведінкою та ізольованими стилями, без фреймворку. Твій <user-card> працює в будь-якому проєкті — на React, Vue чи чистому HTML.

Стандарт складається з трьох частин:

  • Custom Elements — реєстрація власного тега як класу;
  • Shadow DOM — ізольоване піддерево з власними стилями;
  • <template> — шаблон розмітки, що не рендериться, доки не використаний.

2. Custom Element

Успадковуєш HTMLElement і реєструєш тег. Імʼя обовʼязково з дефісом (щоб не конфліктувати зі стандартними тегами).

class GreetBadge extends HTMLElement {
  connectedCallback() {              // викликається, коли елемент додано в DOM
    const name = this.getAttribute('name') ?? 'Гість';
    this.innerHTML = `<span>Привіт, ${name}!</span>`;
  }
}
customElements.define('greet-badge', GreetBadge);
<greet-badge name="Аня"></greet-badge>  <!-- Привіт, Аня! -->

Життєвий цикл: connectedCallback (додано в DOM), disconnectedCallback (прибрано), attributeChangedCallback (змінився атрибут зі списку observedAttributes).

3. Shadow DOM — ізоляція стилів

Shadow DOM створює окреме піддерево, стилі якого не течуть назовні й не зазнають впливу глобального CSS. Це те, чого CSS Modules/CSS-in-JS досягають на збірці, а тут — на рівні браузера.

class UserCard extends HTMLElement {
  connectedCallback() {
    const shadow = this.attachShadow({ mode: 'open' });
    shadow.innerHTML = `
      <style>
        .card { padding: 1rem; border: 1px solid #e5e7eb; border-radius: 8px; }
        /* .card тут НЕ вплине на .card у решті сторінки */
      </style>
      <div class="card"><slot></slot></div>
    `;
  }
}
customElements.define('user-card', UserCard);

<slot> — місце, куди підставляється вміст, який користувач поклав усередину тега. Так компонент лишається гнучким: <user-card>Будь-який вміст</user-card>.

4. Навіщо, якщо є React

  • дизайн-системи — один набір компонентів для команд на різних фреймворках (так робить, напр., бібліотека Shoelace / Lit);
  • віджети для вбудовування на чужі сайти — не тягнеш React, стилі ізольовані;
  • довговічність — це веб-стандарт, не залежить від моди на фреймворки.

Для складних застосунків «сирі» Web Components багатослівні — тоді беруть тонку бібліотеку Lit (реактивність + шаблони поверх стандарту). React лишається кращим для великих SPA; Web Components — для крос-фреймворкових компонентів і віджетів.
