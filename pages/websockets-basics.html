1. Що таке WebSocket

WebSocket — протокол, що дає одне постійне двобічне з'єднання між браузером і сервером. Після встановлення обидві сторони можуть надсилати повідомлення будь-коли, з мінімальним оверхедом на кожен кадр. Ідеально для чатів, ігор, спільних курсорів, тикерів.

2. Рукостискання й схема адрес

З'єднання починається як звичайний HTTP-запит із заголовком Upgrade: websocket. Сервер відповідає 101 Switching Protocols — і далі це вже не HTTP, а WebSocket-кадри тим самим TCP-з'єднанням.

  • ws:// — незашифроване (аналог http);
  • wss:// — через TLS (аналог https) — завжди у продакшені.

3. Браузерний WebSocket API

У браузері є вбудований клас WebSocket — теж без бібліотек:

const ws = new WebSocket('wss://example.com/chat');

ws.onopen = () => ws.send(JSON.stringify({ type: 'join', room: 'general' }));

ws.onmessage = (event) => {
  const msg = JSON.parse(event.data);
  render(msg);
};

ws.onclose = (e) => console.log('закрито', e.code);
ws.onerror = (e) => console.error('помилка', e);

// надіслати
ws.send(JSON.stringify({ type: 'message', text: 'Привіт!' }));

WebSocket передає рядки або бінарні дані — структури серіалізуй у JSON (JSON.stringify/JSON.parse). Зазвичай вводять поле type, щоб розрізняти види повідомлень.

4. Сервер (бібліотека ws)

У Node найпростіший WebSocket-сервер — на пакеті ws:

import { WebSocketServer } from 'ws';

const wss = new WebSocketServer({ port: 8080 });

wss.on('connection', (socket) => {
  socket.on('message', (raw) => {
    const msg = JSON.parse(raw.toString());
    // розіслати всім підключеним (broadcast)
    for (const client of wss.clients) {
      if (client.readyState === client.OPEN) client.send(JSON.stringify(msg));
    }
  });

  socket.on('close', () => console.log('клієнт відключився'));
});

5. Стан і закриття

ws.readyState: CONNECTING → OPEN → CLOSING → CLOSED. Надсилати можна лише в стані OPEN. Закриття супроводжується кодом (1000 — нормальне, 1006 — обрив без рукостискання).

«Голий» WebSocket не має вбудованого перепідключення, кімнат чи fallback — це доводиться писати самому. Тому на практиці часто беруть надбудову Socket.io, яку розглянемо далі.
