Практика: TypeScript

TypeScript компілюється, тож рішення зручно перевіряти в TypeScript Playground — він одразу показує помилки типів. Спробуй розв'язати, а потім звір із рішенням.

Завдання 1. Типізуй функцію

Додай типи до функції, яка приймає масив чисел і повертає їх суму. Некоректний виклик має підсвічуватись помилкою.

Рішення 
function sum(numbers: number[]): number {
  return numbers.reduce((acc, n) => acc + n, 0);
}

sum([1, 2, 3]); // 6
sum(['a', 'b']); // ❌ помилка типу

Завдання 2. Інтерфейс і дженерик

Опиши інтерфейс User (id, name, необов'язковий email) і узагальнену функцію wrap<T>(value: T), що повертає { data: T }.

Рішення 
interface User {
  id: number;
  name: string;
  email?: string;
}

function wrap<T>(value: T): { data: T } {
  return { data: value };
}

const r = wrap<User>({ id: 1, name: 'Ada' }); // r.data: User

Завдання 3. Звуження типів

Напиши функцію format(value: string | number): для числа повертай його з двома знаками після коми, для рядка — у верхньому регістрі.

Рішення 
function format(value: string | number): string {
  if (typeof value === 'number') {
    return value.toFixed(2);
  }
  return value.toUpperCase();
}

Більший виклик: візьми будь-який свій JS-проєкт із розділу практики й типізуй його — це найкращий спосіб відчути користь TypeScript.
