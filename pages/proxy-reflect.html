1. Що таке Proxy

Proxy обгортає обʼєкт і дозволяє перехоплювати операції з ним: читання поля, запис, перевірку наявності, видалення. Ти задаєш «пастки» (traps), і вони спрацьовують замість стандартної поведінки.

const target = { name: 'Аня', age: 30 };

const proxy = new Proxy(target, {
  get(obj, prop) {
    console.log('читають', prop);
    return prop in obj ? obj[prop] : `<немає поля ${prop}>`;
  },
  set(obj, prop, value) {
    if (prop === 'age' && typeof value !== 'number') {
      throw new TypeError('age має бути числом');
    }
    obj[prop] = value;
    return true; // set МУСИТЬ повернути true при успіху
  },
});

proxy.name;        // лог: "читають name" → 'Аня'
proxy.city;        // '<немає поля city>'
proxy.age = 'ой';  // TypeError

2. Поширені пастки

  • get(obj, prop, receiver) — читання obj.prop;
  • set(obj, prop, value, receiver) — запис (повертай true);
  • has(obj, prop) — оператор in;
  • deleteProperty(obj, prop) — delete obj.prop;
  • apply/construct — виклик функції / new.

3. Reflect — «правильний» доступ до операцій

Reflect — обʼєкт із методами, що дублюють базові операції над обʼєктами (Reflect.get, Reflect.set, Reflect.has…). Їх зручно викликати усередині пасток, щоб виконати «стандартну» дію коректно (з правильним this/receiver).

const proxy = new Proxy(target, {
  get(obj, prop, receiver) {
    console.log('get', prop);
    return Reflect.get(obj, prop, receiver); // делегувати стандартне читання
  },
  set(obj, prop, value, receiver) {
    return Reflect.set(obj, prop, value, receiver); // повертає true/false сам
  },
});

Пара Proxy + Reflect — стандартний патерн: пастка додає свою логіку (лог, валідацію), а Reflect виконує саму операцію без ручного obj[prop] = ..., правильно обробляючи гетери/сетери й receiver.

4. Навіщо це на практиці

  • реактивність — саме на Proxy побудована реактивність Vue 3 та бібліотек на кшталт Valtio: перехопив запис у стан → оновив UI;
  • валідація — не дати записати некоректне значення;
  • значення за замовчуванням, логування доступу, «тільки для читання» обʼєкти, віртуальні поля.
// приклад: обʼєкт «тільки для читання»
function readonly(obj) {
  return new Proxy(obj, {
    set() { throw new Error('Обʼєкт незмінний'); },
    deleteProperty() { throw new Error('Обʼєкт незмінний'); },
  });
}

5. Ціна й обережність

Proxy додає накладні витрати на кожну операцію — не обгортай ним «гарячі» структури в циклах без потреби. Це потужний, але спеціалізований інструмент: для щоденного коду рідко потрібен, зате критично важливий у бібліотеках і фреймворках.
