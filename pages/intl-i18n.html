1. Чому «просто підставити текст» замало

Формати дат, чисел і валют різні в різних країнах: 1 000,50 в Україні — 1,000.50 у США; дата, назви місяців, множина («1 товар», «2 товари», «5 товарів») теж відрізняються. Робити це вручну — помилки й безлад. Вбудований обʼєкт Intl усе це вміє.

2. Числа й валюта

new Intl.NumberFormat('uk-UA').format(1234567.89);
// "1 234 567,89"

new Intl.NumberFormat('uk-UA', { style: 'currency', currency: 'UAH' })
  .format(499);
// "499,00 ₴"

new Intl.NumberFormat('en-US', { style: 'percent' }).format(0.25);
// "25%"

3. Дати й час

const d = new Date('2026-03-15T10:30:00');

new Intl.DateTimeFormat('uk-UA', { dateStyle: 'long' }).format(d);
// "15 березня 2026 р."

new Intl.DateTimeFormat('uk-UA', { dateStyle: 'short', timeStyle: 'short' }).format(d);
// "15.03.26, 10:30"

Перший аргумент — локаль ('uk-UA', 'en-US'). Передавай мову користувача (з navigator.language або налаштувань), і той самий код видасть правильний формат для кожного.

4. Множина й відносний час

// правильна форма множини — критично для укр. мови
const pr = new Intl.PluralRules('uk-UA');
pr.select(1);  // "one"   → "товар"
pr.select(3);  // "few"   → "товари"
pr.select(5);  // "many"  → "товарів"

// відносний час: "2 дні тому", "через годину"
const rtf = new Intl.RelativeTimeFormat('uk-UA', { numeric: 'auto' });
rtf.format(-2, 'day');  // "позавчора"
rtf.format(1, 'hour');  // "за 1 годину"

// сортування з урахуванням мови
['я', 'а', 'б'].sort(new Intl.Collator('uk-UA').compare); // ['а','б','я']

5. i18n у застосунках

Intl форматує значення, а переклад текстів інтерфейсу — окрема задача (i18n). Для неї беруть бібліотеки: словники ключ→переклад + вибір мови.

  • i18next / react-i18next — популярний стандарт для React;
  • FormatJS (react-intl) — з інтеграцією Intl;
  • у Next.js — вбудований роутинг локалей (/en, /uk).
// react-i18next — приклад
import { useTranslation } from 'react-i18next';

function Greeting() {
  const { t } = useTranslation();
  return <h1>{t('welcome', { name: 'Аня' })}</h1>; // "Вітаємо, Аня"
}
// словник uk: { "welcome": "Вітаємо, {{name}}" }

Плануй i18n заздалегідь: не «зашивай» тексти в JSX, а виноси в ключі. Додати мову потім — це новий словник, а не переписування компонентів. Числа й дати завжди форматуй через Intl, а не рядками.
