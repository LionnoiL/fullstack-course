1. Що таке middleware

Middleware (проміжне ПЗ) — це функції, які виконуються між отриманням запиту і відправленням відповіді. Кожна має доступ до req, res і функції next, що передає керування далі по ланцюжку.

app.use((req, res, next) => {
  console.log(`${req.method} ${req.url}`);
  next(); // передати керування наступному middleware
});

2. Вбудоване middleware

Найчастіше потрібне для читання тіла запиту та роздачі статичних файлів.

app.use(express.json());                 // парсинг JSON у req.body
app.use(express.urlencoded({ extended: true })); // дані форм
app.use(express.static('public'));       // роздача файлів із папки public

Без express.json() поле req.body буде undefined для JSON-запитів. Це найпоширеніша помилка новачків у Express.

3. Власне middleware

function requireAuth(req, res, next) {
  if (!req.headers.authorization) {
    return res.status(401).json({ error: 'Потрібна авторизація' });
  }
  next();
}

// застосувати лише до конкретного маршруту
app.get('/profile', requireAuth, (req, res) => {
  res.json({ user: 'Ada' });
});

4. Порядок має значення

Middleware виконуються в порядку оголошення. Тому спільні (логування, парсинг) підключають на початку, а обробник помилок — в самому кінці.

5. Middleware обробки помилок

Функція з чотирма аргументами вважається обробником помилок. Express викликає її, коли десь передали помилку в next(err).

app.use((err, req, res, next) => {
  console.error(err.stack);
  res.status(500).json({ error: 'Внутрішня помилка сервера' });
});

6. Популярні сторонні пакети

  • cors — дозвіл крос-доменних запитів;
  • morgan — логування запитів;
