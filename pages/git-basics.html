1. Командний рядок

Розробник щодня працює в терміналі. Базові команди:

pwd            # де я зараз
ls             # список файлів (dir у Windows)
cd projects    # перейти в папку
cd ..          # на рівень вгору
mkdir app      # створити папку
touch file.js  # створити файл
rm file.js     # видалити файл

2. Що таке Git

Git — система контролю версій. Вона зберігає історію змін проєкту, дозволяє повертатися назад і працювати командою без конфліктів. GitHub — хмарний хостинг Git-репозиторіїв.

3. Базовий цикл роботи

git init                 # ініціалізувати репозиторій
git status               # що змінилось

git add .                # додати всі зміни в індекс
git commit -m "Опис"     # зафіксувати зміни

git log --oneline        # історія комітів

Пиши змістовні повідомлення комітів у наказовому способі: «Add login form», а не «зміни». Через місяць саме за ними ти орієнтуватимешся в історії.

4. Робота з GitHub

git remote add origin git@github.com:user/repo.git
git push -u origin main   # надіслати на GitHub
git pull                  # забрати зміни з сервера
git clone <url>           # скопіювати чужий репозиторій

5. Гілки

Гілки дозволяють розробляти функції ізольовано, не чіпаючи основну гілку.

git branch feature-login    # створити гілку
git checkout feature-login  # перейти на неї
git checkout -b feature-x   # створити і одразу перейти

git merge feature-login     # злити гілку в поточну

Командна робота будується навколо Pull Request — пропозиції злити гілку після рев'ю коду.
