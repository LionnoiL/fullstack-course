Проєкт: Хрестики-нулики

Хрестики-нулики — канонічна задача на алгоритм Мінімакс. Почнемо з простої гри двох гравців, потім додамо непереможного AI і розберемо, як він «думає».

Хід: ❌
❌ 0  |  🤝 0  |  ⭕ 0

Завдання 1. Стан та рендер

Стан гри — масив з 9 елементів (null | 'X' | 'O') і поточний гравець. Напиши renderBoard(board): побудуй або оновлюй 9 клітинок у DOM, показуй символ, блокуй зайняті. При натисканні на вільну клітинку — роби хід і перемальовуй.

Рішення 
let board = Array(9).fill(null);
let current = 'X';

const boardEl = document.querySelector('.board');

function renderBoard() {
  boardEl.querySelectorAll('.cell').forEach((el, i) => {
    el.textContent = board[i] === 'X' ? '❌' : board[i] === 'O' ? '⭕' : '';
    el.classList.toggle('taken', board[i] !== null);
  });
}

boardEl.addEventListener('click', (e) => {
  const el = e.target.closest('.cell');
  if (!el || board[el.dataset.i] !== null || gameOver) return;
  const i = +el.dataset.i;
  board[i] = current;
  const win = checkWinner(board);
  if (win) { handleEnd(win); return; }
  current = current === 'X' ? 'O' : 'X';
  renderBoard();
});

Завдання 2. Перевірка переможця

Напиши checkWinner(board): перевір усі 8 виграшних комбінацій (3 рядки, 3 стовпці, 2 діагоналі). Поверни 'X', 'O', 'draw' (якщо всі 9 клітинок заповнені і переможця немає), або null (гра ще йде).

Рішення 
const LINES = [
  [0, 1, 2], [3, 4, 5], [6, 7, 8], // рядки
  [0, 3, 6], [1, 4, 7], [2, 5, 8], // стовпці
  [0, 4, 8], [2, 4, 6],             // діагоналі
];

function checkWinner(board) {
  for (const [a, b, c] of LINES) {
    if (board[a] && board[a] === board[b] && board[a] === board[c])
      return board[a];
  }
  if (board.every((v) => v !== null)) return 'draw';
  return null;
}

Завдання 3. AI: випадкові ходи

Перший рівень AI — грає випадково серед доступних клітинок. Напиши aiRandom(board) що повертає індекс вільної клітинки. Додай режим «гравець проти AI» з перемикачем. AI робить хід через короткий setTimeout щоб не відчувалось миттєво.

Рішення 
function aiRandom(board) {
  const free = board.map((v, i) => v === null ? i : -1).filter((i) => i !== -1);
  return free[Math.floor(Math.random() * free.length)];
}

function aiMove() {
  setTimeout(() => {
    const i = aiRandom(board);
    if (i == null) return;
    board[i] = 'O';
    const win = checkWinner(board);
    if (win) { handleEnd(win); return; }
    current = 'X';
    renderBoard();
  }, 300);
}

Завдання 4. AI: алгоритм Мінімакс

Мінімакс — рекурсивний алгоритм що перебирає всі можливі ігри наперед. minimax(board, isMaximizing) повертає оцінку позиції: +10 якщо 'O' виграє, -10 якщо 'X' виграє, 0 — нічия. AI (O) максимізує, гравець (X) — мінімізує. Функція bestMove(board) перебирає всі вільні клітинки, рахує minimax для кожної і обирає хід із найбільшою оцінкою.

Підказка

Базові випадки: якщо checkWinner повернув результат — поверни оцінку. Інакше ітеруй по вільних клітинках: поставь символ, рекурсивно викличи minimax з протилежним isMaximizing, зніми символ (backtracking). Збери масив оцінок і поверни max або min.

Рішення 
function minimax(board, isMaximizing) {
  const winner = checkWinner(board);
  if (winner === 'O') return 10;
  if (winner === 'X') return -10;
  if (winner === 'draw') return 0;

  const scores = [];
  for (let i = 0; i < 9; i++) {
    if (board[i] !== null) continue;
    board[i] = isMaximizing ? 'O' : 'X';
    scores.push(minimax(board, !isMaximizing));
    board[i] = null; // backtrack
  }
  return isMaximizing ? Math.max(...scores) : Math.min(...scores);
}

function bestMove(board) {
  let best = -Infinity;
  let move = null;
  for (let i = 0; i < 9; i++) {
    if (board[i] !== null) continue;
    board[i] = 'O';
    const score = minimax(board, false);
    board[i] = null;
    if (score > best) { best = score; move = i; }
  }
  return move;
}

Завдання 5. Рахунок серії та підсвітка виграшу

Після кожної гри оновлюй лічильники перемог X, O і нічиїх — зберігай між іграми в змінних (або localStorage). Підсвіть виграшну трійку: додай CSS-клас win до трьох відповідних клітинок. Знайди виграшну комбінацію в LINES після того як checkWinner повернув переможця.

Рішення 
let scores = { X: 0, O: 0, draw: 0 };

function highlightWin(winner) {
  for (const [a, b, c] of LINES) {
    if (board[a] === winner && board[b] === winner && board[c] === winner) {
      [a, b, c].forEach((i) => {
        document.querySelector(`[data-i="${i}"]`).classList.add('win');
      });
      break;
    }
  }
}

function handleEnd(result) {
  renderBoard();
  if (result !== 'draw') highlightWin(result);
  gameOver = true;
  scores[result] = (scores[result] || 0) + 1;
  document.querySelector('#score-x').textContent = scores.X;
  document.querySelector('#score-o').textContent = scores.O;
  document.querySelector('#score-draw').textContent = scores.draw;
  const msg = result === 'draw' ? 'Нічия 🤝' : `Переміг ${result === 'X' ? '❌' : '⭕'}!`;
  document.querySelector('#status').textContent = msg;
}

Завдання 6. Мінімакс з Alpha-Beta обрізанням (виклик)

Для 3×3 мінімакс і так миттєвий, але на більших дошках (4×4, 5×5) він стає нестерпно повільним. Реалізуй Alpha-Beta pruning: додай параметри alpha і beta до рекурсії, обрізай гілки де beta ≤ alpha. Потім розшир гру до 5×5, потрібно 4 в ряд — тепер тільки Alpha-Beta зробить AI грати без помітних затримок.

Підказка

Максимізатор оновлює alpha = max(alpha, score). Мінімізатор — beta = min(beta, score). Якщо beta ≤ alpha — break (решта гілок не змінять результат).

Мінімакс — фундамент ігрового AI: шахи, шашки, го використовують його варіанти. Хрестики-нулики ідеальні для навчання бо дерево невелике і можна в консолі простежити кожне рішення алгоритму.
