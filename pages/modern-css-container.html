1. Проблема медіазапитів

Медіазапити дивляться на розмір вікна. Але один і той самий компонент (картку) можна поставити і в широку колонку, і у вузький сайдбар — а вікно при цьому однакове. Медіазапит тут не допоможе.

Container queries дозволяють компоненту адаптуватися до розміру свого контейнера, а не екрана. Це робить компоненти по-справжньому переносними.

2. Оголошення контейнера

Спершу елемент-обгортку позначають як контейнер запитів:

.card-wrapper {
  container-type: inline-size;   /* стежити за шириною */
  container-name: card;          /* ім'я (необов'язкове) */
}

3. Запит @container

.card {
  display: grid;
  grid-template-columns: 1fr;
}

/* коли контейнер ширший за 400px */
@container card (min-width: 400px) {
  .card {
    grid-template-columns: 150px 1fr; /* зображення + текст поруч */
  }
}

Тепер картка сама вирішує, як виглядати, залежно від відведеного їй місця — де б її не поставили.

Стилі всередині @container застосовуються до нащадків контейнера, а не до самого контейнера. Тому контейнером роблять обгортку, а адаптують — вміст.

4. Контейнерні одиниці

Разом із container queries з'явилися одиниці, відносні до контейнера: cqw (1% ширини контейнера), cqh, cqi, cqmin, cqmax. 

.card .title {
  font-size: clamp(1rem, 5cqi, 2rem); /* масштаб від ширини контейнера */
}

5. Коли що

  • Медіазапити — глобальний макет сторінки (загальна сітка, навігація).
  • Container queries — переносні компоненти, що трапляються в різних місцях.
