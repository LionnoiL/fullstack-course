1. Стилізовані поля

Bootstrap оформлює поля класами form-control, form-label, form-select — і форма одразу виглядає охайно та адаптивно.

<div class="mb-3">
  <label for="email" class="form-label">Email</label>
  <input type="email" class="form-control" id="email" placeholder="you@site.com">
</div>

<div class="mb-3">
  <label for="city" class="form-label">Місто</label>
  <select class="form-select" id="city">
    <option>Київ</option>
    <option>Львів</option>
  </select>
</div>

2. Чекбокси та перемикачі

<div class="form-check">
  <input class="form-check-input" type="checkbox" id="agree">
  <label class="form-check-label" for="agree">Приймаю умови</label>
</div>

<div class="form-check form-switch">
  <input class="form-check-input" type="checkbox" id="dark">
  <label class="form-check-label" for="dark">Темна тема</label>
</div>

3. Групи вводу (input group)

<div class="input-group">
  <span class="input-group-text">@</span>
  <input type="text" class="form-control" placeholder="нікнейм">
</div>

4. Стани валідації

<input class="form-control is-valid">
<div class="valid-feedback">Виглядає добре!</div>

<input class="form-control is-invalid">
<div class="invalid-feedback">Заповніть це поле.</div>

Класи is-valid/is-invalid зручно перемикати з JavaScript після власної перевірки (див. розділ «Форми та валідація»).
