Практика: Реалтайм (WebSockets / SSE)

Зроби невеликий Node-сервер і клієнт (Vite). Пройди шлях від простого SSE-лічильника до чату на Socket.io з кімнатами, автентифікацією й presence.

Завдання 1. SSE-годинник

Зроби ендпоінт /api/time, що щосекунди стрімить поточний час через text/event-stream. На клієнті підпишись через EventSource й оновлюй елемент на сторінці. Не забудь прибирати таймер на close.

Рішення 
// сервер
app.get('/api/time', (req, res) => {
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');
  const t = setInterval(() => res.write(`data: ${Date.now()}\n\n`), 1000);
  req.on('close', () => clearInterval(t));
});

// клієнт
const es = new EventSource('/api/time');
es.onmessage = (e) => { clock.textContent = new Date(+e.data).toLocaleTimeString(); };

Завдання 2. Ехо через WebSocket

Підніми WebSocket-сервер на ws. На кожне отримане повідомлення відповідай тим самим текстом у верхньому регістрі. На клієнті (браузерний WebSocket) надішли рядок і покажи відповідь.

Підказка

Надсилати можна лише в стані OPEN. Структуровані дані серіалізуй через JSON.stringify/JSON.parse.

Рішення 
// сервер (ws)
wss.on('connection', (socket) => {
  socket.on('message', (raw) => socket.send(raw.toString().toUpperCase()));
});
// клієнт
ws.onopen = () => ws.send('привіт');
ws.onmessage = (e) => console.log(e.data); // ПРИВІТ

Завдання 3. Чат на Socket.io

Зроби спільний чат: клієнт надсилає подію message, сервер розсилає її всім через broadcast. Додай список повідомлень на сторінці. Використай іменовані події emit/on.

Рішення 
// сервер
io.on('connection', (socket) => {
  socket.on('message', (text) =>
    io.emit('message', { id: socket.id, text }));
});
// клієнт
socket.emit('message', input.value);
socket.on('message', (m) => addToList(m));

Завдання 4. Кімнати та «друкує…»

Додай кімнати: за подією join клади сокет у кімнату й адресуй повідомлення лише їй (io.to(room)). Реалізуй індикатор typing, який видно іншим учасникам кімнати (але не самому автору).

Підказка

socket.join(room) для входу; socket.to(room).emit('typing', id) — усім у кімнаті, крім відправника.

Завдання 5. Автентифікація й presence (виклик)

Передавай JWT при підключенні (io(url, { auth: { token } })) і перевіряй його в io.use(...)-middleware. Веди список онлайн-користувачів і розсилай presence на connection/disconnect. За бажання — додай дозавантаження пропущених повідомлень через HTTP після reconnect.
