1. Типи, що обчислюються

TypeScript дозволяє не лише описувати типи, а й обчислювати нові типи з наявних. Саме на цих механізмах побудовані utility types.

2. keyof і typeof

keyof дає обʼєднання ключів типу, typeof — тип наявного значення.

interface User {
  id: number;
  name: string;
}

type UserKeys = keyof User; // 'id' | 'name'

const config = { host: 'localhost', port: 3000 };
type Config = typeof config; // { host: string; port: number }

// Безпечний доступ до поля за ключем
function getProp<T, K extends keyof T>(obj: T, key: K): T[K] {
  return obj[key];
}

3. Відображені типи (mapped types)

Дозволяють створити новий тип, «пройшовшись» по ключах наявного.

type Optional<T> = {
  [K in keyof T]?: T[K];
};

type ReadonlyAll<T> = {
  readonly [K in keyof T]: T[K];
};

type UserOptional = Optional<User>; // усі поля необовʼязкові

4. Умовні типи (conditional types)

Синтаксис T extends U ? X : Y обирає тип залежно від умови.

type IsString<T> = T extends string ? true : false;

type A = IsString<'hi'>; // true
type B = IsString<42>;   // false

// infer «витягує» тип із іншого
type ElementType<T> = T extends (infer U)[] ? U : T;
type E = ElementType<number[]>; // number

5. Шаблонні літеральні типи

type Event = 'click' | 'focus';
type Handler = `on${Capitalize<Event>}`;
// 'onClick' | 'onFocus'

Просунуті типи потужні, але легко перестаратися. Якщо тип став нечитабельним — часто простіше описати його явно. Складна типова «магія» доречна в бібліотеках, а не в звичайному прикладному коді.
