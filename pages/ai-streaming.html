1. Навіщо стрімити

Довга відповідь генерується кілька секунд. Якщо чекати її цілком, користувач бачить порожній екран. Стрімінг віддає текст по частинах (токенах), щойно вони готові — як «друкує…» у месенджері. Це той самий SSE, що ми розбирали в розділі «Реалтайм»: один потік сервер→клієнт.

Стрімінг не лише покращує UX — він ще й рятує від таймаутів: довга не-стрімінгова відповідь може перевищити ліміт часу зʼєднання. Для великих max_tokens стрімінг фактично обовʼязковий.

2. Отримати потік

Замість messages.create викликаємо messages.stream і перебираємо події. Найпростіше — слухати текстові дельти: 

const stream = client.messages.stream({
  model: 'claude-opus-4-8',
  max_tokens: 1024,
  messages: [{ role: 'user', content: 'Напиши коротке оповідання.' }],
});

// подія 'text' дає лише новий шматок тексту
stream.on('text', (delta) => {
  process.stdout.write(delta);
});

const finalMessage = await stream.finalMessage(); // повна відповідь у кінці

Або перебрати сирі події вручну — корисно, коли треба розрізняти типи блоків:

for await (const event of stream) {
  if (event.type === 'content_block_delta' && event.delta.type === 'text_delta') {
    process.stdout.write(event.delta.text);
  }
}

3. Пробросити потік на фронт (SSE)

Бекенд читає потік від LLM і одразу пересилає шматки браузеру через text/event-stream: 

app.post('/api/chat', async (req, res) => {
  res.setHeader('Content-Type', 'text/event-stream');
  res.setHeader('Cache-Control', 'no-cache');

  const stream = client.messages.stream({
    model: 'claude-opus-4-8',
    max_tokens: 1024,
    messages: [{ role: 'user', content: req.body.message }],
  });

  stream.on('text', (delta) => {
    res.write(`data: ${JSON.stringify({ delta })}\n\n`);
  });
  await stream.finalMessage();
  res.write('data: [DONE]\n\n');
  res.end();
});

4. Показати по токенах на клієнті

const res = await fetch('/api/chat', {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ message }),
});

const reader = res.body.getReader();
const decoder = new TextDecoder();
let answer = '';

while (true) {
  const { value, done } = await reader.read();
  if (done) break;
  // розбираємо SSE-кадри 'data: ...'
  for (const line of decoder.decode(value).split('\n')) {
    if (!line.startsWith('data: ')) continue;
    const payload = line.slice(6);
    if (payload === '[DONE]') continue;
    answer += JSON.parse(payload).delta;
    render(answer); // дописуємо в UI
  }
}

У React зручно оновлювати стан на кожен шматок: setAnswer((prev) => prev + delta). А ще простіше — узяти Vercel AI SDK з готовим хуком useChat, який робить увесь цей парсинг за тебе (окремий урок).
