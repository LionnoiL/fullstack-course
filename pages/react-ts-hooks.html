1. useContext

Контекст типізують у момент створення — далі useContext поверне вже відомий тип.

type Theme = 'light' | 'dark';
type ThemeCtx = { theme: Theme; toggle: () => void };

const ThemeContext = createContext<ThemeCtx | null>(null);

function useTheme() {
  const ctx = useContext(ThemeContext);
  if (!ctx) throw new Error('useTheme must be used within ThemeProvider');
  return ctx; // тут тип уже ThemeCtx (без null)
}

Патерн «контекст + власний хук із перевіркою на null» позбавляє від постійних перевірок у компонентах: усередині useTheme ми один раз відсікаємо null, і далі тип завжди повний.

2. useReducer

Типізують стан і об'єднання дій — тоді TS перевіряє кожну гілку редюсера й підказує доступні action.type.

type State = { count: number };
type Action =
  | { type: 'inc' }
  | { type: 'dec' }
  | { type: 'set'; payload: number };

function reducer(state: State, action: Action): State {
  switch (action.type) {
    case 'inc': return { count: state.count + 1 };
    case 'dec': return { count: state.count - 1 };
    case 'set': return { count: action.payload };
  }
}

const [state, dispatch] = useReducer(reducer, { count: 0 });
dispatch({ type: 'set', payload: 10 }); // ✅ payload обов'язковий

3. Власні хуки

Кастомний хук типізують як звичайну функцію. Якщо він повертає кортеж — корисно зафіксувати його через as const, щоб типи були точними.

function useToggle(initial = false) {
  const [on, setOn] = useState(initial);
  const toggle = () => setOn((v) => !v);
  return [on, toggle] as const; // тип: readonly [boolean, () => void]
}

const [open, toggleOpen] = useToggle();

4. Дженерик-хук

Хук може бути узагальненим — тип «протікає» від аргументу до результату:

function useLocalStorage<T>(key: string, initial: T) {
  const [value, setValue] = useState<T>(() => {
    const raw = localStorage.getItem(key);
    return raw ? (JSON.parse(raw) as T) : initial;
  });
  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);
  return [value, setValue] as const;
}

const [todos, setTodos] = useLocalStorage<string[]>('todos', []);

5. useEffect

useEffect не потребує типів — головне повертати або нічого, або функцію-очищення. TS перевірить це сам.
