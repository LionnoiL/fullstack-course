1. Адаптивний дизайн

Адаптивний (responsive) дизайн — це підхід, коли сторінка однаково зручна на телефоні, планшеті й десктопі. Досягається гнучкими одиницями, гнучкими розкладками та медіазапитами.

2. Метатег viewport

Обовʼязковий рядок, без якого мобільні браузери масштабують «десктопну» сторінку:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

3. Медіазапити

Медіазапит застосовує стилі лише за певної умови — зазвичай ширини екрана.

/* базові стилі — для мобільних */
.container { flex-direction: column; }

/* від 768px і ширше — планшети/десктоп */
@media (min-width: 768px) {
  .container { flex-direction: row; }
}

@media (max-width: 480px) {
  .menu { display: none; }
}

4. Mobile-first

Підхід mobile-first: базові стилі пишуть для вузького екрана, а медіазапитами min-width додають ускладнення для широких. Це чистіше, ніж навпаки.

Обирайте «точки перелому» (breakpoints) за тим, де ламається ваш дизайн, а не під конкретні моделі пристроїв. Пристроїв безліч, а верстка або тримається, або ні.

5. Гнучкі одиниці й зображення

.text { font-size: clamp(1rem, 2.5vw, 1.5rem); } /* адаптивний шрифт */
img    { max-width: 100%; height: auto; }         /* картинки не вилазять */
.box   { width: 90%; max-width: 1100px; }
