1. Що таке ORM

ORM (Object-Relational Mapping) — інструмент, що дозволяє працювати з базою даних через обʼєкти й методи мови, а не сирий SQL. Запити стають типобезпечними, читабельними й захищеними від інʼєкцій. Сучасний вибір у Node.js — Prisma.

2. Схема Prisma

Модель даних описують декларативно у файлі schema.prisma.

model User {
  id    Int     @id @default(autoincrement())
  name  String
  email String  @unique
  posts Post[]
}

model Post {
  id       Int    @id @default(autoincrement())
  title    String
  author   User   @relation(fields: [authorId], references: [id])
  authorId Int
}
npx prisma migrate dev --name init   // створити таблиці в БД
npx prisma generate                  // згенерувати клієнт

3. Запити через клієнт

const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();

// створити
await prisma.user.create({
  data: { name: 'Ada', email: 'ada@site.com' },
});

// прочитати
const users = await prisma.user.findMany();
const user = await prisma.user.findUnique({ where: { id: 1 } });

// оновити
await prisma.user.update({
  where: { id: 1 },
  data: { name: 'Ada L.' },
});

// видалити
await prisma.user.delete({ where: { id: 1 } });

4. Звʼязки та фільтри

// підвантажити повʼязані записи
const withPosts = await prisma.user.findMany({
  include: { posts: true },
});

// фільтрація та сортування
const found = await prisma.user.findMany({
  where: { name: { contains: 'Ada' } },
  orderBy: { id: 'desc' },
  take: 10,
});

Prisma генерує типи TypeScript зі схеми — редактор підказує поля моделей і ловить помилки ще до запуску. Це чудово поєднується з розділом TypeScript.
