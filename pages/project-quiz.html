Проєкт: вікторина (Quiz)

Рівень: початковий-середній. Етап: після масивів, об'єктів, DOM і подій. Тренує рендер зі структури даних і керування станом кроків.

Що зробити

Гра-вікторина: показує питання з варіантами, рахує правильні відповіді й у кінці виводить результат.

Вимоги

  • питання зберігаються масивом об'єктів;
  • показ по одному питанню з кнопками-варіантами;
  • підсвічування правильної/неправильної відповіді;
  • лічильник балів і прогрес (питання X з N);
  • фінальний екран із результатом і кнопкою «Пройти ще раз».
const questions = [
  {
    question: 'Яка мова додає інтерактивність вебсторінкам?',
    options: ['HTML', 'CSS', 'JavaScript', 'SQL'],
    correct: 2,
  },
  // ...
];

let current = 0;
let score = 0;

function renderQuestion() { /* показати questions[current] */ }

Тримай усе питання й прогрес у стані (current, score), а UI завжди перемальовуй із цього стану. Дані питань легко винести в окремий JSON-файл.

Розвиток

Таймер на питання, категорії, завантаження питань з Open Trivia DB через fetch, таблиця рекордів у localStorage.
