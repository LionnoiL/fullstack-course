1. Вступ

JSON — сучасний формат зберігання і передачі даних.

Об'єктоподібний синтаксис JSON дуже зручний. Саме в цьому форматі дані будуть приходити і відправлятися на сервер, зберігатися в локальному сховищі й т. п.

JSON можна розглядати як строкове представлення JavaScript-об'єкта. Підтримує наступні значення: string, number, object, array, boolean, null.

Нижче наведено приклад JSON-файлу. Він дуже схожий на об'єкти, за винятком того, що ключі і все крім: чисел, булей, null, літерала масиву і об'єкту, завжди повинні бути в подвійних лапках. 

{
  "name": "Josh",
  "weight": 175,
  "age": 30,
  "eyecolor": "brown",
  "isHappy": true,
  "cars": ["Chevy", "Honda"],
  "favoriteBook": {
    "title": "When the Fire Nation Attacked",
    "author": "Nickelodeon",
    "released": "02-21-2005"
  }
}

Javascript і JSON відмінно працюють разом завдяки методам JSON.stringify() і JSON.parse(). Вони перетворять JS-об'єкт в JSON і назад, і незалежно від того, що у вас є, можна легко отримати зворотне.

2. Метод JSON.stringify(obj)

Щоб використовувати JSON.stringify(), просто передайте JavaScript-об'єкт, який необхідно перетворити в JSON. 

const dog = {
  name: 'Mango',
  age: 3,
  isHappy: true,
};

const dogJSON = JSON.stringify(dog);
console.log(dogJSON); // {"name":"Mango","age":3,"isHappy":true}

JSON.stringify(dog) взяв об'єкт dog і перетворив його в рядок. Цей рядок тепер валідний JSON і може бути збережений в файл або переданий по мережі.

3. Метод JSON.parse(string)

Щоб отримати JavaScript-об'єкт з JSON, ви повинні розібрати (розпарсити) його, операція зворотна stringify. 

const json = '{"name":"Mango","age":3,"isHappy":true}';

const dog = JSON.parse(json);
console.log(dog); // {name: "Mango", age: 3, isHappy: true}

Тепер, коли dog є звичайним JavaScript-об'єктом, його можна використовувати.
