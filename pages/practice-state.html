Практика: керування станом

Створи React-проєкт (Vite). Завдання 1–2 зроби на Zustand, 3 — на Redux Toolkit, щоб відчути обидва підходи на одній задачі.

Завдання 1. Лічильник на Zustand

Створи стор із count та діями increment/decrement/reset. Виведи значення у двох різних компонентах — переконайся, що обидва бачать спільний стан.

Рішення 
import { create } from 'zustand';

const useCounter = create((set) => ({
  count: 0,
  increment: () => set((s) => ({ count: s.count + 1 })),
  decrement: () => set((s) => ({ count: s.count - 1 })),
  reset: () => set({ count: 0 }),
}));

function Counter() {
  const { count, increment } = useCounter();
  return <button onClick={increment}>{count}</button>;
}

Завдання 3. Той самий лічильник на Redux Toolkit

Створи слайс counter через createSlice, налаштуй стор (configureStore), обгорни застосунок у Provider і використай useSelector/useDispatch. Порівняй обсяг коду з Zustand.

Рішення 
const counterSlice = createSlice({
  name: 'counter',
  initialState: { value: 0 },
  reducers: {
    increment: (s) => { s.value += 1; },
    decrement: (s) => { s.value -= 1; },
  },
});
export const { increment, decrement } = counterSlice.actions;

const store = configureStore({ reducer: { counter: counterSlice.reducer } });

// у компоненті:
const value = useSelector((s) => s.counter.value);
const dispatch = useDispatch();

Завдання 4. Асинхронне завантаження (виклик)

Додай createAsyncThunk, що вантажить список користувачів із JSONPlaceholder, і обробі стани pending/fulfilled/rejected в extraReducers. Виведи індикатор завантаження й список.
