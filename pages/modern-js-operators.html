1. Логічне присвоєння (ES2021)

Три оператори поєднують логіку й присвоєння — коротший запис поширених патернів:

a ||= b;   // a = a || b   — присвоїти, якщо a хибне (0, '', null, undefined...)
a &&= b;   // a = a && b   — присвоїти, якщо a істинне
a ??= b;   // a = a ?? b   — присвоїти, ЛИШЕ якщо a === null або undefined
// типове застосування — значення за замовчуванням
function greet(opts = {}) {
  opts.name ??= 'Гість';   // лише якщо name не задано (0 чи '' лишились би)
  return `Привіт, ${opts.name}`;
}

Різниця ??= vs ||= критична: ||= спрацює на 0 і '' (вважає їх «порожніми»), а ??= — лише на null/undefined. Для чисел і рядків майже завжди потрібен ??=.

2. Нагадування: ?? та ?.

Логічне присвоєння спирається на два оператори, які варто мати в пальцях:

const port = config.port ?? 3000;        // 3000 лише якщо port null/undefined
const city = user?.address?.city;        // undefined замість помилки, якщо ланцюг обірвано
const first = arr?.[0];                   // безпечний доступ до елемента
const res = obj.method?.();               // виклик, лише якщо метод існує

3. Числові роздільники

Підкреслення в числах — суто для читабельності, на значення не впливають:

const million = 1_000_000;      // === 1000000
const bytes   = 0xFF_FF_FF;
const price   = 19_999_99;      // копійки: легше прочитати

4. Комбінатори промісів

Окрім Promise.all (падає, якщо хоч один відхилився), є ще два корисних:

// allSettled — дочекатися ВСІХ, і успішних, і невдалих
const results = await Promise.allSettled([fetchA(), fetchB()]);
results.forEach((r) => {
  if (r.status === 'fulfilled') console.log(r.value);
  else console.log('помилка:', r.reason);
});

// any — перший, що УСПІШНО виконався (ігнорує відхилення)
const fastest = await Promise.any([mirror1(), mirror2(), mirror3()]);

Promise.all — «усі або нічого» (падає на першій помилці). allSettled — «зібрати всі результати, включно з помилками». any — «дай перший успіх». Обирай за задачею.
