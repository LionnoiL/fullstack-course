1. Тема через @theme

У версії 4 кастомізація живе прямо в CSS. Свої кольори, шрифти, відступи чи брейкпоінти оголошують у блоці @theme як CSS-змінні — Tailwind автоматично генерує з них класи-утиліти. 

@import "tailwindcss";

@theme {
  --color-brand: #4f46e5;
  --color-brand-dark: #4338ca;
  --font-display: "Poppins", sans-serif;
  --spacing-18: 4.5rem;
}

Після цього доступні класи bg-brand, text-brand, font-display, p-18 тощо — так само, як вбудовані. 

<button class="bg-brand hover:bg-brand-dark font-display px-18">
  Фірмова кнопка
</button>

2. Доступ до значень теми

Усі токени теми — це звичайні CSS-змінні, тож їх можна використати й у власному CSS поза утилітами: 

.custom-badge {
  background: var(--color-brand);
  padding: var(--spacing-2);
}

3. Підключення шрифту

@import url("https://fonts.googleapis.com/css2?family=Poppins:wght@400;600&display=swap");
@import "tailwindcss";

@theme {
  --font-display: "Poppins", sans-serif;
}

4. Власні базові стилі

Глобальні стилі (наприклад, для body) додають через @layer base, щоб вони не конфліктували з утилітами за пріоритетом. 

@layer base {
  body {
    @apply bg-gray-50 text-gray-900 antialiased;
  }
  h1 {
    @apply text-3xl font-bold;
  }
}

У версії 4 файл tailwind.config.js більше не обов'язковий — конфігурація переїхала в CSS (@theme). Старіші проєкти на версії 3 усе ще налаштовуються через JS-конфіг, тож звіряйтеся з версією в package.json.
