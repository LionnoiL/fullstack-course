Практика: DOM

Ці завдання зручно робити у зв'язці HTML + JS на CodePen або в локальному файлі.

Завдання 1. Динамічний список

Маючи масив рядків (напр. напоїв чи задач), програмно згенеруй елемент <ul> з окремим <li> на кожен елемент масиву й встав його в сторінку. Використай document.createElement і textContent (а не innerHTML з конкатенацією рядків — так безпечніше й чистіше).

Рішення 
const items = ['Кава', 'Чай', 'Какао'];
const ul = document.createElement('ul');

items.forEach((text) => {
  const li = document.createElement('li');
  li.textContent = text;
  ul.appendChild(li);
});

document.body.appendChild(ul);

Завдання 2. Перемикач теми

Додай кнопку, яка перемикає клас dark на <body> (classList.toggle) і запамʼятовує вибір у localStorage. При повторному відкритті сторінки збережена тема має відновитися одразу — прочитай localStorage на старті й застосуй клас до відмальовування. Додай трохи CSS для body.dark, щоб побачити ефект.

Рішення 
const btn = document.querySelector('#theme');

// відновити збережену тему
if (localStorage.getItem('theme') === 'dark') {
  document.body.classList.add('dark');
}

btn.addEventListener('click', () => {
  document.body.classList.toggle('dark');
  const isDark = document.body.classList.contains('dark');
  localStorage.setItem('theme', isDark ? 'dark' : 'light');
});

Завдання 3. Лічильник кліків (виклик)

Зроби кнопку, що показує, скільки разів її натиснули, і окрему кнопку скидання лічильника до нуля. Тримай значення в змінній, а при кожному кліку оновлюй лише текст потрібного вузла (textContent), а не перемальовуй усю сторінку — це базова звичка ефективної роботи з DOM.
