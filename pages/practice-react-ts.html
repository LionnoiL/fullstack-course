Практика: React + TypeScript

Створи проєкт (npm create vite@latest -- --template react-ts) або відкрий StackBlitz react-ts. Мета — навчитися типізувати пропси, стан, події та хуки без помилок компілятора.

Завдання 1. Типізований компонент

Зроби компонент UserCard із пропсами name: string, age: number і необов'язковим city?: string. Спробуй передати неправильний тип — переконайся, що TS лається.

Рішення 
type UserCardProps = { name: string; age: number; city?: string };

function UserCard({ name, age, city }: UserCardProps) {
  return (
    <div>
      <h2>{name}</h2>
      <p>{age} років{city ? `, ${city}` : ''}</p>
    </div>
  );
}

Завдання 2. Лічильник зі станом

Зроби лічильник на useState. Переконайся, що тип виводиться сам, а сеттер не приймає рядок.

Підказка

const [count, setCount] = useState(0) — тип number виведеться автоматично.

Завдання 3. Форма з подіями

Зроби контрольоване поле вводу й форму: винеси обробники onChange і onSubmit в окремі функції з правильними типами подій. onSubmit має викликати preventDefault().

Рішення 
const [value, setValue] = useState('');

function handleChange(e: React.ChangeEvent<HTMLInputElement>) {
  setValue(e.target.value);
}
function handleSubmit(e: React.FormEvent<HTMLFormElement>) {
  e.preventDefault();
  console.log(value);
}
// <form onSubmit={handleSubmit}><input value={value} onChange={handleChange} /></form>

Завдання 4. Список і кастомний хук (виклик)

Зроби узагальнений компонент List<T> з пропсами items: T[] і render: (item: T) => ReactNode. Додай кастомний хук useToggle, що повертає [boolean, () => void], і застосуй його для приховування/показу списку.

Візьми один зі своїх React-проєктів на чистому JS (напр. To-Do чи вікторину) і переведи його на TypeScript: опиши типи даних, типізуй пропси й стан. Так найкраще видно, скільки помилок TS ловить ще до запуску.
