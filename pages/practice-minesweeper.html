Проєкт: Сапер

Сапер — класика жанру, де головна алгоритмічна перлина — рекурсивне розкриття порожніх клітинок. Побудований на DOM: кожна клітинка — окремий div зі станом у масиві даних.

Завдання 1. Структура клітинки та поля

Визнач клітинку як обʼєкт: { mine, revealed, flagged, adjacentMines }. Напиши createBoard(rows, cols) — двовимірний масив клітинок, усі поля спочатку false / 0. Параметризуй розміри та кількість мін щоб підтримувати різні рівні складності.

Рішення 
const LEVELS = {
  easy:   { rows: 9,  cols: 9,  mines: 10 },
  medium: { rows: 16, cols: 16, mines: 40 },
  hard:   { rows: 16, cols: 30, mines: 99 },
};

function createBoard(rows, cols) {
  return Array.from({ length: rows }, () =>
    Array.from({ length: cols }, () => ({
      mine: false,
      revealed: false,
      flagged: false,
      adjacentMines: 0,
    }))
  );
}

Завдання 2. Розміщення мін

Напиши placeMines(board, count, safeR, safeC). Розстав count мін випадково, але не в клітинку де гравець вперше натиснув (safeR, safeC) і не в її 8 сусідів — це гарантує, що перший хід завжди безпечний. Використай алгоритм Фішера–Єйтса для рівномірного перемішування.

Підказка

Склади список усіх позицій крім безпечних, перемішай через Fisher-Yates, візьми перші count — постав mine = true.

Рішення 
function placeMines(board, count, safeR, safeC) {
  const rows = board.length;
  const cols = board[0].length;
  const safe = new Set();
  for (let dr = -1; dr <= 1; dr++)
    for (let dc = -1; dc <= 1; dc++)
      safe.add(`${safeR + dr},${safeC + dc}`);

  const candidates = [];
  for (let r = 0; r < rows; r++)
    for (let c = 0; c < cols; c++)
      if (!safe.has(`${r},${c}`)) candidates.push([r, c]);

  // Fisher-Yates shuffle перших count елементів
  for (let i = 0; i < count && i < candidates.length; i++) {
    const j = i + Math.floor(Math.random() * (candidates.length - i));
    [candidates[i], candidates[j]] = [candidates[j], candidates[i]];
    const [r, c] = candidates[i];
    board[r][c].mine = true;
  }
}

Завдання 3. Підрахунок сусідніх мін

Напиши calcAdjacent(board): для кожної клітинки що не є міною порахуй скільки з 8 сусідів є мінами і збережи в adjacentMines. Це потрібно обчислити після розстановки мін.

Рішення 
function calcAdjacent(board) {
  const rows = board.length;
  const cols = board[0].length;
  for (let r = 0; r < rows; r++) {
    for (let c = 0; c < cols; c++) {
      if (board[r][c].mine) continue;
      let count = 0;
      for (let dr = -1; dr <= 1; dr++)
        for (let dc = -1; dc <= 1; dc++) {
          const nr = r + dr, nc = c + dc;
          if (nr >= 0 && nr < rows && nc >= 0 && nc < cols && board[nr][nc].mine)
            count++;
        }
      board[r][c].adjacentMines = count;
    }
  }
}

Завдання 4. Рендер поля у DOM

Напиши render(board): побудуй CSS Grid де кожна клітинка — div із класами залежно від стану (revealed, flagged). Для розкритих клітинок показуй цифру (якщо adjacentMines > 0), 💣 для мін, нічого для порожніх. Не перебудовуй весь DOM при кожному оновленні — оновлюй тільки змінені клітинки.

Рішення 
function render(board) {
  board.forEach((row, r) => {
    row.forEach((cell, c) => {
      const el = document.querySelector(`[data-r="${r}"][data-c="${c}"]`);
      el.className = 'cell';
      el.textContent = '';
      el.removeAttribute('data-n');
      if (cell.revealed) {
        el.classList.add('revealed');
        if (cell.mine) { el.textContent = '💣'; el.classList.add('mine-hit'); }
        else if (cell.adjacentMines) {
          el.textContent = cell.adjacentMines;
          el.dataset.n = cell.adjacentMines;
        }
      } else if (cell.flagged) {
        el.textContent = '🚩';
        el.classList.add('flagged');
      }
    });
  });
}

Завдання 5. Розкриття клітинки (рекурсія)

Напиши reveal(board, r, c). Якщо клітинка вже розкрита, помічена прапорцем або є міна — стоп. Встанови revealed = true. Якщо adjacentMines === 0 — рекурсивно розкрий усіх 8 сусідів. Це і є flood-fill що «розливає» порожні зони.

Рішення 
function reveal(board, r, c) {
  const rows = board.length;
  const cols = board[0].length;
  if (r < 0 || r >= rows || c < 0 || c >= cols) return;
  const cell = board[r][c];
  if (cell.revealed || cell.flagged || cell.mine) return;

  cell.revealed = true;

  if (cell.adjacentMines === 0) {
    for (let dr = -1; dr <= 1; dr++)
      for (let dc = -1; dc <= 1; dc++)
        if (dr !== 0 || dc !== 0)
          reveal(board, r + dr, c + dc);
  }
}

Завдання 6. Обробка кліків

Лівий клік — розкрити клітинку. Якщо там міна — розкрий усі міни і завершуй гру. Правий клік — поставити / зняти прапорець (тільки на нерозкритих клітинках), оновлюй лічильник мін. Важливо: міни генеруй тільки після першого кліку (щоб гарантувати безпечний старт).

Рішення 
let firstClick = true;

gridEl.addEventListener('click', (e) => {
  const el = e.target.closest('.cell');
  if (!el || gameEnded) return;
  const r = +el.dataset.r, c = +el.dataset.c;
  const cell = board[r][c];
  if (cell.revealed || cell.flagged) return;

  if (firstClick) {
    firstClick = false;
    placeMines(board, mineCount, r, c);
    calcAdjacent(board);
    startTimer();
  }

  if (cell.mine) {
    revealAll(board);
    el.classList.add('mine-hit');
    endGame(false);
  } else {
    reveal(board, r, c);
    checkWin();
  }
  render(board);
});

gridEl.addEventListener('contextmenu', (e) => {
  e.preventDefault();
  const el = e.target.closest('.cell');
  if (!el || gameEnded) return;
  const r = +el.dataset.r, c = +el.dataset.c;
  const cell = board[r][c];
  if (cell.revealed) return;
  cell.flagged = !cell.flagged;
  flagCount += cell.flagged ? 1 : -1;
  updateMineCounter();
  render(board);
});

Завдання 7. Визначення перемоги та таймер

Гравець перемагає коли кількість нерозкритих клітинок дорівнює кількості мін (тобто всі безпечні клітинки розкриті). Запусти таймер на першому кліку, зупини при перемозі або програші. Виводь час у форматі 000 (з ведучими нулями, макс. 999).

Рішення 
function checkWin() {
  const unrevealed = board.flat().filter((c) => !c.revealed).length;
  if (unrevealed === mineCount) endGame(true);
}

let timerVal = 0;
let timerInterval = null;

function startTimer() {
  timerVal = 0;
  timerInterval = setInterval(() => {
    timerVal = Math.min(999, timerVal + 1);
    document.querySelector('#timer').textContent = String(timerVal).padStart(3, '0');
  }, 1000);
}

function endGame(won) {
  gameEnded = true;
  clearInterval(timerInterval);
  document.querySelector('#face').textContent = won ? '😎' : '😵';
  if (won) {
    board.flat().filter((c) => !c.revealed).forEach((c) => (c.flagged = true));
    render(board);
  }
}

Завдання 8. Хорд-клік та рівні складності (виклик)

Chord click: якщо клікнути на вже розкриту клітинку із цифрою, і кількість прапорців навколо рівна її числу — автоматично розкрий решту сусідів (стандартна механіка Сапера). Додай вибір рівня складності: Легко (9×9, 10 мін), Середньо (16×16, 40 мін), Складно (30×16, 99 мін). Реалізуй збереження найкращого часу для кожного рівня в localStorage.

Рекурсивний flood-fill із Сапера — той самий алгоритм що використовується в Paint («заливка»), пошуку компонент зв'язності у графах і BFS/DFS на гратках. Засвоїти його на грі — найприємніший спосіб.
