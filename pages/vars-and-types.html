1. Змінні

Змінні використовуються для зберігання даних і складаються з ідентифікатора (імені) і області в пам'яті, де зберігається їх значення. Змінну можна уявити як коробку з назвою, в якій щось лежить (значення).

1.1. Імена змінних

Ідентифікатор — це ім'я змінної, функції, параметра або класу. Складається з одного або декількох символів в наступному форматі:

  • Першим символом повинна бути буква a-z або A-Z, символ підкреслення _ або знак долара $.
  • Інші символи можуть бути буквами a-z, A-Z, цифрами 0-9, підкресленнями _ і знаками долара $.
  • Всі ідентифікатори чутливі до регістру. Це означає, що змінні user, usEr і User різні.

Ім'я змінної має бути зрозумілим.

❌ Погано
chislo korzina_tovarov profil_polzovatelya tekushiy_mesyaz

✅ Добре
number cart userProfile currentMonth

Використання camelCase-нотації для ідентифікаторів це стандарт. При такому підході, перше слово пишеться малими літерами, а кожне додаткове починається з великої літери. Наприклад: user, greetUser, getUserData, isActive, activeGuestCount, totalWorkerSalary.

1.3. Оголошення змінних

У сучасному JavaScript є 2 ключових слова для оголошення змінних.

  • let — оголошує змінну, якій можна присвоїти нове значення після оголошення, тобто перевизначити.
  • const — так само оголошує змінну, але з однією відмінністю: оголошується змінна повинна бути негайно ініціалізована значенням, і цій змінній не може бути присвоєно інше значення після ініціалізації.

Створення змінної без ключового слова let або const призведе до помилки. 

/*
 * Для оголошення змінної використовуються ключові слова let і const,
 * за якими слідує ім'я змінної.
 * Змінним оголошеним через let не обов'язково відразу привласнювати значення.
 */
let age;

/*
 * Змінні оголошені як const обов'язково повинні бути ініційовані
 * значенням під час оголошення, інакше нічого не вийде.
 */
const yearOfBirth = 2006;

/*
 * Значення змінної можна отримати звернувшись до неї по імені.
 * console.log() використовується для виведення даних в консоль розробника,
 * з цим методом більш детально познайомимося пізніше.
 */
console.log(yearOfBirth); // 15

/*
 * Якщо змінної оголошеної як let, з самого початку не присвоєно значення,
 * вона ініціюється спеціальним значенням undefined (не визначене).
 */
console.log(age); // undefined

/*
 * Якщо змінна оголошена як let, її значення можна перезаписати.
 */
age = 14;
console.log(age); // 14

/*
 * Якщо змінна оголошена як const, перезаписати її значення не можна.
 * При спробі привласнити нове значення буде помилка виконання скрипта.
 */
yearOfBirth = 2020; // буде помилка

1.4. Коли використовувати const і let

Єдина відмінність const і let полягає в тому, що const забороняє повторне присвоювання змінної будь-якого значення. Оголошення const робить код більш читабельним, оскільки змінна завжди посилається на одне і те ж значення. У випадку з let такої впевненості немає.

Буде розумно використовувати let і const так:

  • Використовуйте const за замовчуванням, більшість змінних будуть оголошені саме так.
  • Використовуйте let, якщо буде потрібно присвоїти змінної інше значення під час виконання скрипта.

1.5. константи і КОНСТАНТИ

Імена КОНСТАНТ -змінних, значення яких не змінюється ніколи протягом роботи всього скрипта, зазвичай записуються в форматі UPPER_SNAKE_CASE.

// Константа зберігає значення кольору
const COLOR_TEAL = '#009688';

// Константа зберігає повідомлення про авторизацію
const MESSAGE_LOGIN_SUCCESS = 'Ласкаво просимо!';

Абсолютна більшість змінних - константи в іншому сенсі, вони просто не змінюють значення після присвоєння. Але при різних запусках скрипта, це значення може бути різним. Імена таких змінних записують використовуючи формат camelCase.

1.6. Звернення до змінної

Важливо розрізняти невизначені та неоголошені змінні.

  • Невизначена (undefined) — це змінна, яка була оголошена, але не ініціалізована значенням, за замовчуванням їй присвоюється значення undefined як початкове.
  • Неоголошена (undeclared або not defined) — це змінна, яка не була оголошена в доступній області видимості.
let name;

/*
 * Змінна name оголошена, але не ініціалізована, тому
 * Її значення undefined (не визначене), тоді як змінна age
 * Не була визнана, тому доступ до неї викликає помилку
 ReferenceError
 */
console.log(name); // undefined
console.log(age); // ReferenceError: age is not defined

Спроба звернутися до змінної до її оголошення викличе помилку.

// console.log(a); // ReferenceError: a is not defined
let a = 10;
console.log(a); // 10

// console.log(b); // ReferenceError: b is not defined
const b = 15;
console.log(b); //15

2. Типи примітивів

JavaScript - це динамічна, слабо типізована мова, тому змінна не асоціюється з будь-яким типом даних, тип є у значення змінної. Тобто змінна може зберігати значення різних типів.

2.1. Number

Цілі числа і числа з плаваючою комою. Після оголошення змінної, можна ініціалізувати її числовим значенням.

const age = 20;
const number = 5.8;

2.2. String

Рядки - це просто текст, послідовність з нуля або більше символів. Рядок починається і закінчується одиночною ', або подвійними лапками ". Відкриваючі та закриваючі лапки повинні бути однакові.

const name = 'Mango';

2.3. Boolean

Логічний тип даних, прапори стану. Має тільки два значення: true і false, в нижньому регістрі. Наприклад, на питання включено світло в кімнаті можна відповісти так (true) або ні (false).

  • true — так, правильно, істина, 1
  • false — ні, не так, брехня, 0

Зверніть увагу на імена змінних, які містять буль. Вони ставлять питання, і відповідають на нього - так чи ні.

const isAuthenticated = true;
const canMerge = false;
const hasChildren = true;
const isModalOpen = false;

2.4. null

Особливе значення, яке по суті означає нічого. Використовується в тих ситуаціях, коли необхідно явно вказати відсутність значення. Наприклад, якщо в базі даних не знайшли користувача, то можна сказати що значення null.

// Мінлива guest порожня і позбавлена значення
const guest = null;

2.5. undefined

Ще одне спеціальне значення. За замовчуванням, коли змінна оголошується, але не ініціалізується, її значення не визначено, їй присвоюється undefined.

let name;
console.log(name); // undefined

2.6. Оператор typeof

Для отримання типу значення змінної, використовується оператор typeof, який повертає на місце свого виклику тип значення змінної вказаного після нього. Значення, що повертається це просто рядок в якій вказано тип.

// undefined
let a;
console.log(typeof a); // "undefined"

// null
const b = null;
console.log(typeof null); // "object"

// Number
const c = 5;
console.log(typeof c); // "number"

// String
const d = 'JavaScript is awesome!';
console.log(typeof d); // "string"

// Boolean
const e = false;
console.log(typeof e); // "boolean"
