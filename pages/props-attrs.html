1. Властивості

Під час побудови DOM-дерева багато стандартних HTML-атрибутів стають властивостями вузлів. Подивимося на кілька часто використовуваних властивостей.

  • hidden - контролює видимість елемента.
  • value - містить поточний текстовий контент елементів input, select, textarea.
  • checked - зберігає стан чекбокса або радіо кнопки.
  • name - зберігає значення вказане в HTML-атрибут name.
  • src - шлях до зображення тега <img>.

1.1. Властивість Node.textContent

elem.textContent — властивість, містить текстовий контент всередині елемента. Доступно для запису, при чому незалежно що буде передано в textContent, дані завжди будуть записані як текст.

Посилання на приклад в Codepen.io

1.2. Властивість HTMLElement.style

Використовується для отримання й установки інлайнових стилів. Повертає об'єкт CSSStyleDeclaration, який містить список всіх властивостей певних тільки в інлайновому стилі елемента, а не весь CSS. Властивість можна як читати так і записувати. При записі, властивості записуються в camelCase, тобто background-color перетворюється в element.style.backgroundColor і т. д.

const button = document.querySelector('.btn');

button.style.backgroundColor = 'teal';
console.log(button.style); // об'єкт інлайн стилів

1.3. Властивість Element.classList

Об'єкт, містить методи для роботи з класами елемента.

  • elem.classList.contains(cls) - повертає true або false, в залежності
    від того, чи є в елемента клас cls
  • elem.classList.add(cls) - додає клас cls в список класів елемента
  • elem.classList.remove(cls) - видаляє клас cls зі списку класів елемента
  • elem.classList.replace(oldClass, newClass) - замінює існуючий клас на
    зазначений
  • elem.classList.toggle(cls) - якщо класу cls немає, додає його, якщо є, видаляє

2. Атрибути

DOM-елементи відповідають HTML-тегам, які мають атрибути. Доступ до атрибутів здійснюється за допомогою стандартних методів. Ці методи працюють зі значенням, яке знаходиться в HTML.

  • elem.hasAttribute(name) - перевіряє наявність атрибута, повертає true або false
  • elem.getAttribute(name) - отримує значення атрибута і повертає його
  • elem.setAttribute(name, value) - встановлює атрибут
  • elem.removeAttribute(name) - видаляє атрибут
  • elem.attributes - властивість, повертає колекцію всіх атрибутів елемента

2.1. HTML5 data-атрибути

У HTML5 можна створювати власні атрибути з префіксом data- і отримувати їхні значення в JavaScript. Цю можливість використовують для того, щоб зв'язати дані і розмітку за унікальним ідентифікатором, вказати тип дії кнопки й т. п.

<button data-action="delete" data-id="42">Видалити</button>

2.2. Властивість dataset

Властивість elem.dataset — сучасний спосіб роботи з data-* атрибутами. Вона повертає об'єкт DOMStringMap, де ключами є назви атрибутів без префікса data- (у camelCase для дефісних назв).

const btn = document.querySelector('button');

// Читання
console.log(btn.dataset.action); // "delete"
console.log(btn.dataset.id);     // "42" (завжди рядок!)

// Запис — автоматично додає атрибут data-*
btn.dataset.userId = '99';        // → data-user-id="99"

Значення з dataset завжди повертаються як рядки. Якщо зберігаєте число, не забудьте перетворити: Number(btn.dataset.id).

3. Різниця між властивостями та атрибутами

Властивість (property) і атрибут (attribute) — близькі, але різні речі. Атрибут — це те, що записано в HTML-коді. Властивість — це поле JavaScript-об'єкта, що відповідає DOM-вузлу.

Коли браузер будує DOM, більшість атрибутів перетворюються на відповідні властивості, але між ними є важлива різниця — особливо для полів форм:

// HTML: <input value="Привіт">
const input = document.querySelector('input');

// Атрибут — початкове значення, завжди рядок
input.getAttribute('value');  // "Привіт"

// Користувач змінив текст у полі на "Світ"
input.value;                    // "Світ" (поточне значення)
input.getAttribute('value');  // "Привіт" (атрибут не змінився!)
  • Властивість input.value відображає поточний стан.
  • Атрибут getAttribute('value') зберігає початкове значення з HTML.
  • Аналогічно для checked, selected та інших.

Правило: для роботи з поточним станом елемента використовуйте властивості (elem.value, elem.checked). Для читання/запису початкових значень HTML або нестандартних атрибутів — методи getAttribute / setAttribute.
