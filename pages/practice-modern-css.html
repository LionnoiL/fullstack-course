Практика: сучасний CSS

Створи HTML-файл і розв'язуй завдання чистим CSS — без препроцесорів і JS. Перевіряй у сучасному браузері, а за бажання — обгортай нові фічі в @supports.

Завдання 1. Вкладеність і &

Опиши стилі картки через нативну вкладеність: заголовок, абзац і стан &:hover — усе всередині одного правила .card.

Рішення 
.card {
  padding: 1rem;
  border: 1px solid #e5e7eb;

  .title { font-weight: bold; }
  p { color: #6b7280; }
  &:hover { box-shadow: 0 4px 12px rgba(0,0,0,.1); }
}

Завдання 2. :has() для форми

Зроби так, щоб кнопка сабміту тьмянішала, коли у формі є невалідне поле — лише за допомогою :has(), без JavaScript.

Підказка

form:has(input:invalid) button { opacity: .5; }

Завдання 3. Container query

Зроби картку, що при вузькому контейнері показує зображення зверху, а при широкому (> 400px) — зображення й текст поруч. Постав ту саму картку у вузьку й широку колонки, щоб побачити різницю.

Рішення 
.wrap { container-type: inline-size; }
.card { display: grid; grid-template-columns: 1fr; gap: .5rem; }

@container (min-width: 400px) {
  .card { grid-template-columns: 140px 1fr; }
}

Завдання 4. Адаптив без медіазапитів (виклик)

Зроби заголовок із плинним розміром через clamp(), контейнер шириною min(100% - 2rem, 1100px) і додай підтримку темної теми через prefers-color-scheme (або light-dark()). Жодного медіазапиту для типографіки.

Візьми свій проєкт-лендинг і спробуй прибрати частину медіазапитів, замінивши їх на clamp() та container queries. Побачиш, наскільки чистішим стає CSS, коли адаптив «плинний», а не стрибками.
