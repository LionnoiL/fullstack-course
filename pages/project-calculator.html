Проєкт: калькулятор

Рівень: початковий. Етап: після HTML, CSS, DOM і подій. Класичний проєкт, що тренує роботу з інтерфейсом і станом.

Що зробити

Калькулятор із кнопками цифр і операцій, який рахує вирази й показує результат на «екрані».

Вимоги

  • кнопки 0–9, + − × ÷, =, C (скидання) і .;
  • дисплей показує поточне введення й результат;
  • ланцюжкові обчислення (2 + 3 × 4);
  • обробка ділення на нуль;
  • розкладка кнопок через CSS Grid;
  • підтримка клавіатури (бонус).

Підказки

  • тримай стан у змінних: поточне число, попереднє, обрана операція;
  • використай делегування — один обробник на контейнер кнопок, читай data-* атрибути;
  • не використовуй eval для обчислень — став окрему функцію на кожну операцію.
const buttons = document.querySelector('.keys');

buttons.addEventListener('click', (e) => {
  const key = e.target.closest('button');
  if (!key) return;
  const { value, action } = key.dataset;
  // action: 'digit' | 'operator' | 'equals' | 'clear'
});

Розбий логіку на дрібні функції: inputDigit, chooseOperator, calculate, reset. Так її легше тестувати й розширювати.

Розвиток

Історія обчислень, пам'ять (M+, MR), відсотки, наукові функції, темна тема.
