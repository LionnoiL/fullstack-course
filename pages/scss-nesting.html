1. Вкладеність селекторів

SCSS дозволяє вкладати селектори один в одного, повторюючи структуру HTML. Це економить повторення батьківського селектора.

.card {
  padding: 1rem;

  .title {
    font-size: 1.25rem;
    font-weight: bold;
  }

  .text { color: #6b7280; }
}

Скомпілюється у:

.card { padding: 1rem; }
.card .title { font-size: 1.25rem; font-weight: bold; }
.card .text { color: #6b7280; }

2. Батьківський селектор &

Символ & посилається на батьківський селектор. Найчастіше — для псевдокласів і модифікаторів.

.button {
  background: #2563eb;

  &:hover { background: #1e40af; }
  &:disabled { opacity: .5; }

  // модифікатор у стилі БЕМ → .button--large
  &--large { padding: 1rem 2rem; }
}

3. & для контексту

& можна поставити й після — щоб описати елемент у певному оточенні:

.title {
  color: #111;

  .dark-theme & {
    color: #fff; // .dark-theme .title
  }
}

4. Вкладені властивості

Властивості зі спільним префіксом теж можна групувати:

.box {
  font: {
    family: sans-serif;
    size: 1rem;
    weight: 600;
  }
}

Не вкладайте глибше 2–3 рівнів. Надмірна вкладеність породжує довгі специфічні селектори (.a .b .c .d), які важко перевизначити й які б'ють по продуктивності. Вкладеність — зручність, а не мета.
