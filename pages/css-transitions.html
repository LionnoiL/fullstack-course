1. Плавні переходи

Властивість transition робить зміну значень плавною замість миттєвої — наприклад, при наведенні. 

.button {
  background: #2563eb;
  transition: background 0.2s ease;
}
.button:hover {
  background: #1e40af; /* плавно за 0.2с */
}

2. Параметри transition

/* властивість | тривалість | функція | затримка */
transition: transform 0.3s ease-in-out 0s;

/* кілька властивостей */
transition: color 0.2s, transform 0.3s;

/* усі властивості */
transition: all 0.2s ease;

3. Трансформації

transform зміщує, масштабує чи обертає елемент — без впливу на сусідів і дуже продуктивно. 

.card:hover {
  transform: translateY(-6px) scale(1.03);
}
/* rotate(45deg); translateX(10px); */

4. Анімації @keyframes

Для складніших, повторюваних анімацій описують ключові кадри.

@keyframes fade-in {
  from { opacity: 0; transform: translateY(10px); }
  to   { opacity: 1; transform: translateY(0); }
}

.modal {
  animation: fade-in 0.4s ease-out;
}

/* нескінченне обертання спінера */
@keyframes spin {
  to { transform: rotate(360deg); }
}
.spinner { animation: spin 1s linear infinite; }

Анімуйте переважно transform і opacity — вони не спричиняють перерахунок макета і працюють плавно. Анімація width, height, top навантажує браузер і може «смикатися».

5. Повага до налаштувань користувача

@media (prefers-reduced-motion: reduce) {
  * { animation: none !important; transition: none !important; }
}
