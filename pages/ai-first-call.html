1. Встановлення SDK

На бекенді (Node) ставимо офіційний SDK Anthropic:

npm install @anthropic-ai/sdk

2. Ініціалізація клієнта

Клієнт сам читає ключ зі змінної оточення ANTHROPIC_API_KEY — не передавай його в коді. 

import Anthropic from '@anthropic-ai/sdk';

const client = new Anthropic(); // читає ANTHROPIC_API_KEY з env

3. Перший запит

Метод messages.create приймає модель, ліміт відповіді (max_tokens), необовʼязковий system-промпт і масив повідомлень. Відповідь — масив блоків; беремо текстові. 

const response = await client.messages.create({
  model: 'claude-opus-4-8',
  max_tokens: 1024,
  system: 'Ти — лаконічний асистент. Відповідай українською.',
  messages: [
    { role: 'user', content: 'Поясни, що таке REST API, одним абзацом.' },
  ],
});

// content — масив блоків; дістаємо текст
const text = response.content
  .filter((b) => b.type === 'text')
  .map((b) => b.text)
  .join('');
console.log(text);

max_tokens — це ліміт відповіді, а не запиту. Якщо відповідь обірвалася, response.stop_reason буде 'max_tokens' — підніми ліміт. Для довгих відповідей використовуй стрімінг (наступний урок).

4. Загорнути у свій ендпоінт

Фронтенд не ходить до LLM напряму — він звертається до твого бекенду:

// Express-роут
app.post('/api/ask', async (req, res) => {
  const response = await client.messages.create({
    model: 'claude-opus-4-8',
    max_tokens: 1024,
    messages: [{ role: 'user', content: req.body.question }],
  });
  const text = response.content.find((b) => b.type === 'text')?.text ?? '';
  res.json({ answer: text });
});

5. Багатоходова розмова

API без стану, тож «памʼять» — це вся історія, яку ти надсилаєш щоразу. Додавай відповіді моделі назад у масив як assistant: 

const messages = [
  { role: 'user', content: 'Мене звати Аня.' },
];
let res1 = await client.messages.create({ model: 'claude-opus-4-8', max_tokens: 512, messages });

// додаємо відповідь моделі в історію
messages.push({ role: 'assistant', content: res1.content });
messages.push({ role: 'user', content: 'Як мене звати?' });

let res2 = await client.messages.create({ model: 'claude-opus-4-8', max_tokens: 512, messages });
// модель «памʼятає»: Аня

Перше повідомлення має бути user. Історія росте з кожним ходом — а отже, росте й вартість. У довгих діалогах старі повідомлення підсумовують або обрізають.

6. Обробка помилок

Мережа, ліміти, невалідний запит — усе це кидає типізовані помилки. Найчастіша — 429 (ліміт запитів); SDK сам робить повтори з відступом. 

import Anthropic from '@anthropic-ai/sdk';

try {
  const res = await client.messages.create({ /* ... */ });
} catch (err) {
  if (err instanceof Anthropic.RateLimitError) {
    // забагато запитів — зачекати й повторити
  } else if (err instanceof Anthropic.APIError) {
    console.error(err.status, err.message);
  }
}
