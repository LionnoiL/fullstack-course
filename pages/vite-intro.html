1. Що таке Vite

Vite (фр. «швидко», вимовляється «віт») — сучасний інструмент для збірки фронтенду. Він дає миттєвий dev-сервер під час розробки й оптимізовану збірку для продакшну. Сьогодні це стандарт де-факто для проєктів на React, Vue, Svelte та чистому JS — саме його пропонують офіційні стартери цих фреймворків.

2. Яку проблему вирішує

Класичні збирачі (як Webpack) перед запуском dev-сервера мусять зібрати увесь бандл. На великому проєкті це десятки секунд очікування, і що більший проєкт — то довше. Vite прибирає цю затримку.

Webpack ти вже бачив у розділі «Інструменти та збірка». Vite не скасовує тих знань про модулі й залежності — він лише робить розробку швидшою завдяки іншому підходу (нативні ESM у браузері замість повного бандлингу на кожен запуск).

3. Як він досягає швидкості

  • Нативні ES-модулі. У режимі розробки Vite віддає код браузеру як <script type="module"> — браузер сам підвантажує лише ті модулі, які потрібні поточній сторінці. Не треба збирати весь проєкт наперед.
  • esbuild для залежностей. Бібліотеки з node_modules Vite попередньо обробляє наднадшвидким збирачем на Go — esbuild.
  • Rollup для продакшну. Фінальну збірку робить перевірений Rollup — з мініфікацією, tree-shaking і code splitting.

4. Vite чи Webpack

  • Vite — нові проєкти, швидкий старт, миттєвий HMR, проста конфігурація. Для більшості нового фронтенду — вибір за замовчуванням.
  • Webpack — усе ще живий у великих легасі-проєктах і там, де потрібні специфічні лоадери/плагіни з його багатої екосистеми.

5. Що потрібно

Лише Node.js (актуальна LTS-версія) і npm — усе, що ми проходили в розділі про NPM. Перевір версію: 

node -v   // має бути свіжа LTS-версія
npm -v
