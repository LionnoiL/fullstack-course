1. Робота з формами

Форми — головний спосіб отримати дані від користувача. JavaScript дозволяє перехопити відправлення форми, зчитати значення полів, перевірити їх і надіслати на сервер без перезавантаження сторінки.

2. Подія submit

Слухати треба саме подію submit самої форми (а не click кнопки) — вона спрацьовує і на Enter у полі. Метод preventDefault() скасовує стандартне перезавантаження сторінки.

const form = document.querySelector('#login');

form.addEventListener('submit', (event) => {
  event.preventDefault(); // не перезавантажувати сторінку

  console.log('Форму відправлено');
});

3. Зчитування значень

До полів можна звертатися через form.elements за атрибутом name, а зручно зібрати всі дані одразу допомагає обʼєкт FormData.

form.addEventListener('submit', (event) => {
  event.preventDefault();

  // Доступ до окремого поля за name
  const email = form.elements.email.value;

  // Або всі поля одразу
  const data = new FormData(form);
  const values = Object.fromEntries(data); // { email: '...', password: '...' }

  console.log(values);
});

4. Події полів вводу

  • input — спрацьовує на кожну зміну символу (миттєва реакція);
  • change — після втрати фокусу, якщо значення змінилось;
  • focus / blur — отримання / втрата фокусу.
const search = document.querySelector('#search');

search.addEventListener('input', (event) => {
  console.log('Поточний текст:', event.target.value);
});

5. Валідація

У браузера є вбудована валідація (атрибути required, type="email", minlength, pattern). Її стан доступний з JS через checkValidity() і validity.

form.addEventListener('submit', (event) => {
  event.preventDefault();

  if (!form.checkValidity()) {
    form.reportValidity(); // показати стандартні підказки браузера
    return;
  }

  // Власна перевірка
  const password = form.elements.password.value;
  if (password.length < 8) {
    alert('Пароль має містити щонайменше 8 символів');
    return;
  }

  console.log('Дані валідні, відправляємо');
});

Клієнтська валідація — це зручність для користувача, а не безпека. Її легко обійти. Усі дані обовʼязково перевіряйте ще раз на сервері.
