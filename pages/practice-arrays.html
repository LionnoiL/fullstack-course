Практика: масиви

Тренуємо методи масивів: map, filter, reduce. Пиши код і тисни «Запустити».

Завдання 1. Сума додатних

Реалізуй sumPositive(arr), що повертає суму лише додатних чисел масиву.

Підказка

Спочатку filter залиши додатні, потім reduce просумуй.

Рішення 
function sumPositive(arr) {
  return arr.filter((n) => n > 0).reduce((acc, n) => acc + n, 0);
}

Завдання 2. Унікальні значення

Реалізуй unique(arr), що повертає новий масив без дублікатів, зберігаючи порядок.

Підказка

Найкоротше — через Set: [...new Set(arr)].

Рішення 
function unique(arr) {
  return [...new Set(arr)];
}

Завдання 3. Групування за властивістю

Реалізуй groupBy(arr, key), що групує масив об'єктів у об'єкт за значенням поля key.

Рішення 
function groupBy(arr, key) {
  return arr.reduce((acc, item) => {
    const k = item[key];
    (acc[k] = acc[k] || []).push(item);
    return acc;
  }, {});
}
