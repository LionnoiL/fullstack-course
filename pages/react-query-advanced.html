1. Пагінація

Сторінку роблять частиною ключа. Опція placeholderData зберігає попередні дані під час переходу, щоб список не «блимав» порожнечею.

import { keepPreviousData } from '@tanstack/react-query';

const { data } = useQuery({
  queryKey: ['todos', page],
  queryFn: () => fetchTodos(page),
  placeholderData: keepPreviousData, // показувати минулу сторінку до приходу нової
});

2. Безкінечний список

Для «Показати ще» / нескінченного скролу є окремий хук useInfiniteQuery:

const { data, fetchNextPage, hasNextPage } = useInfiniteQuery({
  queryKey: ['feed'],
  queryFn: ({ pageParam }) => fetchFeed(pageParam),
  initialPageParam: 1,
  getNextPageParam: (lastPage) => lastPage.nextCursor ?? undefined,
});

3. Залежні запити

Коли один запит потребує результату іншого, керуй ним через enabled:

const { data: user } = useQuery({ queryKey: ['user'], queryFn: fetchUser });

const { data: projects } = useQuery({
  queryKey: ['projects', user?.id],
  queryFn: () => fetchProjects(user.id),
  enabled: !!user?.id, // чекаємо, поки прийде user
});

4. Оптимістичні оновлення

Щоб UI реагував миттєво, оновлюють кеш ще до відповіді сервера, а при помилці відкочують.

useMutation({
  mutationFn: toggleTodo,
  onMutate: async (id) => {
    await queryClient.cancelQueries({ queryKey: ['todos'] });
    const prev = queryClient.getQueryData(['todos']);
    queryClient.setQueryData(['todos'], (old) =>
      old.map((t) => (t.id === id ? { ...t, done: !t.done } : t))
    );
    return { prev }; // контекст для відкату
  },
  onError: (_err, _id, ctx) => {
    queryClient.setQueryData(['todos'], ctx.prev); // відкат
  },
  onSettled: () => queryClient.invalidateQueries({ queryKey: ['todos'] }),
});

Оптимістичні оновлення — потужно, але додають складності. Починай із простого: «мутація → invalidateQueries». Оптимізм додавай там, де миттєвий відгук справді важливий (лайки, чекбокси, перемикачі).

5. Передзавантаження

// напр. при наведенні на посилання — дані вже будуть готові
queryClient.prefetchQuery({ queryKey: ['todo', id], queryFn: () => fetchTodo(id) });
