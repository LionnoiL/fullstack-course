Практика: замикання і this

Замикання, приватний стан, мемоізація. Пиши код і тисни «Запустити».

Завдання 1. Лічильник з приватним станом

Реалізуй createCounter(), що повертає об'єкт із методами increment(), decrement() та get(). Значення має бути недоступним ззовні напряму.

Підказка

Оголоси let count = 0; усередині функції — методи бачитимуть її через замикання.

Рішення 
function createCounter() {
  let count = 0;
  return {
    increment: () => { count += 1; },
    decrement: () => { count -= 1; },
    get: () => count,
  };
}

Завдання 2. Мемоізація

Реалізуй memoize(fn), що кешує результати для однакових аргументів (для функцій одного числового аргументу).

Рішення 
function memoize(fn) {
  const cache = new Map();
  return (arg) => {
    if (cache.has(arg)) return cache.get(arg);
    const result = fn(arg);
    cache.set(arg, result);
    return result;
  };
}

Завдання 3. Глибоке розгортання (рекурсія)

Реалізуй deepFlatten(arr), що розгортає вкладені масиви будь-якої глибини в один плаский масив.

Підказка

Для кожного елемента: якщо це масив — рекурсивно розгорни, інакше додай.

Рішення 
function deepFlatten(arr) {
  return arr.reduce(
    (acc, item) => acc.concat(Array.isArray(item) ? deepFlatten(item) : item),
    [],
  );
}

Завдання 4. Часткове застосування (partial)

Реалізуй partial(fn, ...preset), що «фіксує» перші аргументи функції й повертає нову функцію для решти.

Рішення 
function partial(fn, ...preset) {
  return (...rest) => fn(...preset, ...rest);
}
