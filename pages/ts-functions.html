1. Параметри та результат

Для функції вказують типи параметрів і тип значення, що повертається (останній часто виводиться автоматично).

function add(a: number, b: number): number {
  return a + b;
}

const multiply = (a: number, b: number): number => a * b;

2. Необовʼязкові та типові параметри

Знак ? робить параметр необовʼязковим. Параметр зі значенням за замовчуванням теж стає необовʼязковим.

function greet(name: string, greeting?: string): string {
  return `${greeting ?? 'Привіт'}, ${name}`;
}

greet('Ada');            // 'Привіт, Ada'
greet('Ada', 'Вітаю');   // 'Вітаю, Ada'

function pow(base: number, exp: number = 2): number {
  return base ** exp;
}

Необовʼязкові параметри мають іти після обовʼязкових. Інакше компілятор не зможе зіставити передані аргументи з параметрами.

3. Rest-параметри

function sum(...nums: number[]): number {
  return nums.reduce((acc, n) => acc + n, 0);
}

sum(1, 2, 3, 4); // 10

4. Тип функції

Саму функцію теж можна описати типом — це знадобиться для колбеків.

// (параметри) => тип результату
let operation: (a: number, b: number) => number;

operation = (a, b) => a + b; // типи a і b виводяться з анотації

function repeat(n: number, action: (i: number) => void): void {
  for (let i = 0; i < n; i += 1) {
    action(i);
  }
}

5. Перевантаження функцій

Одну функцію можна описати кількома сигнатурами — залежно від типів аргументів змінюється тип результату.

function len(x: string): number;
function len(x: unknown[]): number;
function len(x: string | unknown[]): number {
  return x.length;
}

len('hello'); // 5
len([1, 2]);  // 2
