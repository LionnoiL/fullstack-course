Мілстоун 3: погодний застосунок

Етап: після розділів «Асинхронність» і «Мережа та сервер». Мета — застосунок, що завантажує дані з реального API та обробляє стани завантаження й помилок.

Функціонал

  • поле вводу назви міста й кнопка пошуку;
  • завантаження поточної погоди з відкритого API;
  • показ температури, опису, вологості, вітру, іконки;
  • індикатор завантаження, поки триває запит;
  • зрозуміле повідомлення, якщо місто не знайдено або немає мережі;
  • (бонус) збереження останнього міста в localStorage.

Вимоги

  • запити через fetch + async/await;
  • обробка помилок через try...catch і перевірку res.ok;
  • три стани UI: завантаження / успіх / помилка;
  • API-ключ у конфізі, а не «зашитий» по всьому коду.

Публічні API

  • Open-Meteo — без ключа, найпростіший старт;
  • OpenWeatherMap — потрібен безкоштовний ключ.
async function getWeather(city) {
  setLoading(true);
  try {
    const res = await fetch(`https://api.example.com/weather?q=${city}`);
    if (!res.ok) throw new Error('Місто не знайдено');
    const data = await res.json();
    renderWeather(data);
  } catch (e) {
    renderError(e.message);
  } finally {
    setLoading(false);
  }
}

Спершу подивись у консолі/Network, яку саме структуру повертає API, і лише потім «діставай» потрібні поля. Це типовий робочий процес з будь-яким API.

Розвиток проєкту

Додай прогноз на 5 днів, геолокацію (navigator.geolocation), debounce на поле пошуку, перемикання °C/°F.
