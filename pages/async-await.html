1. async / await

async / await — це синтаксичний «цукор» над промісами (ES2017), який дозволяє писати асинхронний код так, наче він синхронний: без ланцюжків .then(), зверху вниз, з природним try...catch. Під капотом усе одно працюють проміси.

2. Функція async

Ключове слово async перед функцією означає, що вона завжди повертає проміс. Значення, яке ви повертаєте, автоматично загортається у виконаний проміс. 

async function getNumber() {
  return 42;
}

getNumber().then((n) => console.log(n)); // 42
// getNumber() повертає Promise, що резолвиться в 42

3. Оператор await

await ставиться перед промісом і «призупиняє» виконання async-функції, доки проміс не завершиться, повертаючи його результат. Використовувати await можна лише всередині async-функції (або на верхньому рівні модуля). 

// Було: ланцюжок then
function loadOld() {
  return fetch('/api/user')
    .then((res) => res.json())
    .then((user) => console.log(user.name));
}

// Стало: async/await — лінійно й читабельно
async function loadNew() {
  const res = await fetch('/api/user');
  const user = await res.json();
  console.log(user.name);
}

4. Обробка помилок

З await помилки промісів перехоплюються звичайним try...catch — саме тому цей синтаксис такий зручний. 

async function load() {
  try {
    const res = await fetch('/api/data');
    if (!res.ok) {
      throw new Error('HTTP ' + res.status);
    }
    return await res.json();
  } catch (error) {
    console.error('Не вдалося завантажити:', error.message);
    return null;
  }
}

5. Послідовно проти паралельно

Кілька await поспіль виконуються послідовно — кожен чекає попередній. Якщо запити незалежні, це марна трата часу. Запускайте їх паралельно через Promise.all. 

// Повільно: 2 запити один за одним (сума часів)
const a = await fetch('/api/a');
const b = await fetch('/api/b');

// Швидко: обидва стартують одночасно
const [resA, resB] = await Promise.all([
  fetch('/api/a'),
  fetch('/api/b'),
]);

Promise.all відхиляється, щойно впаде будь-який з промісів. Якщо потрібно дочекатися всіх незалежно від помилок — використовуйте Promise.allSettled.

6. await у циклах

Щоб виконати асинхронну операцію для кожного елемента по черзі, підходить for...of. Для паралельного запуску — map + Promise.all. 

// По черзі
for (const id of ids) {
  const item = await fetchItem(id);
  console.log(item);
}

// Паралельно
const items = await Promise.all(ids.map((id) => fetchItem(id)));

forEach не «чекає» на await усередині себе. Для послідовної асинхронної обробки використовуйте for...of, а не forEach.
