Практика: Vite

Знадобиться встановлений Node.js. Виконуй завдання в терміналі й перевіряй результат у браузері. Мета — пройти повний цикл: створення → розробка → збірка.

Завдання 1. Створити й запустити проєкт

Створи проєкт на шаблоні Vanilla JS, встанови залежності й запусти dev-сервер. Відкрий сторінку в браузері.

Рішення 
npm create vite@latest my-app -- --template vanilla
cd my-app
npm install
npm run dev
// відкрий http://localhost:5173

Завдання 2. Перевірити HMR

Не зупиняючи сервер, зміни текст і колір у src/style.css та src/main.js. Переконайся, що сторінка оновлюється миттєво без повного перезавантаження.

Підказка

Стеж за вкладкою браузера: при HMR вона не «блимає» перезавантаженням, а стан сторінки зберігається.

Завдання 3. Змінна оточення

Створи файл .env зі змінною VITE_APP_TITLE і виведи її значення на сторінку. Потім додай змінну без префікса VITE_ і переконайся, що вона недоступна в коді клієнта.

Рішення 
// .env
VITE_APP_TITLE=Мій застосунок
SECRET=123

// src/main.js
document.querySelector('#app').textContent = import.meta.env.VITE_APP_TITLE;
console.log(import.meta.env.SECRET); // undefined

Завдання 4. Збірка й аліас (виклик)

Налаштуй аліас @ на папку src у vite.config.js, використай його в імпорті, а потім збери проєкт (npm run build) і переглянь результат через npm run preview. Подивись, які файли з'явились у dist/.

Спробуй перенести один зі своїх проєктів (наприклад, калькулятор чи To-Do з розділу «Проєкти») на Vite: розбий код на ES-модулі, підключи CSS імпортом і збери в dist/. Відчуєш різницю зі звичайним підключенням скриптів у HTML.
