1. Що таке лейаут

Лейаут (layout) — це спільна оболонка, що обгортає сторінки й не перемальовується під час навігації між ними. Ідеально для шапки, меню, підвалу.

2. Кореневий лейаут

Файл app/layout.jsx обовʼязковий — він містить теги <html> і <body> та обгортає весь застосунок. Проп children — це поточна сторінка.

// app/layout.jsx
export const metadata = {
  title: 'Мій сайт',
  description: 'Опис для SEO',
};

export default function RootLayout({ children }) {
  return (
    <html lang="uk">
      <body>
        <header>Шапка</header>
        <main>{children}</main>
        <footer>Підвал</footer>
      </body>
    </html>
  );
}

3. Вкладені лейаути

Кожен сегмент може мати власний layout.jsx — вони вкладаються один в одного. Це дозволяє, наприклад, додати бічне меню лише для розділу /dashboard.

// app/dashboard/layout.jsx
export default function DashboardLayout({ children }) {
  return (
    <div className="dashboard">
      <aside>Меню кабінету</aside>
      <section>{children}</section>
    </div>
  );
}

4. Метадані та SEO

Next.js генерує теги <head> з експортованого обʼєкта metadata — окремо для кожної сторінки чи лейаута.

// у будь-якому page.jsx або layout.jsx
export const metadata = {
  title: 'Про нас',
  description: 'Сторінка про компанію',
};

Оскільки лейаут не перемальовується при переходах, стан у ньому (напр., відкрите меню) зберігається між сторінками — на відміну від самих сторінок.
