Корисні посилання

Добірка інструментів і довідників, які стануть у пригоді під час навчання й реальної роботи. Багато з них згадані у відповідних уроках — тут вони зібрані в одному місці.

1. Валідатори та якість

  • W3C Nu Html Checker — перевірка коректності HTML-розмітки.
  • W3C CSS Validator — перевірка CSS.
  • PageSpeed Insights — аналіз швидкості й підказки з оптимізації (Lighthouse).

2. Зображення та графіка

  • Squoosh — стиснення й конвертація зображень (JPEG/PNG → WebP/AVIF) прямо в браузері.
  • remove.bg — автоматичне видалення фону зі знімка.
  • IcoMoon — генератор наборів іконок (іконковий шрифт або SVG-спрайт).

3. Довідники та документація

  • css.in.ua — довідник CSS українською.
  • MDN Web Docs — головна документація з HTML, CSS, JS.
  • Can I use — підтримка можливостей у різних браузерах.

Перед деплоєм корисно прогнати сторінку через валідатори HTML/CSS і PageSpeed, а важкі зображення — через Squoosh. Це швидко покращує якість і швидкість сайту.
