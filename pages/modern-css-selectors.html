1. :has() — батьківський селектор

:has() обирає елемент залежно від його вмісту чи наступних елементів. Роками це було неможливо в чистому CSS — тепер є.

/* картка, ВСЕРЕДИНІ якої є зображення */
.card:has(img) {
  padding: 0;
}

/* лейбл, за яким іде обов'язкове поле */
label:has(+ input:required)::after {
  content: " *";
  color: red;
}

2. :has() для станів

Особливо потужно у поєднанні з іншими псевдокласами — реагувати на стан всередині:

/* форма, де є невалідне поле */
form:has(input:invalid) button[type="submit"] {
  opacity: .5;
  pointer-events: none;
}

/* світла/темна тема без JS — за станом чекбокса десь вище */
body:has(#theme-toggle:checked) { background: #111; color: #eee; }

:has() закриває купу задач, які раніше вимагали JavaScript: реакція батька на дитину, залежності між сусідами, «розумні» стани форм. Часто тепер достатньо самого CSS.

3. :is() — коротший запис груп

:is() скорочує повторювані групи селекторів:

/* замість h1 a, h2 a, h3 a { ... } */
:is(h1, h2, h3) a { color: inherit; }

4. :where() — те саме, але без специфічності

:where() працює як :is(), але має нульову специфічність — його стилі легко перевизначити. Ідеально для базових стилів.

/* базовий стиль, який легко перебити пізніше */
:where(ul, ol) { margin: 0; padding: 0; }

Різниця у специфічності: :is() бере найвищу специфічність зі своїх аргументів, а :where() завжди 0. Для скидання й базових стилів обирай :where(), щоб не створювати «важких» правил, які потім важко перекрити.
