1. ES6 класи

JavaScript є єдиною масовою мовою програмування з успадкуванням, заснованим не на класах, а на прототипах. Величезне число розробників, які володіють технікою використання класів, постійно намагалися переробити JavaScript під свої вміння, а головне, під наявні напрацювання в області ООП. У ES6 зробили крок назустріч і ввели клас схожий на такий у мовах Java, C # і т. п. Це все ті ж прототипи, тільки в красивій обгортці.

2. Оголошення класу

Клас — це зручний спосіб для завдання конструктора разом з прототипом.

Переваги використання класів:

  • Весь код всередині класу виконується в строгому режимі.
  • Всі методи є неперерахованими.
  • У всіх методів класу відсутній внутрішній метод [[Construct]], що означає появу помилки при спробі використовувати ці методи з оператором new.
  • Виклик конструктора класу без оператора new викличе помилку.

Припустимо, ми запустили готель і хочемо, щоб об'єкт з методами представляв кожного гостя.

//class declaration
class Guest {
  //...
}

// Під капотом клас це функція-конструктор з прототипом
console.log(typeof Guest); // "function"
console.log(Guest.prototype); // {constructor: ƒ}

const guest = new Guest();
console.log(guest); // Guest {}

Як будувати клас, залежить від того, що вам потрібно. У нашому випадку, клас являє собою гостя готелю, тому ми додамо туди поля для імені, кількості днів проживання та номера кімнати.

Клас використовує аналог функції-конструктора - метод constructor. це особливий метод, він повинен бути присутнім в оголошенні класу обов'язково. Призначення конструктора - створювати власні властивості екземпляра класу.

  • Функція constructor запускається при виклику new Guest, інші методи записуються в Guest.prototype.
  • Властивість prototype класу є тільки для читання, тобто цю властивість не можна змінити.
  • У класі повинен бути тільки один конструктор, інакше нічого не вийде.
class Guest {
  // аналог функції-конструктора
  constructor(name, roomNumber) {
    this.name = name;
    this.roomNumber = roomNumber;
  }
}

const mango = new Guest('Mango', 26);

console.log(mango); // {name: Mango, roomNumber: 26}
console.log(mango instanceof Guest); // true
console.log(mango instanceof Object); // true

Сьогодні в концепції JavaScript-класів відсутні приватні властивості. Тобто, всі властивості та методи класу доступні зовні. Але ведеться робота над їх імплементацією в майбутніх редакціях стандарту.

3. Методи

Додамо функцію getFullInfo. Функції певні таким чином називатися методами класу і доступні всім екземплярам через prototype.

class Guest {
  // Аналог функції-конструктора
  constructor(name, roomNumber) {
    this.name = name;
    this.roomNumber = roomNumber;
  }

  // Аналог Guest.prototype.getFullInfo
  getFullInfo() {
    console.log(`
      Guest ${this.name}
      Room number ${this.roomNumber}
    `);
  }
}

const mango = new Guest('Mango', 26);

mango.getFullInfo();
// Guest Mango
// Room number 26

4. Геттери і сеттери

Власні властивості класу бажано зберігати в constructor. Але існує і інший варіант - розмістити в тілі класу методи set і get. Ці методи використовують особливий синтаксис, а при їх виклику, після імені об'єкта слід написати тільки ім'я геттера або сетера без виклику функції, тобто без круглих дужок.

class Guest {
  // Власні властивості класу розміщуємо в конструкторі
  constructor(name, roomNumber) {
    this._name = name;
    this._roomNumber = roomNumber;
  }

  // Використовуємо геттери і сеттери для опису інтерфейсу доступу до властивостей
  get name() {
    return this._name;
  }

  set name(value) {
    this._name = value;
  }
}

const mango = new Guest('Mango', 26);

// звернення до get і set не вимагає виклику - тобто без ()
console.log(mango.name); // Mango

mango.name = 'Mango the Fluffy';
console.log(mango.name); // Mango the Fluffy

Зверніть увагу - ім'я геттера і сеттера не може збігатися з ім'ям поля майбутнього примірника. Якщо в прикладі вище замінити this._name на this.name, то буде помилка.

5. Статичні властивості і методи

Можна створювати власні властивості класу і власні методи класу для виклику на ім'я класу, без створення об'єкта. Такі властивості й методи називають статичними. Для їх створення в класі перед властивістю або методом потрібно додати службове слово static.

Конструктор класу теж метод, але його не можна робити статичним, це викличе помилку.

// Клас зі статичними властивостями й методами
class Calc {
  // Клас-калькулятор для двох аргументів
  constructor() {}

  // Метод як заміна властивості
  static get PI() {
    return 3.14;
  }

  // Статичний метод +
  static add(...args) {
    return args.reduce((acc, next) => acc + next, 0);
  }

  // Статичний метод *
  static mult(...args) {
    return args.reduce((acc, next) => acc * next, 1);
  }
}

console.log(Calc.PI); // 3.14
console.log(Calc.add(2, 3, 4)); // 9
console.log(Calc.mult(12, 3, 4)); // 144

6. Спадкування

JavaScript дозволяє реалізувати спадкування класів. Це означає, що ми можемо створювати нові класи, які успадковують все від іншого класу, але при цьому додають унікальну інформацію для себе.

/*
 * Ключове слово extends вказує на батьківський клас,
 * чиї властивості будуть успадковані.
 */
class Child extends Parent {
  // ...
}

Створення базовий клас-батько Animal, від якого клас Dog буде успадковувати.

class Animal {
  constructor(name) {
    this.name = name;
  }

  move() {
    console.log(`I, ${this.name}, am moving!`);
  }
}

class Dog extends Animal {
  constructor(name, breed) {
    // Викликати конструктор Animal з аргументом name
    super(name);
    this.breed = breed;
  }

  bark() {
    console.log('woof!');
  }

  moveAndMakeSound() {
    super.move();
    this.bark();
  }
}

const dog = new Dog('Mango', 'shepherd');

dog.move(); // I, Mango, am moving!
dog.bark(); // woof!
dog.moveAndMakeSound(); // I, Mango, am moving! woof!

При спадкуванні через extends формується стандартний ланцюжок прототипів: методи Dog знаходяться в Dog.prototype, методи Animal в Animal.prototype, і вони пов'язані через __proto__.

Конструктор батька успадковується автоматично. Тобто, якщо в нащадку не вказано свій constructor, то використовується батьківський. Якщо ж у нащадка свій Constructor, то, щоб в ньому викликати конструктор батька, використовується метод Super() з аргументами для constructor батька.

  • Викликати конструктор батька можна тільки зсередини конструктора нащадка. Зокрема, super() не можна викликати з довільного методу.
  • У конструкторі нащадка ми зобов'язані викликати super() до першого звернення до ключового слова this. До виклику super () не існує this, через те, що по специфікації в цьому випадку саме super ініціалізує this.
  • super () можна викликати тільки в спадковому класі, інакше нічого не вийде.
  • При спадкуванні, виклик конструктора батька здійснюється через Super (... args), виклик батьківських методів через super.method (... args).
