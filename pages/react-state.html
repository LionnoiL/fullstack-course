1. Що таке стан

Стан (state) — це дані компонента, які змінюються з часом і впливають на те, що відображається. Коли стан змінюється, React перерендерює компонент.

Звичайна змінна для цього не підходить: її зміна не викликає перерендер, а після рендеру вона обнуляється. Тому стан зберігають через хук useState.

2. Хук useState

useState повертає масив із двох елементів: поточне значення і функцію для його оновлення.

import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0); // 0 — початкове значення

  return (
    <button onClick={() => setCount(count + 1)}>
      Натиснуто {count} разів
    </button>
  );
}

Ніколи не змінюйте стан напряму (count++ або state.x = 1). Тільки через функцію-сеттер — інакше React не побачить зміни й не перерендерить UI.

3. Оновлення на основі попереднього

Якщо нове значення залежить від попереднього, передавайте у сеттер функцію — це надійно за кількох оновлень поспіль.

setCount((prev) => prev + 1); // безпечно
setCount((prev) => prev + 1); // спрацюють обидва

4. Стан-обʼєкти та масиви

Стан треба оновлювати імутабельно — створювати нову копію, а не мутувати наявну. Тут стають у пригоді spread-оператори.

const [user, setUser] = useState({ name: 'Ada', age: 30 });
setUser((prev) => ({ ...prev, age: 31 })); // копія з новим age

const [items, setItems] = useState([]);
setItems((prev) => [...prev, 'новий']);    // додати елемент

5. Кілька незалежних станів

function Form() {
  const [name, setName] = useState('');
  const [agree, setAgree] = useState(false);
  // ... кожен стан керується окремо
}
