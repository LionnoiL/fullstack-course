1. Що таке HTML

HTML (HyperText Markup Language) — це мова розмітки, якою описують структуру вебсторінки: заголовки, абзаци, зображення, посилання. HTML не програмує логіку (це робить JavaScript) і не відповідає за вигляд (це CSS) — він задає зміст і його ієрархію.

2. Елементи й теги

Сторінка складається з елементів. Елемент зазвичай має відкривальний та закривальний теги, між якими — вміст. 

<p>Це абзац тексту.</p>
<h1>Це заголовок</h1>

Деякі елементи порожні (не мають вмісту) і пишуться одним тегом:

<img src="cat.png" alt="Кіт">
<br>
<hr>

3. Атрибути

Атрибути додають елементу додаткову інформацію і пишуться у відкривальному тезі у форматі ім'я="значення". 

<a href="https://example.com" target="_blank">Посилання</a>
<img src="logo.png" alt="Логотип" width="120">

4. Скелет документа

Будь-яка HTML-сторінка має стандартну структуру:

<!DOCTYPE html>
<html lang="uk">
  <head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Назва вкладки</title>
  </head>
  <body>
    <h1>Привіт, світ!</h1>
  </body>
</html>
  • <!DOCTYPE html> — оголошує сучасний стандарт HTML5;
  • <head> — службова інформація (кодування, назва, підключення стилів);
  • <body> — видимий вміст сторінки.

Атрибут lang і <meta charset="UTF-8"> важливі для коректного відображення української мови та роботи пошукових систем і читачів екрана.

5. Вкладеність елементів

Елементи вкладаються один в одного, утворюючи дерево. Важливо закривати теги у правильному порядку. 

<div>
  <h2>Заголовок</h2>
  <p>Текст із <strong>важливим</strong> словом.</p>
</div>
