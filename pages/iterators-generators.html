1. Протокол ітерації

Багато конструкцій JavaScript (for...of, spread ..., деструктуризація) працюють з будь-яким перебиральним (iterable) обʼєктом. Перебиральним є той, у кого є метод Symbol.iterator, що повертає ітератор — обʼєкт із методом next().

const arr = ['a', 'b'];
const it = arr[Symbol.iterator]();

it.next(); // { value: 'a', done: false }
it.next(); // { value: 'b', done: false }
it.next(); // { value: undefined, done: true }

Масиви, рядки, Map, Set вже перебиральні. Свій обʼєкт можна зробити таким, реалізувавши Symbol.iterator вручну (як у попередньому уроці про Symbol).

2. Генератори

Генератор — це особлива функція (позначена function*), виконання якої можна ставити на паузу й відновлювати. Кожен yield віддає значення і призупиняє функцію до наступного виклику next().

function* count() {
  yield 1;
  yield 2;
  yield 3;
}

const gen = count();
gen.next(); // { value: 1, done: false }
gen.next(); // { value: 2, done: false }

// Генератор одразу є перебиральним:
[...count()];          // [1, 2, 3]
for (const n of count()) console.log(n);

Генератор повертає обʼєкт, який одночасно є і ітератором, і перебиральним. Тому його зручно використовувати всюди, де очікується iterable — без ручної реалізації Symbol.iterator.

3. Ліниві та нескінченні послідовності

Оскільки генератор обчислює значення «на вимогу», ним можна описати потенційно нескінченну послідовність, не займаючи памʼять.

function* ids() {
  let id = 1;
  while (true) {
    yield id++;
  }
}

const nextId = ids();
nextId.next().value; // 1
nextId.next().value; // 2
nextId.next().value; // 3 ...

4. Делегування yield*

Конструкція yield* передає керування іншому генератору чи перебиральному обʼєкту — зручно для композиції.

function* letters() {
  yield 'a';
  yield 'b';
}

function* all() {
  yield* letters();  // віддає 'a', 'b'
  yield* [1, 2];     // потім 1, 2
}

[...all()]; // ['a', 'b', 1, 2]
