1. Що таке Tailwind CSS

Tailwind CSS — це utility-first CSS-фреймворк. Замість готових компонентів (як у Bootstrap) він дає велику бібліотеку маленьких класів-утиліт, кожен з яких відповідає за одну властивість: p-4 — це padding: 1rem, flex — це display: flex, text-center — це text-align: center. Дизайн ви збираєте прямо в розмітці, комбінуючи ці класи. 

<button class="px-4 py-2 rounded-lg bg-blue-600 text-white font-medium hover:bg-blue-700">
  Кнопка
</button>

2. Чим відрізняється від звичайного CSS і Bootstrap

  • vs звичайний CSS: не треба вигадувати назви класів і перемикатися між HTML і .css-файлом — стилі живуть поруч із розміткою.
  • vs Bootstrap: Bootstrap дає готові компоненти (кнопки, картки), і сайти виглядають схоже. Tailwind дає будівельні блоки — унікальний дизайн без боротьби з чужими стилями.

Tailwind не генерує «зайвого» CSS: під час збірки він сканує ваші файли й лишає у фінальному файлі лише ті класи, які ви реально використали. Тому продакшн-CSS зазвичай важить кілька кілобайтів. Приклади нижче — для актуальної версії 4.

3. Встановлення

Найпоширеніший спосіб — плагін для Vite:

npm install tailwindcss @tailwindcss/vite
// vite.config.js
import { defineConfig } from 'vite';
import tailwindcss from '@tailwindcss/vite';

export default defineConfig({
  plugins: [tailwindcss()],
});

Далі в головному CSS-файлі один рядок імпорту — і все:

/* src/style.css */
@import "tailwindcss";

4. Швидкий старт без збірки (CDN)

Щоб просто спробувати, підключіть браузерну версію — збірка не потрібна:

<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>

<div class="p-8 text-center">
  <h1 class="text-3xl font-bold text-blue-600">Привіт, Tailwind!</h1>
</div>

CDN зручний лише для експериментів і прототипів. Для реальних проєктів використовуйте збірку (Vite) — тоді Tailwind вирізає невикористані класи й дозволяє кастомізацію.

5. Коли брати, а коли ні

  • Плюси: швидка розробка, узгоджена шкала відступів/кольорів, малий фінальний CSS, легко робити адаптив і теми.
  • Мінуси: розмітка з довгим списком класів лякає спершу; потрібне розуміння базового CSS — Tailwind його не замінює, а лише пришвидшує.
