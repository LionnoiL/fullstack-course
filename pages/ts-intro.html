1. Що таке TypeScript

TypeScript — це надмножина (superset) JavaScript від Microsoft, яка додає статичну типізацію. Будь-який валідний JS-код є валідним TS-кодом, але TS дозволяє описувати типи даних і ловить помилки ще до запуску програми.

Браузер не розуміє TypeScript напряму — код спочатку компілюється (транспілюється) у звичайний JavaScript компілятором tsc. Типи існують лише на етапі розробки і повністю зникають зі скомпільованого коду.

2. Навіщо це потрібно

У чистому JS помилка типу проявляється лише під час виконання:

// JavaScript — помилки немає до запуску
function total(price, qty) {
  return price * qty;
}
total('10', 5); // '10' * 5 = 50, але це випадковість; total(10) -> NaN

У TypeScript таку помилку видно одразу в редакторі:

function total(price: number, qty: number): number {
  return price * qty;
}

total('10', 5); // ❌ Помилка: рядок не можна передати замість number
total(10);      // ❌ Помилка: очікувалось 2 аргументи

3. Переваги

  • помилки типів ловляться до запуску, а не в продакшені;
  • автодоповнення і підказки в редакторі стають набагато точнішими;
  • типи слугують живою документацією коду;
  • безпечний рефакторинг великих проєктів.

TypeScript не робить код швидшим під час виконання — після компіляції це звичайний JavaScript. Його цінність саме в процесі розробки: менше багів і впевненіший рефакторинг.
