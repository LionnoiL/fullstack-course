1. Controller — для кастомних полів

register працює з нативними <input>. Але UI-бібліотеки (напр. Radix Select чи компоненти shadcn/ui) не приймають ref напряму. Для них є Controller — обгортка, що зв'язує контрольований компонент із RHF.

import { useForm, Controller } from 'react-hook-form';

<Controller
  name="country"
  control={control}
  render={({ field }) => (
    <CustomSelect {...field} options={countries} />
  )}
/>

2. useFieldArray — динамічні поля

Коли кількість полів змінна (список телефонів, позиції замовлення), беруть useFieldArray.

import { useFieldArray, useForm } from 'react-hook-form';

const { control, register } = useForm({ defaultValues: { phones: [{ value: '' }] } });
const { fields, append, remove } = useFieldArray({ control, name: 'phones' });

{fields.map((field, i) => (
  <div key={field.id}>
    <input {...register(`phones.${i}.value`)} />
    <button type="button" onClick={() => remove(i)}>✕</button>
  </div>
))}
<button type="button" onClick={() => append({ value: '' })}>Додати</button>

Використовуй field.id (а не індекс) як key у списку полів. RHF генерує стабільні id, і це рятує від багів під час додавання/видалення рядків — так само, як правильні ключі списків у React.

3. watch — стежити за значеннями

watch дозволяє реагувати на поточні значення (напр. показати поле лише за умовою):

const { watch } = useForm();
const hasCompany = watch('hasCompany');

{hasCompany && <input {...register('companyName')} />}

4. reset і програмна зміна

const { reset, setValue, getValues } = useForm();

reset();                          // очистити форму
reset({ email: 'a@b.com' });      // задати нові значення
setValue('email', 'x@y.com');     // змінити одне поле
const values = getValues();       // прочитати без ре-рендеру
