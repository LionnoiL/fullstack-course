1. Що таке CSS-in-JS

CSS-in-JS — підхід, де стилі описуються прямо в JS/JSX, а не в окремих CSS-файлах. Бібліотека генерує унікальні класи й вставляє стилі в сторінку. Найвідоміші — styled-components та Emotion (API дуже схожі).

Мета та сама, що в CSS Modules — локальний scope — але досягається інакше: стилі живуть поряд із компонентом, у тому ж файлі, і можуть залежати від пропсів та стану засобами JS.

2. Встановлення й перший компонент

npm install styled-components

styled.button повертає React-компонент, який рендерить <button> із заданими стилями. Стилі пишуть у шаблонному рядку — це звичайний CSS.

import styled from 'styled-components';

const Button = styled.button`
  padding: 0.6rem 1.2rem;
  border: none;
  border-radius: 6px;
  background: #2563eb;
  color: #fff;
  cursor: pointer;

  &:hover { background: #1e40af; }   /* & — сам елемент, як у SCSS */
`;

export default function App() {
  return <Button>Натисни</Button>;
}

3. Стилі за пропсами

Головна перевага — стилі можуть читати пропси: передаєш функцію, що повертає значення залежно від пропа. Один компонент — різні варіанти без зайвих класів.

const Button = styled.button`
  padding: 0.6rem 1.2rem;
  border-radius: 6px;
  color: #fff;
  background: ${(props) => (props.$variant === 'danger' ? '#dc2626' : '#2563eb')};
  opacity: ${(props) => (props.disabled ? 0.5 : 1)};
`;

<Button $variant="danger">Видалити</Button>
<Button disabled>Зачекайте</Button>

Кастомні пропси лише для стилю префіксуй $ ($variant) — так styled-components не передасть їх у реальний DOM-атрибут. Звичайні (disabled) підуть і в стилі, і в елемент.

4. Теми через ThemeProvider

Обгортка ThemeProvider роздає обʼєкт теми всім стильованим компонентам — зручно для дизайн-системи (кольори, відступи в одному місці).

import { ThemeProvider } from 'styled-components';

const theme = { colors: { accent: '#2563eb' }, radius: '6px' };

const Button = styled.button`
  background: ${(p) => p.theme.colors.accent};
  border-radius: ${(p) => p.theme.radius};
`;

<ThemeProvider theme={theme}>
  <Button>OK</Button>
</ThemeProvider>

5. Плюси й мінуси

  • ➕ стилі й логіка поряд; динаміка за пропсами/станом; теми; немає окремих файлів;
  • ➕ автоматичний scope й видалення невикористаного;
  • ➖ рантайм-вартість — стилі генеруються в браузері під час роботи;
  • ➖ гірша сумісність із React Server Components (styled-components працює лише в клієнтських компонентах).

Саме про рантайм і сучасні zero-runtime рішення — наступний урок.
