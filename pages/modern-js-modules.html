1. Top-level await (ES2022)

Раніше await працював лише всередині async-функції. Тепер у модулях (ESM) можна писати await на верхньому рівні — без обгортки: 

// config.js — це ES-модуль
const res = await fetch('/api/config');
export const config = await res.json();
// інші модулі, що імпортують config, зачекають, поки він готовий

Працює лише в модулях (<script type="module">, файли ESM у Vite/Node). У звичайному скрипті — помилка. Памʼятай: top-level await затримує завантаження модулів, що його імпортують, тож не зловживай у критичному шляху.

2. Динамічний import()

Статичний import ... from завжди на початку файлу. Динамічний import() — це функція, що повертає проміс: модуль завантажується тоді, коли потрібен. Основа code splitting. 

button.addEventListener('click', async () => {
  // важкий модуль вантажимо лише при кліку
  const { Chart } = await import('./chart.js');
  new Chart(data);
});
// умовне завантаження
if (user.locale === 'uk') {
  const { messages } = await import('./locales/uk.js');
}

3. Навіщо: менший бандл

Динамічний імпорт дозволяє code splitting — не тягнути весь код одразу. Білдери (Vite/webpack) автоматично виносять динамічно імпортований модуль в окремий файл (chunk), який вантажиться на вимогу. Так початковий бандл лишається малим.

У React це роблять через React.lazy(() => import('./HeavyPage')) + Suspense — та сама ідея динамічного імпорту, загорнута під ліниве завантаження компонентів (див. розділ React).

4. import.meta

Модулі мають доступ до метаданих через import.meta — напр. до URL модуля або змінних оточення в Vite: 

import.meta.url;          // повний URL цього модуля
import.meta.env.MODE;     // 'development' / 'production' (Vite)
import.meta.env.VITE_API; // твоя env-змінна (Vite)

5. Іменовані та дефолтний експорти

// utils.js
export const sum = (a, b) => a + b;   // іменований
export default function App() {}       // дефолтний (один на модуль)

// main.js
import App, { sum } from './utils.js';       // дефолт + іменований
import { sum as add } from './utils.js';      // перейменування
import * as utils from './utils.js';          // усе одним обʼєктом
