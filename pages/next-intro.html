1. Що таке Next.js

Next.js — це фреймворк над React від компанії Vercel. Він додає до React те, чого тому бракує «з коробки»: роутинг, рендеринг на сервері, отримання даних, оптимізацію і збірку. Фактично це стандарт для повноцінних застосунків на React.

2. Що дає Next.js

  • файловий роутинг — сторінки визначаються структурою папок;
  • рендеринг на сервері (SSR) і статична генерація (SSG);
  • серверні компоненти — менше JavaScript у браузері;
  • Route Handlers — бекенд-ендпоінти в тому ж проєкті (фулстек);
  • вбудована оптимізація зображень, шрифтів, коду.

Чистий React рендериться лише в браузері (CSR). Next.js дозволяє рендерити сторінку ще на сервері — це швидший перший показ і краще SEO, бо пошуковик одразу бачить готовий HTML.

3. Створення проєкту

npx create-next-app@latest my-app
cd my-app
npm run dev   // http://localhost:3000

4. Структура (App Router)

Сучасний Next.js використовує App Router — папку app/, де кожна тека відповідає маршруту, а спеціальні файли — його частинам.

app/
├─ layout.jsx     // спільна оболонка
├─ page.jsx       // сторінка "/"
├─ about/
│  └─ page.jsx    // сторінка "/about"
└─ globals.css

5. Перша сторінка

// app/page.jsx
export default function HomePage() {
  return <h1>Привіт із Next.js!</h1>;
}
