1. Правила прямо в register

Найпростіша валідація задається другим аргументом register — об'єктом правил.

<input {...register('email', {
  required: 'Вкажіть email',
  pattern: { value: /^\S+@\S+$/, message: 'Некоректний email' },
})} />

<input type="password" {...register('password', {
  required: 'Введіть пароль',
  minLength: { value: 8, message: 'Мінімум 8 символів' },
})} />

2. Показ помилок

Повідомлення дістають з errors за ім'ям поля:

const { register, formState: { errors } } = useForm();

<input {...register('email', { required: 'Вкажіть email' })} />
{errors.email && <p className="error">{errors.email.message}</p>}

3. Доступні правила

  • required — обов'язкове поле;
  • min / max — межі числа;
  • minLength / maxLength — довжина рядка;
  • pattern — регулярний вираз (тема з розділу «Основи»);
  • validate — власна функція перевірки.
<input {...register('age', {
  validate: (v) => Number(v) >= 18 || 'Тільки 18+',
})} />

4. Коли перевіряти: mode

За замовчуванням валідація спрацьовує при сабміті. Опція mode змінює момент:

useForm({ mode: 'onBlur' });   // при втраті фокуса
useForm({ mode: 'onChange' }); // на кожну зміну

Вбудовані правила зручні для простих випадків. Але коли форма складна або ті самі правила потрібні й на бекенді, краще винести валідацію в схему Zod — одне джерело правди. Саме цим займемось далі.
