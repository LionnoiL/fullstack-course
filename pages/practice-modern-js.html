Практика: сучасний JavaScript

Виконуй у консолі браузера чи в Node (18+). Мета — закріпити сучасний синтаксис, Proxy/Reflect і патерни на маленьких прикладах.

Завдання 1. Незмінне сортування

Маючи масив чисел, поверни новий відсортований за спаданням масив, не змінюючи оригінал. Виведи оригінал і результат — переконайся, що оригінал недоторканий. Використай toSorted.

Рішення 
const nums = [3, 1, 4, 1, 5];
const desc = nums.toSorted((a, b) => b - a); // [5, 4, 3, 1, 1]
console.log(nums); // [3, 1, 4, 1, 5] — не змінено

Завдання 2. Групування замовлень

Маючи масив замовлень { id, status }, згрупуй їх за status через Object.groupBy і виведи, скільки замовлень у кожному статусі.

Рішення 
const orders = [
  { id: 1, status: 'new' }, { id: 2, status: 'paid' }, { id: 3, status: 'new' },
];
const byStatus = Object.groupBy(orders, (o) => o.status);
for (const [status, list] of Object.entries(byStatus)) {
  console.log(status, list.length);
} // new 2 · paid 1

Завдання 3. Глибока копія стану

Створи обʼєкт стану з вкладеним обʼєктом і Date. Зроби його глибоку копію через structuredClone, зміни поле в копії й переконайся, що оригінал не змінився, а Date лишився обʼєктом Date.

Підказка

JSON.parse(JSON.stringify(...)) тут не підійде — зіпсує Date. Саме тому беремо structuredClone.

Завдання 4. Значення за замовчуванням

Напиши функцію withDefaults(opts), що через логічне присвоєння (??=) підставляє opts.timeout ??= 3000 і opts.retries ??= 0. Перевір, що передане retries: 0 не перезаписується (на відміну від ||=).

Рішення 
function withDefaults(opts = {}) {
  opts.timeout ??= 3000;
  opts.retries ??= 0;
  return opts;
}
withDefaults({ retries: 0 }); // { retries: 0, timeout: 3000 } — 0 збережено

Завдання 5. Проксі з валідацією

Обгорни обʼєкт user у Proxy, що забороняє записувати в age не-число (кидає TypeError), а решту записів пропускає через Reflect.set. Перевір коректний і некоректний запис.

Рішення 
const user = new Proxy({ name: 'Аня', age: 30 }, {
  set(obj, prop, value, receiver) {
    if (prop === 'age' && typeof value !== 'number') {
      throw new TypeError('age має бути числом');
    }
    return Reflect.set(obj, prop, value, receiver);
  },
});
user.age = 31;      // ок
user.age = 'ой';    // TypeError

Завдання 6. Event bus (Observer) — виклик

Реалізуй маленький EventBus з методами on(event, fn) та emit(event, data). Підпишись на подію message двома слухачами й переконайся, що emit викликає обох. За бажання додай off для відписки.

Спробуй свідомо застосувати ці інструменти у своєму коді: незмінні методи масивів у React-стані, structuredClone для копій, словник функцій замість switch (Strategy), EventBus для звʼязку модулів.
