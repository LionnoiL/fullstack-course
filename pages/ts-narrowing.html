1. Обʼєднання типів (union)

Обʼєднання (|) означає, що значення може бути одного з кількох типів.

function printId(id: number | string) {
  console.log('ID:', id);
}

printId(101);
printId('abc');
printId(true); // ❌ boolean не входить в обʼєднання

2. Перетин типів (intersection)

Перетин (&) обʼєднує кілька типів в один, що має усі їхні поля.

type Name = { name: string };
type Age = { age: number };

type Person = Name & Age;

const p: Person = { name: 'Ada', age: 30 }; // обовʼязкові обидва поля

3. Звуження типів (narrowing)

Якщо значення має обʼєднаний тип, перед використанням специфічних методів TS вимагає звузити тип. Найпростіший спосіб — перевірка typeof.

function format(value: number | string): string {
  if (typeof value === 'number') {
    return value.toFixed(2); // тут value гарантовано number
  }
  return value.trim();       // а тут — string
}

Інші прийоми звуження: Array.isArray(), instanceof, перевірка на in, порівняння з null.

function area(shape: { radius: number } | { side: number }): number {
  if ('radius' in shape) {
    return Math.PI * shape.radius ** 2;
  }
  return shape.side ** 2;
}

4. Захисники типів (type guards)

Власна функція-предикат із x is Type навчає компілятор звужувати тип.

interface Cat { meow(): void; }
interface Dog { bark(): void; }

function isCat(pet: Cat | Dog): pet is Cat {
  return 'meow' in pet;
}

function speak(pet: Cat | Dog) {
  if (isCat(pet)) {
    pet.meow(); // TS знає, що це Cat
  } else {
    pet.bark();
  }
}

5. Розрізнювані обʼєднання

Спільне поле-«тег» дозволяє зручно розрізняти варіанти в switch.

type Shape =
  | { kind: 'circle'; radius: number }
  | { kind: 'square'; side: number };

function area(s: Shape): number {
  switch (s.kind) {
    case 'circle': return Math.PI * s.radius ** 2;
    case 'square': return s.side ** 2;
  }
}

Розрізнювані обʼєднання (discriminated unions) — один із найпотужніших патернів TypeScript. Вони роблять неможливі стани недосяжними ще на рівні типів.
