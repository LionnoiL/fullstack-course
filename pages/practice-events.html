Завдання 1. Делегування подій

У списку задач додай один обробник на контейнер, який видаляє <li> при кліку по кнопці «×» усередині нього.

Підказка

Слухай click на ul, перевіряй event.target та шукай closest('li').

Рішення 
const list = document.querySelector('#todos');

list.addEventListener('click', (event) => {
  if (event.target.classList.contains('remove')) {
    event.target.closest('li').remove();
  }
});

Завдання 2. Живий пошук із debounce

Фільтруй список під час введення в поле пошуку, але виконуй фільтрацію не частіше ніж раз на 300 мс.

Рішення 
function debounce(fn, delay) {
  let timer;
  return (...args) => {
    clearTimeout(timer);
    timer = setTimeout(() => fn(...args), delay);
  };
}

const input = document.querySelector('#search');
input.addEventListener('input', debounce((e) => {
  const q = e.target.value.toLowerCase();
  // ...фільтрація списку за q
}, 300));
