Мілстоун 2: застосунок задач (To-Do)

Етап: після розділів «Масиви», «DOM», «Події та браузер», «Дані». Мета — інтерактивний застосунок на чистому JavaScript, що зберігає дані в браузері.

Функціонал

  • додавання задачі з поля вводу;
  • позначення задачі виконаною (закреслення);
  • видалення задачі;
  • фільтри: усі / активні / виконані;
  • лічильник активних задач;
  • збереження в localStorage (дані не зникають після перезавантаження).

Вимоги

  • дані задач — у масиві об'єктів ({ id, text, done });
  • рендер списку з масиву; оновлення DOM після кожної зміни;
  • делегування подій замість обробника на кожній кнопці;
  • збереження/відновлення стану через JSON + localStorage;
  • чиста структура: окремо дані, окремо рендер, окремо обробники.

Орієнтовна структура коду

let todos = load();               // з localStorage

function save() { localStorage.setItem('todos', JSON.stringify(todos)); }
function load() { return JSON.parse(localStorage.getItem('todos')) || []; }

function render() { /* перемалювати список за поточним фільтром */ }

function addTodo(text) {
  todos.push({ id: Date.now(), text, done: false });
  save();
  render();
}

// делегування: один обробник на список
list.addEventListener('click', (e) => { /* toggle / remove за data-id */ });

Тримай «джерело істини» в масиві todos, а DOM завжди перемальовуй з нього. Не намагайся точково правити і DOM, і масив — це швидко розсинхронізується.

Розвиток проєкту
