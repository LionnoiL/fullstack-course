1. Хук useForm

Центральний хук — useForm. Він повертає інструменти для роботи з формою: register (підключити поле), handleSubmit (обробити відправлення), formState (стан, зокрема помилки). 

import { useForm } from 'react-hook-form';

function LoginForm() {
  const { register, handleSubmit, formState: { errors } } = useForm();

  const onSubmit = (data) => console.log(data); // { email, password }

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register('email')} />
      <input type="password" {...register('password')} />
      <button>Увійти</button>
    </form>
  );
}

2. register — підключення поля

register('ім'я') повертає потрібні пропси (name, ref, onChange, onBlur), які розгортають у поле через spread. Ім'я стає ключем у даних форми. 

<input {...register('email')} />
// вкладені імена → вкладений об'єкт
<input {...register('address.city')} /> // data.address.city

3. handleSubmit

handleSubmit обгортає твій обробник: спершу валідує форму, і лише якщо все гаразд — викликає onSubmit з зібраними даними. Другим аргументом можна передати обробник помилок. 

<form onSubmit={handleSubmit(onValid, onInvalid)}>

4. Початкові значення

const { register } = useForm({
  defaultValues: { email: '', remember: true },
});

5. Корисне з formState

  • errors — об'єкт помилок по полях;
  • isSubmitting — форма відправляється (блокуй кнопку);
  • isValid — чи валідна форма зараз;
  • isDirty — чи змінював користувач значення.
const { formState: { isSubmitting } } = useForm();
<button disabled={isSubmitting}>Зберегти</button>

Не обгортай поля RHF у власні useState — це зруйнує головну перевагу (мінімум ре-рендерів). Дай RHF керувати значеннями, а читай їх у onSubmit або через watch.
