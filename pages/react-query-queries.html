1. Хук useQuery

Читання даних — це useQuery. Він приймає два ключові поля: queryKey (унікальний ключ для кешу) і queryFn (функція, що повертає проміс із даними). 

import { useQuery } from '@tanstack/react-query';

function Todos() {
  const { data, isPending, isError, error } = useQuery({
    queryKey: ['todos'],
    queryFn: () => fetch('/api/todos').then((r) => r.json()),
  });

  if (isPending) return <p>Завантаження…</p>;
  if (isError)   return <p>Помилка: {error.message}</p>;

  return <ul>{data.map((t) => <li key={t.id}>{t.title}</li>)}</ul>;
}

2. Стани запиту

  • isPending — даних ще немає (перше завантаження);
  • isError + error — запит впав;
  • data — успішно отримані дані;
  • isFetching — запит виконується зараз (зокрема фонове оновлення при вже наявних data).

Розрізняй isPending і isFetching: isPending — «даних ще немає взагалі», isFetching — «йде мережевий запит» (може бути true навіть коли data вже показані — під час фонового оновлення).

3. Ключ запиту (queryKey)

Ключ — це масив, що однозначно ідентифікує дані. Якщо запит залежить від параметра, параметр входить у ключ — при його зміні дані перезавантажаться автоматично. 

function Todo({ id }) {
  const { data } = useQuery({
    queryKey: ['todo', id],                 // id — частина ключа
    queryFn: () => fetchTodo(id),
  });
  // зміниться id → новий ключ → новий запит (старий лишиться в кеші)
}

4. Умовний запит (enabled)

Запит можна відкласти, поки не готові дані для нього — через опцію enabled: 

const { data } = useQuery({
  queryKey: ['user', userId],
  queryFn: () => fetchUser(userId),
  enabled: !!userId,   // не робити запит, поки немає userId
});

5. Перетворення даних (select)

const { data: titles } = useQuery({
  queryKey: ['todos'],
  queryFn: fetchTodos,
  select: (todos) => todos.map((t) => t.title), // тільки заголовки
});
