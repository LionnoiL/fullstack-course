1. Що таке Web APIs

Web APIs — це вбудовані можливості браузера, доступні з JavaScript, окрім самої мови. DOM, fetch, localStorage, IntersectionObserver — усе це Web APIs, і ти вже ними користувався. У цьому розділі — потужніша частина: фонові потоки, локальні бази, офлайн, власні HTML-теги, форматування під локаль, малювання.

2. Що розберемо

  • Web Workers — важкі обчислення в окремому потоці, щоб не «вішати» UI;
  • IndexedDB — повноцінна база даних у браузері (більше за localStorage);
  • Service Workers + PWA — офлайн, кешування, встановлення застосунку;
  • Web Components — власні перевикористовувані елементи з ізоляцією стилів;
  • Intl — форматування дат, чисел і валют під мову/регіон.

3. Як перевіряти підтримку

Не всі API є всюди. Перевіряй наявність перед використанням (feature detection) і давай запасний варіант:

if ('serviceWorker' in navigator) {
  // Service Worker підтримується
}
if (window.Worker) {
  // Web Workers доступні
}
// сумісність зручно дивитися на caniuse.com

Принцип progressive enhancement: базова функція працює скрізь, а сучасні API додають покращення там, де вони є. Ніколи не покладайся на API «наосліп».

4. Приклад: Canvas — малювання

Canvas API дає полотно для програмного малювання — графіки, ігри, візуалізації, обробка зображень. Малюєш через 2D-контекст:

<canvas id="c" width="300" height="150"></canvas>

const ctx = document.querySelector('#c').getContext('2d');

ctx.fillStyle = '#2563eb';
ctx.fillRect(20, 20, 100, 60);        // прямокутник

ctx.beginPath();
ctx.arc(200, 80, 40, 0, Math.PI * 2); // коло
ctx.fillStyle = '#16a34a';
ctx.fill();

ctx.font = '16px sans-serif';
ctx.fillStyle = '#000';
ctx.fillText('Привіт, Canvas', 20, 120);

Canvas — растровий (пікселі): швидкий для багатьох обʼєктів (ігри, частинки), але без DOM-вузлів. Для векторних інтерактивних діаграм часто беруть SVG. Обирай за задачею.

5. Куди далі

Кожному з ключових API присвячено окремий урок. Почнемо з Web Workers — як винести важку роботу з головного потоку.
