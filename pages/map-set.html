1. Сучасні колекції

Крім масивів і звичайних обʼєктів, JavaScript має спеціалізовані колекції: Map та Set. Вони зʼявилися в ES6 і часто зручніші й швидші за обʼєкт для задач «ключ → значення» та «набір унікальних елементів».

2. Map — словник ключ/значення

Map зберігає пари «ключ → значення». На відміну від обʼєкта, ключем може бути будь-який тип (навіть обʼєкт чи функція), а порядок вставки гарантовано зберігається.

const users = new Map();

users.set('id42', { name: 'Ada' });
users.set(1, 'число як ключ');

users.get('id42');     // { name: 'Ada' }
users.has(1);          // true
users.size;            // 2
users.delete(1);       // видалити пару
users.clear();         // очистити повністю

Map легко перебирається і зберігає порядок:

const scores = new Map([
  ['math', 90],
  ['js', 100],
]);

for (const [subject, score] of scores) {
  console.log(subject, score);
}

[...scores.keys()];   // ['math', 'js']
[...scores.values()]; // [90, 100]

Обирайте Map замість обʼєкта, коли ключі динамічні, їх багато, або потрібні ключі-не-рядки. Обʼєкт залишається кращим для фіксованої структури з відомими полями.

3. Set — набір унікальних значень

Set зберігає лише унікальні значення. Повторні додавання ігноруються.

const tags = new Set();

tags.add('js');
tags.add('css');
tags.add('js');   // дублікат — проігноровано

tags.has('css');  // true
tags.size;        // 2

Класичний прийом — прибрати дублікати з масиву:

const nums = [1, 2, 2, 3, 3, 3];
const unique = [...new Set(nums)]; // [1, 2, 3]

4. WeakMap і WeakSet

«Слабкі» колекції зберігають лише обʼєкти як ключі і не заважають збиранню сміття: якщо на обʼєкт-ключ більше немає посилань, він разом із записом видаляється з памʼяті автоматично.

const cache = new WeakMap();

let node = document.querySelector('#box');
cache.set(node, { clicks: 0 });

// коли node видалять і посилання зникне —
// запис у cache очиститься сам собою

Обмеження: WeakMap/WeakSet не мають size і їх не можна перебрати — вони призначені лише для приватного зберігання даних, привʼязаних до обʼєкта.

5. Коротке порівняння

  • Object — структура з відомими рядковими ключами;
  • Map — динамічний словник, ключі будь-якого типу, збережений порядок;
  • Set — набір унікальних значень;
  • WeakMap/WeakSet — приватні дані на обʼєкти, дружні до збирача сміття.
