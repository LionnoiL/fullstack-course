1. Що таке Zod

Zod — бібліотека для опису й перевірки форми даних через схеми. Ти описуєш, якими мають бути дані, а Zod перевіряє реальні значення й повертає або результат, або зрозумілі помилки. Бонус — з однієї схеми виводиться TypeScript-тип. 

npm install zod

2. Опис схеми

import { z } from 'zod';

const userSchema = z.object({
  name: z.string().min(2, 'Мінімум 2 символи'),
  email: z.string().email('Некоректний email'),
  age: z.number().int().min(18, 'Тільки 18+'),
  role: z.enum(['user', 'admin']),
  website: z.string().url().optional(),
});

3. Перевірка: parse і safeParse

parse кидає виняток при помилці, а safeParse повертає результат-об'єкт — зручніше для форм. 

const result = userSchema.safeParse(data);

if (result.success) {
  console.log(result.data);   // валідні, типізовані дані
} else {
  console.log(result.error.issues); // список помилок по полях
}

4. Тип зі схеми: z.infer

Не треба окремо писати тип — Zod виведе його зі схеми. Одне джерело правди для перевірки й типів. 

type User = z.infer<typeof userSchema>;
// { name: string; email: string; age: number;
//   role: 'user' | 'admin'; website?: string }

Схема — одне джерело правди: змінив правило (напр. мінімальну довжину) в одному місці — і оновилися і валідація, і тип. Ту саму схему можна використати й на бекенді, щоб перевіряти вхідні дані запиту.

5. Уточнення й трансформації

// перевірка кількох полів разом
const schema = z.object({
  password: z.string().min(8),
  confirm: z.string(),
}).refine((d) => d.password === d.confirm, {
  message: 'Паролі не збігаються',
  path: ['confirm'],
});

// перетворення значення
z.string().trim().toLowerCase();
z.coerce.number(); // "42" → 42
