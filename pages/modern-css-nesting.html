1. Вкладеність без препроцесора

Тепер селектори можна вкладати прямо в CSS — так само, як у Sass, але без збірки.

.card {
  padding: 1rem;

  .title {
    font-size: 1.25rem;
    font-weight: bold;
  }

  p { color: #6b7280; }
}

2. Батьківський селектор &

Символ & посилається на батьківський селектор — зручно для псевдокласів і модифікаторів. 

.button {
  background: #2563eb;

  &:hover { background: #1e40af; }
  &:disabled { opacity: .5; }

  &.is-active { outline: 2px solid; }
}

Відмінність від Sass: у нативному CSS & потрібен частіше. Наприклад, для вкладеного типового селектора (p, a) браузер розуміє його й без &, але для конкатенації (&.is-active, &:hover) & обов'язковий.

3. Вкладені медіа- та container-запити

Медіазапити теж можна вкладати всередину правила — стилі елемента лишаються поруч:

.grid {
  display: grid;
  grid-template-columns: 1fr;

  @media (min-width: 768px) {
    grid-template-columns: 1fr 1fr;
  }
}

4. Не переборщити з глибиною

Як і в Sass, глибока вкладеність (4+ рівнів) породжує довгі специфічні селектори, які важко перевизначати. Тримайся 2–3 рівнів. 

/* ❌ занадто глибоко */
.a { .b { .c { .d { color: red; } } } }

5. Тоді навіщо Sass?

Вкладеність і змінні (--x) тепер є в CSS. Sass лишається корисним для складнішої логіки: міксини з параметрами, цикли, функції, партіали @use — цього нативний CSS поки не має.
