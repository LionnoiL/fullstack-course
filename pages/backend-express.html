1. Що таке Express

Express — мінімалістичний вебфреймворк для Node.js. Він спрощує створення маршрутів, обробку запитів і відповідей, підключення проміжного ПЗ.

npm init -y
npm install express

2. Перший сервер

const express = require('express');
const app = express();

app.get('/', (req, res) => {
  res.send('Привіт із Express!');
});

app.listen(3000, () => {
  console.log('Сервер на http://localhost:3000');
});

3. Маршрути (routes)

Маршрут — це поєднання HTTP-методу і шляху. Express має методи під кожен дієслово.

app.get('/users', (req, res) => { /* отримати список */ });
app.post('/users', (req, res) => { /* створити */ });
app.put('/users/:id', (req, res) => { /* оновити */ });
app.delete('/users/:id', (req, res) => { /* видалити */ });

4. Параметри та запити

// параметр шляху: /users/42
app.get('/users/:id', (req, res) => {
  res.json({ id: req.params.id });
});

// query-параметри: /search?q=js&page=2
app.get('/search', (req, res) => {
  const { q, page } = req.query;
  res.json({ q, page });
});

5. Формування відповіді

res.send('текст');            // текст або HTML
res.json({ ok: true });       // JSON
res.status(404).json({ error: 'Не знайдено' }); // код статусу
res.redirect('/login');       // перенаправлення

Щоб сервер сам перезапускався при зміні коду, встановіть nodemon (npm i -D nodemon) і запускайте npx nodemon server.js.
