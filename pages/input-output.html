1. Вступ

Розберемо базові операції введення/виводу, достатні для отримання і відображення даних від користувача, до того як навчимося працювати з HTML-документом.

2. Висновок даних

Для виведення даних будемо використовувати 2 методи: console.log() і alert().

console і alert є частиною інтерфейсу window - глобального об'єкта, доступного при виконанні скрипта на веб-сторінці. Запис window.alert() надлишкова, пишемо просто alert() або console.log(). Детальніше про це будемо говорити далі в курсі.

const message = 'JavaScript is awesome!';
/*
 * В круглих дужках вказуємо ім'я змінної,
 * Значення якої необхідно вивести в консоль
 */
console.log(message); // JavaScript is awesome!

const name = 'Mango';
/*
 * Можна спочатку вказати якийсь довільний рядок,
 * наприклад описує змінну або доповнює її, після чого
 * поставити кому і вказати ім'я змінної
 */
console.log('My name is: ', name); // My name is: Mango

/*
 * alert виводить модальне вікно, текст якого відповідає значенням
 * змінної (або літерала) яку ми вкажемо в дужках.
 */
alert(message);

3. Отримання даних

Для отримання даних від користувача використовуватимемо prompt() і confirm(), це теж методи з інтерфейсу window. Їх особливість в тому, що результатом свого виконання вони повертають те, що було введено користувачем. Результат їхньої роботи можна записати в змінну для подальшого використання.

confirm() — виводить модальне вікно з повідомленням, і 2 кнопки, Ok і Cancel. При натисканні на Ok, на місце виклику функції повертається true, при натисканні на Cancel повертається false.

/*
 * Просимо клієнта підтвердити бронь на готель
 * і зберігаємо в змінну результат роботи confirm
 */
const isComing = confirm('Please confirm hotel reservation');
console.log(isComing);

prompt() — виводить модальне вікно з полем введення і кнопками Ok і Cancel. При Ok повертає те, що було введено в поле введення, при Cancel повертає null.

/*
 * Запитуємо ім'я готелю в якому хотів би зупиниться клієнт
 * і зберігаємо в змінну результат виклику prompt
 */
const hotelName = prompt('Please enter desired hotel name:');
console.log(hotelName);

/*
 * Важлива особливість prompt в тому, що не залежно що ввів користувач,
 * завжди повернеться рядок. Тобто якщо користувач ввів 5, то повернеться
 * не число 5, а рядок "5". Про це необхідно завжди пам'ятати.
 */
const value = prompt('Please enter a number!');
console.log(typeof value); // 'string'
console.log(value); // '5'
