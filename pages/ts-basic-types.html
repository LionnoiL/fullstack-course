1. Анотації типів

Тип змінної вказують після двокрапки. Якщо тип очевидний зі значення, TypeScript виведе його сам (type inference) — анотацію можна не писати.

let name: string = 'Ada';
let age: number = 30;
let isAdmin: boolean = false;

let city = 'Kyiv'; // тип string виведено автоматично

2. Прості типи

let a: number = 42;        // усі числа (цілі, дробові)
let b: string = 'текст';
let c: boolean = true;
let d: null = null;
let e: undefined = undefined;
let big: bigint = 10n;
let sym: symbol = Symbol('id');

3. Масиви та кортежі

let nums: number[] = [1, 2, 3];
let names: string[] = ['a', 'b'];
let matrix: number[][] = [[1, 2], [3, 4]];

// Кортеж — масив фіксованої довжини з відомими типами
let pair: [string, number] = ['age', 30];

4. any, unknown, void, never

  • any — вимикає перевірку типів (уникайте його);
  • unknown — «щось невідоме», але безпечне: перед використанням треба перевірити тип;
  • void — функція нічого не повертає;
  • never — функція ніколи не завершується нормально (кидає помилку або нескінченна).
let risky: any = 5;
risky.foo.bar; // помилки немає — але це небезпечно

let value: unknown = getData();
// value.trim(); // ❌ спершу треба звузити тип
if (typeof value === 'string') {
  value.trim(); // ✅ тут TS знає, що це string
}

function fail(msg: string): never {
  throw new Error(msg);
}

any фактично «вимикає» TypeScript для значення і повертає всі проблеми чистого JS. Якщо тип справді невідомий — беріть unknown: він змусить вас перевірити тип перед використанням.

5. Літеральні типи

Типом може бути конкретне значення. У поєднанні з обʼєднанням (|) це дає зручні переліки допустимих значень.

let direction: 'left' | 'right' | 'up' | 'down';
direction = 'left';  // ✅
direction = 'top';   // ❌ такого значення немає в списку
