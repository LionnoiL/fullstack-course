1. Хук useMutation

Якщо useQuery — для читання, то useMutation — для змін (створення, оновлення, видалення). Він не виконується сам: ти запускаєш його викликом mutate. 

import { useMutation } from '@tanstack/react-query';

function AddTodo() {
  const mutation = useMutation({
    mutationFn: (title) =>
      fetch('/api/todos', {
        method: 'POST',
        body: JSON.stringify({ title }),
      }).then((r) => r.json()),
  });

  return (
    <button onClick={() => mutation.mutate('Нова задача')}>
      Додати
    </button>
  );
}

2. Стани мутації

  • isPending — запит виконується (зручно блокувати кнопку);
  • isError / error — не вдалося;
  • isSuccess / data — успіх і відповідь сервера.
<button disabled={mutation.isPending} onClick={() => mutation.mutate('X')}>
  {mutation.isPending ? 'Зберігаю…' : 'Додати'}
</button>

3. Колбеки життєвого циклу

useMutation({
  mutationFn: addTodo,
  onSuccess: (data) => { /* після успіху */ },
  onError:   (err)  => { /* після помилки */ },
  onSettled: ()     => { /* у будь-якому разі */ },
});

4. Оновлення даних після мутації

Найважливіше: після зміни даних треба оновити відповідні запити. Для цього беруть queryClient і інвалідують ключ — TanStack Query перезавантажить ці дані. 

import { useMutation, useQueryClient } from '@tanstack/react-query';

const queryClient = useQueryClient();

const mutation = useMutation({
  mutationFn: addTodo,
  onSuccess: () => {
    // список ['todos'] застарів → перечитати з сервера
    queryClient.invalidateQueries({ queryKey: ['todos'] });
  },
});

Схема «змінив → інвалідував ключ» — 90% роботи з мутаціями. Не оновлюй локальні useState вручну після запиту: хай джерелом правди лишається кеш TanStack Query, а UI перемалюється сам після інвалідації.

5. mutateAsync

Якщо потрібно дочекатися результату (напр. закрити форму лише після успіху) — є проміс-версія mutateAsync: 

async function handleSubmit() {
  try {
    await mutation.mutateAsync(title);
    closeModal();
  } catch (e) {
    // помилку вже обробить onError; тут — за потреби
  }
}
