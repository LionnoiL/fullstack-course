1. Що таке Redux і Redux Toolkit

Redux — передбачуване сховище зі суворим потоком даних. Redux Toolkit (RTK) — офіційний, сучасний спосіб писати Redux: він прибирає більшість бойлерплейту старого Redux. Сьогодні «писати Redux» означає «писати RTK».

2. Односпрямований потік даних

Дані течуть в один бік, і це робить зміни передбачуваними:

компонент → dispatch(action) → reducer → новий state → компонент
  • store — єдине сховище всього стану;
  • action — об'єкт-опис того, «що сталося» ({ type, payload });
  • reducer — чиста функція (state, action) → новий state;
  • dispatch — спосіб надіслати action у стор.

Редюсер має бути чистою функцією (тема з розділу «Функції»): жодних запитів, випадковості чи мутацій ззовні — лише обчислення нового стану зі старого та action. Це те, що дає Redux передбачуваність і чудові devtools.

3. «Мутації» завдяки Immer

Класичний Redux вимагав повертати нові об'єкти вручну (spread на кожному рівні). RTK вбудовує Immer, тож усередині редюсера можна писати наче «мутуючий» код — насправді Immer створює новий незмінний стан. 

// виглядає як мутація, але стан лишається immutable
increment: (state) => {
  state.count += 1;
}

4. Встановлення

npm install @reduxjs/toolkit react-redux
  • @reduxjs/toolkit — сам RTK (стор, слайси, тунки);
  • react-redux — прив'язка до React (Provider, хуки).

5. Коли обирати Redux Toolkit

  • великий застосунок зі складним спільним станом;
  • потрібні суворі патерни й передбачуваність у великій команді;
  • цінні потужні DevTools (time-travel, інспекція кожного action).
