1. Готові компоненти

Bootstrap дає десятки готових UI-блоків. Розглянемо найпоширеніші — їх достатньо для більшості інтерфейсів.

2. Кнопки та бейджі

<button class="btn btn-primary">Основна</button>
<button class="btn btn-outline-secondary">Контурна</button>
<button class="btn btn-danger btn-sm">Маленька</button>

<span class="badge bg-success">Новий</span>
<button class="btn btn-primary">
  Повідомлення <span class="badge bg-light text-dark">4</span>
</button>

3. Сповіщення (alerts)

<div class="alert alert-success" role="alert">Успішно збережено!</div>
<div class="alert alert-danger" role="alert">Сталася помилка</div>

4. Картки (cards)

<div class="card" style="width: 18rem;">
  <img src="cover.jpg" class="card-img-top" alt="...">
  <div class="card-body">
    <h5 class="card-title">Заголовок</h5>
    <p class="card-text">Короткий опис картки.</p>
    <a href="#" class="btn btn-primary">Детальніше</a>
  </div>
</div>

5. Навігаційна панель (navbar)

<nav class="navbar navbar-expand-lg bg-light">
  <div class="container-fluid">
    <a class="navbar-brand" href="#">Логотип</a>
    <div class="navbar-nav">
      <a class="nav-link active" href="#">Головна</a>
      <a class="nav-link" href="#">Про нас</a>
    </div>
  </div>
</nav>

6. Список-група

<ul class="list-group">
  <li class="list-group-item active">Активний</li>
  <li class="list-group-item">Другий</li>
  <li class="list-group-item">Третій</li>
</ul>

Компоненти зручно поєднувати із сіткою та утилітами: напр., сітка карток — це row з col, у кожній — card.
