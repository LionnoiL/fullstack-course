1. Рендеринг списків

Щоб відобразити масив даних, його перетворюють на масив елементів методом map. React відрендерить кожен елемент. 

function TodoList() {
  const todos = ['Купити хліб', 'Прочитати книгу', 'Написати код'];

  return (
    <ul>
      {todos.map((todo, index) => (
        <li key={index}>{todo}</li>
      ))}
    </ul>
  );
}

2. Атрибут key

Кожен елемент списку має унікальний key — він допомагає React відстежувати, що змінилось. Найкраще брати стабільний ідентифікатор із даних, а не індекс. 

const users = [
  { id: 1, name: 'Ada' },
  { id: 2, name: 'Grace' },
];

<ul>
  {users.map((user) => (
    <li key={user.id}>{user.name}</li>
  ))}
</ul>;

Індекс як key прийнятний лише для статичних списків. Якщо елементи додаються, видаляються чи сортуються — індекс призведе до багів рендеру. Використовуйте унікальний id.

3. Умовний рендеринг

Оскільки JSX — це вирази, для умов використовують тернарний оператор або &&. 

function Status({ isOnline }) {
  return (
    <div>
      {isOnline ? <span>В мережі</span> : <span>Офлайн</span>}
    </div>
  );
}

4. Рендер за умовою через &&

Коли треба показати щось лише за умовою (без «інакше»), зручний оператор &&. 

function Cart({ items }) {
  return (
    <div>
      <h2>Кошик</h2>
      {items.length > 0 && <p>Товарів: {items.length}</p>}
      {items.length === 0 && <p>Кошик порожній</p>}
    </div>
  );
}

Обережно з && і числами: {items.length && ...} при довжині 0 відрендерить сам 0 на сторінці. Тому краще писати явну умову items.length > 0 && ....
