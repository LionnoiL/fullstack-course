1. Вступ

Коли ми говоримо про програмування, перше що приходить в голову це набір інструкцій у файлі - вихідний код.

Вихідний код (source code) — набір фраз, слів, спеціальних символів і т. д., специфічних для мови програмування, що описують набір інструкцій для комп'ютера.

Але символи, слова і фрази, які складають програму, насправді незрозумілі для машини. Є крок, що виконується після написання програми, який конвертує вихідний код в файлі в набір інструкцій зрозумілих комп'ютера. Цим займається спеціальна програма: компилятор або интерпретатор.

Звідси можна зробити висновок - код пишеться не для машини, а для розробника. Вихідний код повинен не тільки вірно вирішувати завдання, а й мати сенс, бути зрозумілим і легко читаним. Це одна з найскладніших завдань для початківців (і не тільки), на її рішення піде багато часу і сил.

2. Логічне мислення

У світі існує багато (сотні) мов програмування. Насправді, вони не такі складні, як людські, тому що складаються з доволно маленького набору синтаксичних конструкцій, а їх принцип роботи та базові концепції схожі між різними мовами.

Досвідчені розробники розглядають проблеми з точки зору алгоритмів - набору кроків, які потрібно виконати для досягнення певної мети, навіть якщо деталі міняються.

Ми постійно використовуємо алгоритми в повсякденному житті. Наприклад процес приготування чаю це набір необхідних кроків (алгоритм) для досягнення результату. Коли ви звикнете вибудовувати рішення задачі у вигляді алгоритму, мова програмування буде всього лише інструментом.

3. JavaScript

JavaScript — реалізація специфікації EcmaScript, високорівнева мова програмування, підтримуваний всіма сучасними веб-браузерами. Спочатку призначений для взаємодії з елементами веб-сторінок і додавання інтерактивності.

JavaScript не має ніякого відношення до мови програмування Java. Це дві незалежних мови програмування з різним синтаксисом і принципами роботи. Плутати їх в середовищі розробників буде верхом професійної неграмотності.

При Front-end розробці, JavaScript використовується з HTML і CSS для забезпечення функціональності веб-сторінки, такий як:

  • нескладні обчислення
  • перевірка і маніпуляція введеними користувачем даними
  • зберігання інформації в браузері користувача
  • динамічна зміна HTML-документа
  • реакція на дії користувача
  • створення інтерактивних елементів: галерей, графіків і т. д.
  • взаємодія з сервером і базою даних

Якщо JavaScript-код пишеться для виконання в браузері (Front-end), у розробника немає інструментів і доступу до файлової або операційній системі з міркувань безпеки.

На сьогоднішній день використовуючи JavaScript можна створювати:

  • веб-додатки використовуючи фреймворки React, Vue, Angular та інші
  • бекенд-додатки на Node.js
  • мобільні додатки використовуючи React Native або Ionic
  • десктоп-додатки за допомогою Electron
  • мікроконтролери з Johnny-Five і Espruino

Для реалізації всіх цих можливостей необхідно добре знати синтаксис мови, його особливості та механізми, а так само тренуватися мислити алгоритмічно і вирішувати якомога більше завдань.
