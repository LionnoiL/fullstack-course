Мілстоун 1: адаптивний лендинг

Етап: після розділів HTML і CSS. Мета — зверстати повноцінну односторінкову презентацію продукту без JavaScript.

Що зробити

Лендинг вигаданого продукту (застосунок, кав'ярня, портфоліо — на твій вибір) із такими секціями:

  • шапка з логотипом і навігацією;
  • hero — великий заголовок, підзаголовок і кнопка заклику;
  • переваги — сітка з 3–4 карток;
  • відгуки або галерея;
  • форма підписки;
  • підвал із контактами й соцмережами.

Вимоги (acceptance criteria)

  • семантична розмітка (header, main, section, footer);
  • Flexbox і/або Grid для розкладки;
  • адаптивність: коректний вигляд на мобільному й десктопі;
  • hover-ефекти на кнопках і картках (transition);
  • CSS-змінні для кольорів;
  • усі зображення мають alt.

Рекомендовані кроки

  • склади HTML-структуру всіх секцій;
  • задай базові стилі й змінні теми в :root;
  • зв"яжи секції через Flexbox/Grid;
  • додай адаптивність медіазапитами (mobile-first);
  • відшліфуй дрібниці: відступи, типографіку, стани наведення.

Роби на CodePen або локально. Це перший проєкт для портфоліо — вибери приємну палітру й акуратні відступи, візуал справляє враження.

Розвиток проєкту

Пізніше повернися й «оживи» лендинг: працююча форма підписки (розділ «Форми та валідація»), мобільне меню-бургер, плавна поява секцій при прокрутці (IntersectionObserver).
