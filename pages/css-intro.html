1. Що таке CSS

CSS (Cascading Style Sheets) — мова, якою описують зовнішній вигляд HTML-документа: кольори, шрифти, розміри, розташування. HTML відповідає за структуру, CSS — за оформлення.

2. Синтаксис правила

Правило складається із селектора (що стилізуємо) і блоку оголошень (які властивості й значення застосувати). 

selector {
  property: value;
  color: #1c1917;
  font-size: 16px;
}

3. Три способи підключення

<!-- 1. Зовнішній файл (найкраще) -->
<link rel="stylesheet" href="style.css">

<!-- 2. Внутрішні стилі в head -->
<style>
  p { color: gray; }
</style>

<!-- 3. Інлайн (уникайте) -->
<p style="color: gray;">Текст</p>

Майже завжди використовуйте зовнішній файл: стилі кешуються, спільні для всіх сторінок і не змішуються з розміткою. Інлайн-стилі мають найвищий пріоритет і ускладнюють підтримку.

4. Коментарі та одиниці

/* Це коментар */
.box {
  width: 300px;    /* пікселі */
  padding: 1rem;   /* відносно кореневого шрифту */
  font-size: 1.2em;/* відносно шрифту батька */
  height: 50vh;    /* 50% висоти вікна */
  color: hsl(210, 50%, 40%);
}

5. CSS-змінні

Власні властивості (змінні) задають один раз і перевикористовують — зручно для кольорів і розмірів теми. 

:root {
  --accent: #2563eb;
  --gap: 16px;
}

.button {
  background: var(--accent);
  padding: var(--gap);
}
