1. Властивість position

Властивість position керує тим, як елемент розташовується і чи реагує на top, right, bottom, left.

  • static — за замовчуванням, у звичайному потоці;
  • relative — зсув відносно власного місця;
  • absolute — відносно найближчого позиціонованого предка;
  • fixed — відносно вікна (не рухається при прокрутці);
  • sticky — «прилипає» при прокрутці.

2. relative + absolute

Найпоширеніший патерн: батько relative, дитина absolute — так дитина позиціонується всередині батька.

.card {
  position: relative;
}
.badge {
  position: absolute;
  top: 8px;
  right: 8px;
}

3. fixed — закріплені елементи

.header {
  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}

4. sticky — прилипання

.sidebar {
  position: sticky;
  top: 0; /* прилипне до верху при прокрутці */
}

5. z-index — порядок накладання

z-index визначає, який позиціонований елемент буде «над» іншими. Більше значення — вище.

.modal   { position: fixed; z-index: 1000; }
.overlay { position: fixed; z-index: 900; }

z-index працює лише для позиціонованих елементів (не static) і діє в межах «контексту накладання». Не роздувайте значення до 9999 — це ознака проблем зі структурою, а не рішення.
