1. Коли компонент перерендерюється

Компонент рендериться повторно, коли змінюється його стан або пропси, а також коли рендериться його батько. Здебільшого це швидко, але у важких компонентах зайві рендери варто прибирати. Головні інструменти — memo, useMemo, useCallback.

Спершу зробіть, щоб працювало правильно, і лише потім оптимізуйте — за даними профайлера. Передчасна оптимізація ускладнює код без реальної користі.

2. React.memo

memo запамʼятовує результат рендеру компонента і пропускає перерендер, якщо пропси не змінились. 

import { memo } from 'react';

const Item = memo(function Item({ title }) {
  console.log('render', title);
  return <li>{title}</li>;
});
// Item не перерендериться, поки title той самий

3. useMemo — кешування обчислень

useMemo запамʼятовує результат важкого обчислення й перераховує його лише при зміні залежностей. 

import { useMemo } from 'react';

function Report({ items }) {
  const total = useMemo(() => {
    return items.reduce((sum, i) => sum + i.price, 0);
  }, [items]); // перерахунок лише коли items змінюється

  return <p>Разом: {total}</p>;
}

4. useCallback — стабільні функції

Щоразу під час рендеру створюється нова функція. Якщо передати її в memo-нащадка, він усе одно перерендериться. useCallback зберігає ту саму функцію між рендерами. 

import { useCallback } from 'react';

function Parent({ items }) {
  const handleSelect = useCallback((id) => {
    console.log('обрано', id);
  }, []); // та сама функція між рендерами

  return <List items={items} onSelect={handleSelect} />;
}

5. Прості способи без хуків

  • коректні key у списках — уникають зайвих перемонтувань;
  • виносьте важкий стан якнайближче до місця використання;
  • розбивайте великі компоненти — тоді рендер зачіпає менше вузлів;
  • lazy loading сторінок через React.lazy і Suspense. 
import { lazy, Suspense } from 'react';

const Dashboard = lazy(() => import('./Dashboard'));

<Suspense fallback={<p>Завантаження...</p>}>
  <Dashboard />
</Suspense>;
