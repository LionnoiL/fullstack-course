1. Таблиці для табличних даних

Таблиці <table> призначені для табличних даних — рядків і стовпців зі звʼязаним змістом. Рядок — <tr>, комірка даних — <td>, комірка-заголовок — <th>.

<table>
  <tr>
    <th>Імʼя</th>
    <th>Вік</th>
  </tr>
  <tr>
    <td>Ada</td>
    <td>30</td>
  </tr>
</table>

2. Правильна структура

Для великих таблиць вміст ділять на <thead>, <tbody> та <tfoot>, а підпис задають тегом <caption>.

<table>
  <caption>Успішність студентів</caption>
  <thead>
    <tr><th>Предмет</th><th>Бал</th></tr>
  </thead>
  <tbody>
    <tr><td>JavaScript</td><td>95</td></tr>
    <tr><td>CSS</td><td>88</td></tr>
  </tbody>
</table>

3. Обʼєднання комірок

<td colspan="2">Обʼєднано 2 стовпці</td>
<td rowspan="3">Обʼєднано 3 рядки</td>

Не використовуйте таблиці для верстки макета сторінки — це застарілий і шкідливий для доступності підхід. Для розкладки є Flexbox і Grid (розділ CSS).
