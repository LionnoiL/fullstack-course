1. Вступ

За замовчуванням об'єкт не є ітеруючим, тобто по ньому не можна пройти циклом for абоfor ... of як по масиву або рядку. Для того, щоб перебрати об'єкт існує кілька спеціальних конструкцій, деякі необхідно знати оскільки це частина мови, а деякі використовуються в повсякденній роботі.

2. Цикл for...in

for (key in object) {
  // statements
}
  • Перебирає ключі об'єкта
  • Можна видаляти властивості під час перебору
  • Не можна використовувати для перебору масивів
const hotel = {
  name: 'Resort Hotel',
  stars: 5,
  capacity: 100,
};

// Перебір ключів об'єкта hotel
for (const key in hotel) {
  console.log('Key: ', key);
}

/*
 * Key: name
 * Key: stars
 * Key: capacity
 */

Для того, щоб отримати значення властивості з таким ключем під час ітерації, використовується синтаксис квадратних дужок, оскільки ключ завжди рядок. 

const hotel = {
  name: 'Resort Hotel',
  stars: 5,
  capacity: 100,
};

for (const key in hotel) {
  console.log('Value: ', hotel[key]);
}

/*
 * Value: "Resort Hotel"
 * Value: 5
 * Value: 100
 */

3. Object.keys(), Object.values(), Object.entries()

Всі об'єкти походять від конструктора Object. У нього є кілька дуже корисних методів для роботи з об'єктами.

  • Object.keys (obj) - поверне масив, з ключами об'єкта obj у вигляді рядків.
  • Object.values (obj) - поверне масив, зі значеннями властивостей об'єкта obj.
  • Object.entries (obj) - поверне масив записів, кожним елементом якого буде ще один масив з 2-х елементів, ключа і значення цього ключа з об'єкта Obj. 
const hotel = {
  name: 'Resort Hotel',
  stars: 5,
  capacity: 100,
};

const keys = Object.keys(hotel); // ["name", "stars", "capacity"]
const values = Object.values(hotel); // ["Resort Hotel", 5, 100]
const entries = Object.entries(hotel); // [Array(2), Array(2), Array(2)]

Скомбінувавши результат Object.keys () і цикл for ... of ми можемо перебрати об'єкт. Насправді ми перебираємо масив ключів, а потім просто звертаємося до властивості об'єкта з таким ключем. 

const hotel = {
  name: 'Resort Hotel',
  stars: 5,
  capacity: 100,
};

const keys = Object.keys(hotel); // ["name", "stars", "capacity"]

for (const key of keys) {
  console.log('Value: ', hotel[key]);
}
/*
 * Value: Resort Hotel
 * Value: 5
 * Value: 100
 */

А можна використовувати результат Object.entries () який поверне масив записів з ключами і значеннями властивостей об'єкта. 

const hotel = {
  name: 'Resort Hotel',
  stars: 5,
  capacity: 100,
};

/*
 * Подивіться в консолі з яких двох елементів складається кожен підмасив.
  * Перший елемент - це ключ властивості, другий - це значення.
 */
const entries = Object.entries(hotel);

/*
 * На кожній ітерації по entries виберемо перший елемент підмасив (ключ)
  * В змінну key, а другий (значення) в змінну value
 */
for (const entry of entries) {
  const key = entry[0];
  const value = entry[1];

  console.log(`${key}: ${value}`);
}

/*
 * name: Resort Hotel
 * stars: 5
 * capacity: 100
 */

Припустимо перед нами стоїть завдання порахувати загальну кількість продуктів в об'єкті формату ім'я-продукту: кількість. Тоді підійде метод Object.values () для того щоб отримати масив всіх значень і потім зручно їх скласти. 

const goods = {
  apples: 6,
  grapes: 3,
  bread: 4,
  cheese: 7,
};

const values = Object.values(goods); // [6, 3, 4, 7]

let total = 0;

for (const value of values) {
  total += value;
}

console.log(total); // 20
