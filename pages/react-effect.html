1. Побічні ефекти

Побічний ефект — це взаємодія із зовнішнім світом поза рендером: запити до сервера, підписки, таймери, робота з DOM напряму. Такий код не можна виконувати під час рендеру — для нього є хук useEffect.

2. Хук useEffect

useEffect приймає функцію-ефект і масив залежностей. Ефект виконується після рендеру. 

import { useState, useEffect } from 'react';

function Title() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    document.title = `Кліків: ${count}`;
  }, [count]); // ефект запускається, коли count змінюється

  return <button onClick={() => setCount(count + 1)}>+</button>;
}

3. Масив залежностей

  • [] — ефект спрацює один раз після монтування;
  • [a, b] — щоразу, коли зміниться a або b;
  • без масиву — після кожного рендеру (рідко потрібно).
useEffect(() => {
  console.log('Компонент змонтовано');
}, []); // лише при появі компонента

4. Функція очищення

Якщо ефект щось «підписує» (таймер, слухач події), він має повернути функцію очищення — React викличе її перед наступним ефектом і при видаленні компонента. 

useEffect(() => {
  const id = setInterval(() => console.log('tick'), 1000);

  return () => clearInterval(id); // прибрати таймер
}, []);

Забута функція очищення — часта причина витоків памʼяті й «подвійних» підписок. Якщо ефект щось запускає у фоні — майже завжди його треба зупинити в поверненій функції.

5. Завантаження даних

function Users() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    fetch('/api/users')
      .then((res) => res.json())
      .then(setUsers);
  }, []);

  return <ul>{users.map((u) => <li key={u.id}>{u.name}</li>)}</ul>;
}
