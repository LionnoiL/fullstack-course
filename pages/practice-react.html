Практика: React

Найшвидше — створити пісочницю на StackBlitz (шаблон React). Спробуй сам, потім звір із рішенням.

Завдання 1. Лічильник

Зроби компонент з кнопками «+» і «−» та скиданням, що керує станом через useState.

Рішення 
import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);
  return (
    <div>
      <button onClick={() => setCount((c) => c - 1)}>−</button>
      <span>{count}</span>
      <button onClick={() => setCount((c) => c + 1)}>+</button>
      <button onClick={() => setCount(0)}>Скинути</button>
    </div>
  );
}

Завдання 2. Список задач (To-Do)

Поле вводу + кнопка додають задачу до списку; кожну задачу можна видалити. Використай key та імутабельне оновлення стану.

Рішення 
import { useState } from 'react';

export default function Todo() {
  const [items, setItems] = useState([]);
  const [text, setText] = useState('');

  function add() {
    if (!text.trim()) return;
    setItems((prev) => [...prev, { id: Date.now(), text }]);
    setText('');
  }

  return (
    <div>
      <input value={text} onChange={(e) => setText(e.target.value)} />
      <button onClick={add}>Додати</button>
      <ul>
        {items.map((item) => (
          <li key={item.id}>
            {item.text}
            <button onClick={() => setItems((p) => p.filter((i) => i.id !== item.id))}>×</button>
          </li>
        ))}
      </ul>
    </div>
  );
}

Завдання 3. Завантаження даних (виклик)

У useEffect завантаж список постів з API (напр. JSONPlaceholder) і покажи три стани: «завантаження…», список даних і повідомлення про помилку. Далі винеси цю логіку в кастомний хук useFetch(url), що повертає { data, loading, error } — і використай його в компоненті. Зверни увагу на масив залежностей useEffect, щоб не було зайвих повторних запитів.
