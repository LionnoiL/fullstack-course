1. Регулярні вирази

Регулярний вираз (regular expression, RegExp) — це шаблон для пошуку та заміни підрядків у тексті. Замість того, щоб перебирати рядок вручну, ми описуємо яким має бути фрагмент, а рушій сам знаходить збіги.

У JavaScript регулярку можна створити двома способами:

// Літерал (шаблон між слешами) — коли патерн відомий заздалегідь
const re1 = /\d+/;

// Конструктор — коли патерн збирається з рядка динамічно
const word = 'cat';
const re2 = new RegExp(word, 'gi');

Літерал компілюється один раз під час парсингу коду і працює трохи швидше. Конструктор потрібен, коли патерн формується з даних.

2. Прапорці (flags)

Прапорці змінюють поведінку пошуку і вказуються після закривального слеша:

  • g — глобальний пошук (усі збіги, а не лише перший);
  • i — ігнорувати регістр;
  • m — багаторядковий режим (^ і $ для кожного рядка);
  • s — крапка . також збігається з переносом рядка;
  • u — підтримка Unicode;
  • y — «липкий» пошук від конкретної позиції.

3. Базовий синтаксис

Найчастіші будівельні блоки шаблону:

\d   // будь-яка цифра, те саме що [0-9]
\D   // будь-який символ, крім цифри
\w   // літера, цифра або _
\s   // пробільний символ (пробіл, таб, перенос)
.    // будь-який символ, крім переносу рядка

[abc]   // один із символів a, b або c
[^abc]  // будь-який символ, КРІМ a, b, c
[a-z]   // діапазон від a до z

^   // початок рядка
$   // кінець рядка
\b  // межа слова

Квантифікатори задають, скільки разів повторюється попередній елемент:

a*      // 0 або більше
a+      // 1 або більше
a?      // 0 або 1 (необовʼязково)
a{3}    // рівно 3
a{2,5}  // від 2 до 5
a{2,}   // 2 або більше

4. Методи для роботи з регулярками

Методи самої регулярки:

const re = /\d+/;

re.test('year 2026');   // true — чи є хоча б один збіг
'year 2026'.match(re);  // ['2026', index: 5, ...]

Методи рядка, які приймають регулярку:

const text = 'ціна: 100 грн, знижка 20 грн';

text.match(/\d+/g);            // ['100', '20'] — усі збіги
text.replace(/\d+/g, '#');     // 'ціна: # грн, знижка # грн'
text.split(/,\s*/);            // ['ціна: 100 грн', 'знижка 20 грн']
text.search(/\d/);             // 6 — індекс першого збігу

5. Групи та захоплення

Круглі дужки (...) створюють групу, значення якої можна дістати окремо. Іменовані групи (?<name>...) роблять код читабельнішим.

const date = '2026-07-31';
const re = /(?<year>\d{4})-(?<month>\d{2})-(?<day>\d{2})/;

const { groups } = date.match(re);
console.log(groups.year);  // '2026'
console.log(groups.day);   // '31'

// Заміна з посиланням на групи
date.replace(re, '$<day>.$<month>.$<year>'); // '31.07.2026'

6. Практичні приклади

const emailRe = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
emailRe.test('user@example.com'); // true

// Прибрати зайві пробіли всередині рядка
'  багато    пробілів  '.replace(/\s+/g, ' ').trim();

// Розбити camelCase на слова
'getUserName'.replace(/([a-z])([A-Z])/g, '$1 $2'); // 'get User Name'

Не варто валідувати складні формати (email, URL) занадто «строгими» регулярками — вони стають нечитабельними і все одно не покривають усіх випадків. Для критичних перевірок використовуйте спеціалізовані бібліотеки або серверну валідацію.
