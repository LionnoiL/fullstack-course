1. Тип Symbol

Symbol — це примітивний тип даних (ES6), кожне значення якого унікальне і незмінне. Символи створюють, щоб робити «приховані» або гарантовано неконфліктні ключі властивостей обʼєкта. 

const id = Symbol('id'); // 'id' — лише опис для дебагу
const id2 = Symbol('id');

id === id2; // false — кожен символ унікальний

Опис у дужках жодним чином не впливає на унікальність — два символи з однаковим описом усе одно різні. Опис потрібен лише для зручного відображення в консолі.

2. Символи як ключі властивостей

Символьний ключ не перетинається з жодним рядковим ключем і не потрапляє у звичайні перебори (for...in, Object.keys). Це зручно для «службових» даних. 

const id = Symbol('id');

const user = {
  name: 'Ada',
  [id]: 42,        // символьний ключ у квадратних дужках
};

user[id];               // 42
Object.keys(user);      // ['name'] — символ прихований
JSON.stringify(user);   // '{"name":"Ada"}' — символ ігнорується

3. Глобальний реєстр символів

Symbol.for(key) повертає символ із глобального реєстру, створюючи його лише за потреби. Такі символи спільні для всього застосунку. 

const a = Symbol.for('app.id');
const b = Symbol.for('app.id');

a === b;              // true — той самий символ із реєстру
Symbol.keyFor(a);     // 'app.id'

4. Системні (well-known) символи

Рушій використовує вбудовані символи, щоб налаштовувати поведінку обʼєктів. Найвідоміший — Symbol.iterator, який робить обʼєкт перебиральним (див. урок про ітератори). 

const range = {
  from: 1,
  to: 3,
  [Symbol.iterator]() {
    let current = this.from;
    const last = this.to;
    return {
      next() {
        return current <= last
          ? { value: current++, done: false }
          : { value: undefined, done: true };
      },
    };
  },
};

[...range]; // [1, 2, 3]
