1. Типізовані класи

TypeScript розширює класи JavaScript типами полів і модифікаторами доступу. Поля треба оголошувати з їхніми типами.

class User {
  name: string;
  age: number;

  constructor(name: string, age: number) {
    this.name = name;
    this.age = age;
  }

  greet(): string {
    return `Привіт, я ${this.name}`;
  }
}

2. Модифікатори доступу

  • public — доступне звідусіль (за замовчуванням);
  • private — лише всередині класу;
  • protected — усередині класу та нащадків;
  • readonly — лише для читання після ініціалізації.
class Account {
  private balance = 0;
  readonly owner: string;

  constructor(owner: string) {
    this.owner = owner;
  }

  deposit(amount: number): void {
    this.balance += amount;
  }
}

const acc = new Account('Ada');
acc.deposit(100);
acc.balance; // ❌ private — недоступне ззовні

3. Короткий запис у конструкторі

Модифікатор перед параметром конструктора автоматично створює й ініціалізує поле — менше шаблонного коду.

class Point {
  constructor(
    public x: number,
    public y: number,
    private label: string = '',
  ) {}
}
// x, y, label вже стали полями обʼєкта

4. Абстрактні класи та implements

Абстрактний клас не можна створити напряму — лише успадкувати. Клас може implements інтерфейс, зобовʼязуючись реалізувати його форму.

interface Printable {
  print(): void;
}

abstract class Shape implements Printable {
  abstract area(): number; // нащадок мусить реалізувати

  print(): void {
    console.log('Площа:', this.area());
  }
}

class Circle extends Shape {
  constructor(private r: number) {
    super();
  }
  area(): number {
    return Math.PI * this.r ** 2;
  }
}

5. Геттери та сеттери

class Temperature {
  private celsius = 0;

  get fahrenheit(): number {
    return this.celsius * 1.8 + 32;
  }
  set fahrenheit(value: number) {
    this.celsius = (value - 32) / 1.8;
  }
}
