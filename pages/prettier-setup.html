1. Що таке Prettier

Prettier — «упертий» форматер коду: він розбирає файл і друкує його заново за єдиними правилами. Суперечки про стиль зникають — форматування завжди однакове, незалежно від того, як ти набрав код.

npm install -D --save-exact prettier

2. Запуск

npx prettier . --check    // показати, що не відформатовано
npx prettier . --write    // відформатувати всі файли
"scripts": {
  "format": "prettier . --write"
}

3. Налаштування .prettierrc

Prettier навмисно має мало опцій. Їх задають у .prettierrc (JSON):

{
  "semi": true,          // крапки з комою
  "singleQuote": true,   // одинарні лапки
  "printWidth": 80,      // бажана довжина рядка
  "tabWidth": 2,         // ширина відступу
  "trailingComma": "all" // коми в кінці багаторядкових списків
}

4. Файл .prettierignore

Що не форматувати — перелічують у .prettierignore (синтаксис як у .gitignore):

dist/
node_modules/
package-lock.json

Філософія Prettier — мінімум налаштувань. Не витрачай час на тонке підстроювання стилю: візьми дефолти (або кілька опцій), зафіксуй їх у репозиторії й забудь. Головна цінність — щоб у всіх однаково, а не «ідеально під мене».

5. Формати, які він розуміє

Prettier форматує не лише JS/TS, а й CSS, SCSS, HTML, JSON, Markdown, YAML — тож одним інструментом покривається майже весь проєкт.
