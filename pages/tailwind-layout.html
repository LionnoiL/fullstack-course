1. Flexbox

Клас flex вмикає флекс-контейнер, а далі напрямок, вирівнювання й проміжки задаються окремими утилітами.

<div class="flex items-center justify-between gap-4">
  <span>Ліворуч</span>
  <span>Праворуч</span>
</div>
  • flex-row / flex-col — напрямок осі;
  • items-center — вирівнювання по поперечній осі (align-items);
  • justify-between — розподіл по головній осі (justify-content);
  • gap-4 — проміжок між елементами.

2. Grid

Клас grid плюс grid-cols-* задає кількість колонок.

<div class="grid grid-cols-3 gap-4">
  <div>1</div>
  <div>2</div>
  <div>3</div>
</div>

Елемент може займати кілька колонок через col-span-*:

<div class="grid grid-cols-4 gap-4">
  <div class="col-span-2">широкий блок на 2 колонки</div>
  <div>вузький</div>
  <div>вузький</div>
</div>

3. Проміжки та вирівнювання

<!-- різні проміжки по осях -->
<div class="grid grid-cols-2 gap-x-8 gap-y-2">...</div>

<!-- вирівнювання елементів у гріді -->
<div class="grid place-items-center h-64">
  <p>Ідеально по центру</p>
</div>

4. Позиціонування

<div class="relative">
  <span class="absolute top-2 right-2 bg-red-500 text-white rounded-full px-2">
    3
  </span>
  Іконка з бейджем
</div>

<header class="sticky top-0 z-10 bg-white">Липке меню</header>

Для типової картки-макета «шапка / контент / підвал на всю висоту» комбінуйте flex flex-col на контейнері й flex-1 (він же flex: 1) на середньому блоці — він розтягнеться й притисне підвал донизу.
