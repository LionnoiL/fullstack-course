Практика: форми (React Hook Form + Zod)

Створи React-проєкт (Vite) і встанови react-hook-form, zod, @hookform/resolvers. Рухайся від простої форми до типізованої зі схемою.

Завдання 1. Проста форма на RHF

Зроби форму входу (email, пароль) через useForm, register і handleSubmit. Виведи зібрані дані в консоль.

Рішення 
const { register, handleSubmit } = useForm();
const onSubmit = (data) => console.log(data);

<form onSubmit={handleSubmit(onSubmit)}>
  <input {...register('email')} />
  <input type="password" {...register('password')} />
  <button>Увійти</button>
</form>

Завдання 2. Zod-схема

Опиши схему реєстрації: name (мін. 2), email, age (18+), password (мін. 8). Перевір тестовий об'єкт через safeParse і виведи помилки.

Підказка

z.object({ ... }), для віку — z.coerce.number().min(18) (значення з input приходить рядком).

Завдання 3. З'єднати RHF + Zod

Підключи схему із завдання 2 через zodResolver і показуй повідомлення про помилки під кожним полем. Кнопку блокуй під час isSubmitting.

Рішення 
const { register, handleSubmit, formState: { errors } } = useForm({
  resolver: zodResolver(schema),
});

<input {...register('email')} />
{errors.email && <p className="error">{errors.email.message}</p>}

Завдання 4. Динамічні поля (виклик)

Через useFieldArray зроби список навичок, який можна доповнювати й видаляти. Додай перевірку схемою (z.array(...).min(1)) — хоча б одна навичка обов'язкова. За наявності — використай Controller для кастомного поля-селекта.

Переведи форму зі свого проєкту (напр. форму додавання нотатки у fullstack-проєкті) на RHF + Zod і застосуй ту саму схему на бекенді для перевірки запиту. Відчуєш головну перевагу — одне джерело правди для валідації й типів.
