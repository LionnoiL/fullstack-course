Практика: дизайн-системи

Створи React-проєкт на Vite з Tailwind. Далі — від примітивів до каталогу компонентів. Мета — відчути зв'язку Radix → shadcn/ui → Storybook на практиці.

Завдання 1. Доступний діалог на Radix

Встанови @radix-ui/react-dialog і зроби модальне вікно з власними стилями. Перевір, що працюють Esc, клік по фону й пастка фокуса — і все це без твого коду на ці випадки.

Рішення 
import * as Dialog from '@radix-ui/react-dialog';

<Dialog.Root>
  <Dialog.Trigger>Відкрити</Dialog.Trigger>
  <Dialog.Portal>
    <Dialog.Overlay className="fixed inset-0 bg-black/50" />
    <Dialog.Content className="fixed left-1/2 top-1/2 -translate-x-1/2 -translate-y-1/2 bg-white p-6 rounded-lg">
      <Dialog.Title>Привіт</Dialog.Title>
      <Dialog.Close>Закрити</Dialog.Close>
    </Dialog.Content>
  </Dialog.Portal>
</Dialog.Root>

Завдання 2. Компонент через shadcn/ui

Ініціалізуй shadcn/ui (npx shadcn@latest init), додай button і dialog, використай їх на сторінці. Знайди код кнопки в components/ui/ і додай власний варіант (напр. variant="danger").

Підказка

npx shadcn@latest add button dialog. Варіанти живуть у buttonVariants (cva) прямо у файлі кнопки — редагуй його.

Завдання 3. Історії у Storybook

Додай Storybook (npx storybook@latest init) і напиши Button.stories з історіями Primary, Ghost, Disabled. Покрути пропси через панель Controls.

Рішення 
export default { title: 'UI/Button', component: Button };
export const Primary  = { args: { children: 'Кнопка' } };
export const Ghost    = { args: { variant: 'ghost', children: 'Привид' } };
export const Disabled = { args: { disabled: true, children: 'Вимкнена' } };

Завдання 4. Каталог і a11y (виклик)

Напиши історії ще для 2–3 компонентів (Input, Dialog), увімкни аддон a11y і виправ усі знайдені зауваження щодо доступності. Так ти отримаєш маленьку живу дизайн-систему.

Збери з цих компонентів невелику сторінку (форму чи діалог) у своєму проєкті — і побач, як Radix дає доступність, shadcn/ui — швидкий старт зі стилями, а Storybook — впевненість, що кожен стан виглядає правильно.
