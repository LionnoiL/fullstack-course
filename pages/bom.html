1. Об'єктна модель браузера

BOM (Browser Object Model) — це набір обʼєктів, які браузер надає для взаємодії з самим вікном, а не з вмістом сторінки. Якщо DOM описує документ, то BOM описує вікно, адресний рядок, історію та інформацію про браузер.

Кореневий обʼєкт — window. Він же є глобальним обʼєктом: усі глобальні змінні й функції насправді є його властивостями. 

window.innerWidth;   // ширина видимої області, px
window.innerHeight;  // висота видимої області
window.alert('Привіт');   // те саме, що просто alert(...)
window.scrollTo(0, 0);    // прокрутити на початок сторінки

2. window.location — адреса сторінки

Обʼєкт location містить частини поточного URL і дозволяє керувати переходами. 

location.href;      // повний URL, напр. 'https://site.com/page?id=5#top'
location.protocol;  // 'https:'
location.host;      // 'site.com'
location.pathname;  // '/page'
location.search;    // '?id=5'
location.hash;      // '#top'

location.href = 'https://example.com'; // перейти на іншу сторінку
location.reload();                     // перезавантажити

Розібрати параметри запиту зручно через URLSearchParams:

const params = new URLSearchParams(location.search);
params.get('id'); // '5'

3. window.history — історія переходів

history.back();     // назад (як кнопка «Назад»)
history.forward();  // вперед
history.go(-2);     // на 2 кроки назад

// Змінити URL без перезавантаження (основа SPA-роутингу)
history.pushState({ page: 2 }, '', '/page/2');

history.pushState — це те, на чому побудований роутинг у React Router, Vue Router тощо: URL змінюється, а сторінка не перезавантажується.

4. window.navigator — про браузер і пристрій

navigator.userAgent;   // рядок з інформацією про браузер
navigator.language;    // 'uk-UA'
navigator.onLine;      // true / false — чи є зʼєднання

// Сучасні Web API також живуть у navigator:
navigator.clipboard.writeText('скопійовано');
navigator.geolocation.getCurrentPosition((pos) => {
  console.log(pos.coords.latitude, pos.coords.longitude);
});

5. window.screen та розміри

screen.width;         // ширина екрана монітора
screen.height;        // висота екрана
window.devicePixelRatio; // щільність пікселів (Retina = 2)

Не варто визначати браузер за userAgent для вибору логіки — цей рядок легко підробити і він часто бреше. Перевіряйте наявність конкретної можливості (feature detection), а не назву браузера.
