1. Проблема повторення

Коли той самий довгий набір класів повторюється в багатьох місцях, його стає важко підтримувати. Є два способи прибрати дублювання.

2. Компонент розмітки (найкращий спосіб)

Якщо ви на React/Vue чи у шаблонізаторі — винесіть повторюваний блок у компонент, а класи лишіть у розмітці. Тоді стилі й структура в одному місці. 

function Button({ children }) {
  return (
    <button className="px-4 py-2 rounded-lg bg-blue-600 text-white
                       font-medium hover:bg-blue-700">
      {children}
    </button>
  );
}

3. @apply для власного класу

Якщо компонентів немає (звичайний HTML), повторювані утиліти можна зібрати в один клас через директиву @apply у CSS. 

@layer components {
  .btn-primary {
    @apply px-4 py-2 rounded-lg bg-blue-600 text-white font-medium;
  }
  .btn-primary:hover {
    @apply bg-blue-700;
  }
}
<button class="btn-primary">Зберегти</button>

Не зловживайте @apply: якщо загорнути в нього все підряд, ви фактично повернетесь до звичайного CSS і втратите переваги utility-first. Використовуйте його точково — для дійсно частих елементів (кнопки, поля вводу).

4. Офіційні плагіни

Готові набори утиліт для типових задач підключають одним рядком у CSS:

@import "tailwindcss";
@plugin "@tailwindcss/forms";      /* акуратні стилі полів форм */
@plugin "@tailwindcss/typography"; /* клас prose для статей/markdown */
<article class="prose lg:prose-xl">
  <h1>Заголовок статті</h1>
  <p>Автоматично гарна типографіка для контенту...</p>
</article>
