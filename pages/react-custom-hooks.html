1. Правила хуків

Хуки (useState, useEffect тощо) підпорядковані двом правилам:

  • викликати лише на верхньому рівні компонента — не в циклах, умовах чи вкладених функціях;
  • викликати лише з React-компонентів або з інших хуків.

2. Що таке кастомний хук

Кастомний хук — це звичайна функція, назва якої починається з use, і яка використовує інші хуки. Вона дозволяє винести й перевикористати логіку зі станом між компонентами.

import { useState } from 'react';

function useCounter(initial = 0) {
  const [count, setCount] = useState(initial);

  const increment = () => setCount((c) => c + 1);
  const decrement = () => setCount((c) => c - 1);
  const reset = () => setCount(initial);

  return { count, increment, decrement, reset };
}

Використання виглядає як робота зі звичайним хуком:

function Counter() {
  const { count, increment, reset } = useCounter(10);

  return (
    <>
      <span>{count}</span>
      <button onClick={increment}>+</button>
      <button onClick={reset}>Скинути</button>
    </>
  );
}

3. Хук для завантаження даних

function useFetch(url) {
  const [data, setData] = useState(null);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    setLoading(true);
    fetch(url)
      .then((res) => res.json())
      .then(setData)
      .finally(() => setLoading(false));
  }, [url]);

  return { data, loading };
}

// у компоненті:
const { data, loading } = useFetch('/api/users');

4. Хук над localStorage

function useLocalStorage(key, initial) {
  const [value, setValue] = useState(() => {
    const saved = localStorage.getItem(key);
    return saved ? JSON.parse(saved) : initial;
  });

  useEffect(() => {
    localStorage.setItem(key, JSON.stringify(value));
  }, [key, value]);

  return [value, setValue];
}

Кастомні хуки не ділять стан між собою — кожен виклик створює власний ізольований стан. Вони перевикористовують логіку, а не дані.
