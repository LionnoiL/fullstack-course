1. Обробники в JSX — тип виводиться

Якщо писати обробник прямо в атрибуті, TypeScript сам знає тип події — анотувати нічого не треба.

<button onClick={(e) => console.log(e.currentTarget)}>
  Клік
</button>

<input onChange={(e) => setValue(e.target.value)} />

2. Обробник як окрема функція

Коли виносиш обробник у змінну, тип події треба вказати явно. React надає готові типи: React.MouseEvent, React.ChangeEvent, React.FormEvent тощо.

function handleChange(e: React.ChangeEvent<HTMLInputElement>) {
  setValue(e.target.value);
}

function handleSubmit(e: React.FormEvent<HTMLFormElement>) {
  e.preventDefault();
}

// <input onChange={handleChange} />
// <form onSubmit={handleSubmit} />

У дженерику вказують тип елемента, на якому подія: HTMLInputElement, HTMLButtonElement, HTMLFormElement. Саме він визначає, які поля має e.target / e.currentTarget.

3. useRef на DOM-елемент

Для рефа на елемент задають тип елемента й початкове null:

const inputRef = useRef<HTMLInputElement>(null);

function focus() {
  inputRef.current?.focus();   // ?. бо на старті null
}

// <input ref={inputRef} />

4. useRef як «коробка» для значення

Реф часто використовують не для DOM, а щоб зберігати значення між рендерами (напр. id таймера):

const timerRef = useRef<number | null>(null);

timerRef.current = window.setInterval(tick, 1000);
// ...
if (timerRef.current) clearInterval(timerRef.current);

5. Найпоширеніші типи подій

  • React.ChangeEvent<HTMLInputElement> — введення в поле;
  • React.MouseEvent<HTMLButtonElement> — клік;
  • React.FormEvent<HTMLFormElement> — сабміт форми;
  • React.KeyboardEvent — натискання клавіш.
