1. Навіщо Socket.io

Socket.io — популярна бібліотека поверх WebSocket, що додає те, чого «голому» протоколу бракує: автоперепідключення, кімнати, іменовані події, підтвердження доставки й fallback на HTTP long-polling, якщо WebSocket недоступний. Має узгоджений API на сервері й клієнті.

Socket.io — не чистий WebSocket: у нього власний протокол поверх. Клієнт Socket.io працює лише із сервером Socket.io (і навпаки). Для «сирого» WebSocket бери браузерний WebSocket + ws з попереднього уроку.

2. Встановлення

npm install socket.io        // сервер
npm install socket.io-client // клієнт

3. Сервер

import { Server } from 'socket.io';

const io = new Server(3000, { cors: { origin: 'http://localhost:5173' } });

io.on('connection', (socket) => {
  console.log('підключився', socket.id);

  // слухаємо подію від клієнта
  socket.on('message', (text) => {
    // розіслати всім, крім відправника
    socket.broadcast.emit('message', { id: socket.id, text });
  });

  socket.on('disconnect', () => console.log('відключився', socket.id));
});

4. Клієнт

import { io } from 'socket.io-client';

const socket = io('http://localhost:3000');

socket.on('connect', () => console.log('я', socket.id));
socket.on('message', (msg) => render(msg));

// надіслати подію на сервер
socket.emit('message', 'Привіт усім!');

Модель Socket.io — іменовані події: emit('назва', дані) надсилає, on('назва', cb) слухає. Це зручніше за один onmessage з ручним полем type, як у сирого WebSocket.

5. Кімнати (rooms)

Кімната — довільна група сокетів, якій можна адресувати повідомлення. Ідеально для чат-кімнат, дощок, ігрових столів:

// сервер
socket.on('join', (room) => {
  socket.join(room);
  io.to(room).emit('system', `${socket.id} приєднався`);
});

socket.on('room-message', ({ room, text }) => {
  io.to(room).emit('message', { text }); // лише учасникам кімнати
});

6. Підтвердження та namespaces

Acknowledgement — колбек, який спрацьовує, коли інша сторона підтвердила отримання (зручно для «доставлено»):

// клієнт
socket.emit('save', data, (res) => console.log('сервер підтвердив:', res.ok));
// сервер
socket.on('save', (data, ack) => { store(data); ack({ ok: true }); });

Namespace (io.of('/admin')) — розділення логіки на незалежні канали в межах одного з'єднання. Кімнати живуть усередині namespace.
