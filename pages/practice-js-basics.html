Практика: основи JavaScript

Закріпимо змінні, оператори, розгалуження й цикли. Напиши код прямо в редакторі й натисни «Запустити» — тести перевірять рішення. Код зберігається в браузері автоматично.

Завдання 1. Конвертер температури

Реалізуй функцію celsiusToFahrenheit(c), яка переводить градуси Цельсія у Фаренгейти за формулою c × 9/5 + 32.

Підказка

Просто повернути результат виразу: return c * 9 / 5 + 32;

Рішення 
function celsiusToFahrenheit(c) {
  return c * 9 / 5 + 32;
}

Завдання 2. FizzBuzz

Реалізуй функцію fizzBuzz(n), яка повертає масив від 1 до n: числа, кратні 3 — заміни на 'Fizz', кратні 5 — на 'Buzz', кратні 15 — на 'FizzBuzz'.

Підказка

Перебирай i від 1 до n. Перевіряй i % 15 першим, потім i % 3, потім i % 5, інакше — саме число.

Рішення 
function fizzBuzz(n) {
  const result = [];
  for (let i = 1; i <= n; i += 1) {
    if (i % 15 === 0) result.push('FizzBuzz');
    else if (i % 3 === 0) result.push('Fizz');
    else if (i % 5 === 0) result.push('Buzz');
    else result.push(i);
  }
  return result;
}

Завдання 3. Валідація пароля (самостійно)

Реалізуй функцію isStrongPassword(str), яка повертає true, якщо пароль має щонайменше 8 символів, містить хоча б одну цифру й одну велику літеру.

Рішення 
function isStrongPassword(str) {
  return str.length >= 8 && /[0-9]/.test(str) && /[A-Z]/.test(str);
}

Завдання 4. Діапазон чисел

Реалізуй range(start, end), що повертає масив цілих від start до end включно.

Рішення 
function range(start, end) {
  const result = [];
  for (let i = start; i <= end; i += 1) result.push(i);
  return result;
}

Завдання 5. Паліндром

Реалізуй isPalindrome(str), що повертає true, якщо рядок читається однаково в обидва боки (без урахування регістру).

Підказка

Приведи до нижнього регістру, розверни через [...s].reverse().join('') і порівняй.

Рішення 
function isPalindrome(str) {
  const s = str.toLowerCase();
  return s === [...s].reverse().join('');
}
