1. Клас Date

Робота з проміжками часу це одна з найбільш популярних завдань: годинник, календарі та інше. JavaScript надає клас Date, який абстрагує більшу частину роботи з датами безпосередньо. Це дозволяє нам представляти моменти в часі і маніпулювати ними лише кількома рядками коду.

2. Створення дати

Створення дати дуже просто. Просто створіть новий екземпляр вбудованого класу Date.

const date = new Date();
console.log(date); // Mon Mar 19 2018 16:51:32 GMT+0200 (FLE Standard Time)

Оскільки не були передані аргументи, буде створена поточна дата і час. Однак, можна додатково передати рядок або число в Date, і результатом буде об'єкт, що описує зазначену дату і час.

2.1. Datestring

Якщо передати рядок, вона буде оброблена методом Date.parse (), щоб повернути об'єкт Date.

Припустимо, необхідно створити подію на дату 4 березня 2017 року.

const date = new Date('March 4, 2017');
console.log(date); // Sat Mar 04 2017 00:00:00 GMT+0200 (FLE Standard Time)

2.2. 7 аргументів

Інший спосіб створення нових об'єктів Date - це передати 7 чисел. Ці числа описують рік, місяць, день, годину, хвилину, секунду і мілісекунду.

new Date(year, month, date, hours, minutes, seconds, ms)

Останні 4 аргументу необов'язкові.

const date = new Date(2000, 5, 8, 12, 0, 0, 0);

// Індекси місяців починаються з 0, тому 5-й місяць це липень.
console.log(date); // Thu Jun 08 2000 12:00:00 GMT+0300 (FLE Daylight Time)

3. Unix час

В області інформатики існує концепція епохи Unix. Цей момент часу встановлений на північ 1 січня 1970 року в часовому поясі UTC.

З урахуванням цієї системи відліку, якщо ви передаєте число об'єкту Date, це число являє собою кількість мілісекунд, що пройшли з того часу.

const date = new Date(1000000);
console.log(date); // Thu Jan 01 1970 02:16:40 GMT+0200 (FLE Standard Time)

Щоб побачити число мілісекунд від цієї дати до поточного моменту, використовується статичний метод Date.now().

const date = Date.now();
console.log(date); // 1521471595501

Зручність цього формату полягає в тому, що можна представляти точні моменти часу у вигляді одного числа і не турбуватися про дати, рядки і часові пояси, оскільки можна отримати всю необхідну інформацію коли необхідно.

4. Методи Date

Примірник клас Date має безліч методів як для отримання значень дати і часу, так і для установки значень в об'єкт. Методи повертають або привласнюють рік, місяць, день місяця або тижня, годину, хвилину, секунду і мілісекунди для кожного екземпляра. Ці дані можуть бути представлені у вигляді рядка з урахуванням місцевого календаря або мови.

4.1. Гетери

Ось все методи отримання інформації з об'єкта Date:

const date = new Date();
console.log('Date: ' + date);

// повертає день місяця від 1 до 31
console.log('getDate(): ' + date.getDate());

// повертає день тижня від 0 до 6
console.log('getDay(): ' + date.getDay());

// повертає місяць від 0 до 11
console.log('getMonth(): ' + date.getMonth());

// повертає рік з 4 цифр
console.log('getFullYear(): ' + date.getFullYear());

// повертає годину
console.log('getHours(): ' + date.getHours());

// повертає хвилини
console.log('getMinutes(): ' + date.getMinutes());

// повертає секунди
console.log('getSeconds(): ' + date.getSeconds());

// повертає мілісекунди
console.log('getMilliseconds(): ' + date.getMilliseconds());

// повертає кількість мілісекунд минулих зі старту епохи Unix
console.log('getTime(): ' + date.getTime());

Поекспериментуймо:

const date = new Date();

// перевіримо кількість мс з з початку епохи Unix
console.log(`Час в мс з початку епохи Unix: ${date.getTime()}`);
// "Час в мс з початку епохи Unix: ....  значення будуть змінюватися :-)
// "Час в мс з початку епохи Unix: 1504721892483"

let result = 'Date: ';
result += date.getFullYear() + '/'; // рік
result += date.getMonth() + '/'; // місяць, починання з 0
result += date.getDate() + '. Day of week: '; // день тижня, починаючи з 1
result += date.getDay() + '.'; // день , починаючи з 0

result += ' Time: ' + date.getHours() + ':'; // години
result += date.getMinutes() + ':'; // хвилини
result += date.getSeconds() + ':'; // секунди
result += date.getMilliseconds() + ''; // мілісекунди

// рядок повинна показати поточний час і дату
console.log(result); // "Date: 2017/8/6. Day of week: 3. Time: 21:18:12:483"
// ...  значення будуть змінюватися :-)

4.2. Сетери

Все що можна прочитати можна записати, методи для запису починаються з set*.

// Щоб встановити дату існує 2 способи. Встановимо 1500000000000мс
// з початку ери Unix за допомогою конструктора
const date = new Date(2017, 6, 14, 5, 40, 0, 0);

// Перевіримо
console.log(`2017, 6, 14, 5, 40 відповідає ${date.getTime()}`);
// "2017, 6, 14, 5, 40 відповідає 1500000000000"

/* За допомогою методів set */
// Створимо новий об'єкт з поточною датою
const secondDate = new Date();

// Змінимо рік і в ньому ж місяць і день місяця
secondDate.setFullYear(2017, 6, 14);
// Змінимо годину і в ньому ж хвилини, секунди і мілісекунди
secondDate.setHours(5, 40, 0, 0);

// Перевіримо
console.log(`2017, 6, 14, 5, 40 відповідає ${secondDate.getTime()}`);
// "2017, 6, 14, 5, 40 відповідає 1500000000000"

5. Форматування і висновок дат

У всіх браузерах, крім IE10-, підтримується новий стандарт, який додає спеціальні методи для форматування дат.

Це робиться викликом date.toLocaleString (locale, opts), в якому можна задати багато налаштувань. Він дозволяє вказати, які параметри дати потрібно вивести, і ряд налаштувань виведення, після чого інтерпретатор сам сформує рядок.

let date = new Date();

// формат виведення
const options = {
  weekday: 'long',
  year: 'numeric',
  month: 'short',
  day: 'numeric',
  hour: '2-digit',
  minute: '2-digit',
};

// Україна
const localeUk = date.toLocaleString('Uk-uk', options);
console.log(localeUk); // понеділок, 19 бер. 2018 р., 17:42

// USA
const localeUs = date.toLocaleString('en-US', options);
console.log(localeUs); // Monday, Mar 19, 2018, 5:43 PM

5.1. Методи виведення без локалізації

toString(), toDateString(), toTimeString() повертають стандартне рядкове подання, не заданий жорстко в стандарті, а залежне від браузера. Єдина вимога до нього - читабельність людиною. Метод toString () повертає дату цілком, toDateString () і toTimeString () - тільки дату і час відповідно.
