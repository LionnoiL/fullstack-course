1. Елемент form

Форми збирають дані від користувача. Контейнер <form> має атрибути action (куди надіслати) і method (GET або POST).

<form action="/submit" method="post">
  <!-- поля -->
  <button type="submit">Надіслати</button>
</form>

2. Поля вводу та мітки

Кожне поле варто підписати міткою <label>. Звʼязок через for/id робить клік по мітці фокусом на полі й важливий для доступності.

<label for="email">Email</label>
<input type="email" id="email" name="email" placeholder="you@site.com">

  <option value="kyiv">Київ</option>
  <option value="lviv">Львів</option>
</select>

5. Вбудована валідація

Браузер сам перевіряє поля за атрибутами — без жодного JavaScript.

<input type="email" required>
<input type="text" minlength="3" maxlength="20">
<input type="number" min="1" max="10">
<input type="text" pattern="[0-9]{6}" title="6 цифр">

Групуйте повʼязані поля в <fieldset> із заголовком <legend> — це покращує структуру й доступність великих форм.
