1. Що таке React

React — це бібліотека для побудови інтерфейсів користувача, створена в Meta. Її головна ідея — розбити інтерфейс на компоненти: незалежні шматки UI, які описують, що має відображатися, а React сам оновлює DOM.

Замість того щоб вручну змінювати DOM (як у чистому JS), ви описуєте стан і розмітку, а React декларативно синхронізує сторінку зі станом.

2. Віртуальний DOM

React тримає в памʼяті легку копію DOM — віртуальний DOM. Коли стан змінюється, React будує нове віртуальне дерево, порівнює його зі старим (reconciliation) і оновлює в реальному DOM лише те, що справді змінилось. Це робить оновлення швидкими й позбавляє від ручних маніпуляцій.

3. Швидкий старт

Сучасний спосіб створити проєкт — збірник Vite:

npm create vite@latest my-app -- --template react
cd my-app
npm install
npm run dev

Точка входу монтує кореневий компонент у DOM:

import { createRoot } from 'react-dom/client';
import App from './App';

const root = createRoot(document.getElementById('root'));
root.render(<App />);

4. Перший компонент

Компонент — це звичайна функція, що повертає розмітку (JSX).

function App() {
  return (
    <div>
      <h1>Привіт, React!</h1>
      <p>Мій перший компонент</p>
    </div>
  );
}

export default App;

React — це саме бібліотека для UI, а не повноцінний фреймворк. Роутинг, запити, керування станом підключають окремими пакетами. Це дає гнучкість, але вимагає збирати «стек» самостійно.
