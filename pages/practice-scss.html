Практика: SCSS

Постав sass (npm install -D sass) і запусти npx sass --watch style.scss:style.css, або скористайся онлайн-пісочницею SassMeister, де видно скомпільований CSS одразу. Перевіряй результат після кожного завдання.

Завдання 1. Змінні й вкладеність

Опиши кнопку через змінні ($primary, $radius) і додай стан :hover через &, а не окремим селектором.

Рішення 
$primary: #2563eb;
$radius: 8px;

.button {
  padding: .5rem 1rem;
  border-radius: $radius;
  background: $primary;
  color: #fff;

  &:hover { background: darken($primary, 10%); }
}

Завдання 2. Міксин для медіазапитів

Зроби міксин respond($bp), що приймає tablet/desktop і всередині ставить відповідний @media. Застосуй його до сітки.

Підказка

Усередині міксина використай @content, а вибір брейкпоінта — через @if/@else if.

Рішення 
@mixin respond($bp) {
  @if $bp == tablet  { @media (min-width: 768px)  { @content; } }
  @else if $bp == desktop { @media (min-width: 1024px) { @content; } }
}

.grid {
  display: grid;
  grid-template-columns: 1fr;
  @include respond(tablet)  { grid-template-columns: 1fr 1fr; }
  @include respond(desktop) { grid-template-columns: repeat(4, 1fr); }
}

Завдання 3. Генерація утиліт із мапи

Опиши мапу кольорів ($colors: (primary: #2563eb, danger: #dc2626, ...)) і через цикл @each згенеруй для кожного запису два класи: .text-* (колір тексту) і .bg-* (колір фону) — напр. .text-primary, .bg-danger. Мета — побачити, як з однієї мапи народжується цілий набір утиліт без ручного дублювання (саме так працюють утиліти Bootstrap/Tailwind).

Рішення 
$colors: ("primary": #2563eb, "danger": #dc2626, "muted": #6b7280);

@each $name, $value in $colors {
  .text-#{$name} { color: $value; }
  .bg-#{$name}   { background: $value; }
}

Завдання 4. Структура файлів (виклик)

Розбий стилі невеликого проєкту на партіали (_variables.scss, _mixins.scss, _buttons.scss) і збери їх у main.scss через @use. Переконайся, що змінні доступні через простір імен.

Візьми готовий CSS одного зі своїх проєктів і перепиши його на SCSS: винеси кольори у змінні, згорни повторення в міксини, розбий на партіали. Так найкраще відчувається користь препроцесора.
