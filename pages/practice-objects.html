Практика: об'єкти та колекції

Робота з об'єктами, деструктуризацією, Map/Set. Пиши код і тисни «Запустити».

Завдання 1. pick — вибрати поля

Реалізуй pick(obj, keys), що повертає новий об'єкт лише з переліченими в масиві keys полями.

Підказка

keys.reduce(...), додаючи поле лише якщо воно є в obj.

Рішення 
function pick(obj, keys) {
  return keys.reduce((acc, key) => {
    if (key in obj) acc[key] = obj[key];
    return acc;
  }, {});
}

Завдання 2. Підрахунок слів

Реалізуй wordCount(str), що повертає об'єкт із кількістю кожного слова (слова розділені пробілами).

Рішення 
function wordCount(str) {
  return str.split(' ').reduce((acc, word) => {
    acc[word] = (acc[word] || 0) + 1;
    return acc;
  }, {});
}

Завдання 3. Інвертувати об'єкт

Реалізуй invert(obj): поміняй місцями ключі й значення.

Рішення 
function invert(obj) {
  const result = {};
  for (const [key, value] of Object.entries(obj)) {
    result[value] = key;
  }
  return result;
}

Завдання 4. Глибоке копіювання

Реалізуй deepClone(obj), що повертає незалежну глибоку копію об'єкта (без вкладених функцій).

Підказка

Найпростіше — JSON.parse(JSON.stringify(obj)).

Рішення 
function deepClone(obj) {
  return JSON.parse(JSON.stringify(obj));
}

Завдання 5. Значення за замовчуванням

Реалізуй mergeDefaults(obj, defaults), що повертає новий об'єкт, де відсутні поля беруться з defaults, а наявні лишаються з obj.

Рішення 
function mergeDefaults(obj, defaults) {
  return { ...defaults, ...obj };
}
