1. Інтерполяція #{}

Щоб підставити значення змінної туди, де очікується «текст» (ім'я властивості, селектор, частина рядка), використовують #{...}.

$side: left;
$name: "primary";

.box { margin-#{$side}: 1rem; } // margin-left: 1rem
.btn-#{$name} { color: blue; }   // .btn-primary

2. Умови: @if / @else

@mixin text-contrast($bg) {
  @if lightness($bg) > 50% {
    color: #111;
  } @else {
    color: #fff;
  }
}

.badge { background: #fde047; @include text-contrast(#fde047); }

3. Цикл @each — по списку чи мапі

Найпоширеніший цикл: згенерувати класи з набору значень.

$colors: (
  "primary": #2563eb,
  "danger":  #dc2626,
  "success": #16a34a,
);

@each $name, $value in $colors {
  .text-#{$name} { color: $value; }
  .bg-#{$name}   { background: $value; }
}

Результат — по парі класів .text-primary/.bg-primary тощо для кожного кольору.

4. Цикл @for — за діапазоном

// утиліти відступів: .m-1 ... .m-5
@for $i from 1 through 5 {
  .m-#{$i} { margin: #{$i * 0.25}rem; }
}

5. Цикл @while

$i: 1;
@while $i <= 3 {
  .col-#{$i} { width: percentage($i / 3); }
  $i: $i + 1;
}

Цикли + мапи — це «двигун» багатьох CSS-фреймворків: так генерують сотні утилітних класів з кількох рядків. Але пам'ятайте, що кожна ітерація додає CSS — не генеруйте те, чим не користуєтесь.
