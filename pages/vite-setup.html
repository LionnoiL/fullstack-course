1. Створення проєкту

Найшвидший старт — офіційний генератор. Він поставить питання й розгорне готовий шаблон:

npm create vite@latest

Далі майстер запитає ім'я проєкту, фреймворк (Vanilla, React, Vue, Svelte…) і варіант (JavaScript / TypeScript). Можна задати все одразу:

// проєкт my-app на React + TypeScript
npm create vite@latest my-app -- --template react-ts

2. Встановлення й запуск

cd my-app
npm install     // поставити залежності
npm run dev     // запустити dev-сервер

У консолі з'явиться локальна адреса (зазвичай http://localhost:5173) — відкрий її в браузері.

3. Основні npm-скрипти

У package.json шаблон додає три команди:

"scripts": {
  "dev":     "vite",         // сервер розробки з HMR
  "build":   "vite build",   // продакшн-збірка в dist/
  "preview": "vite preview"  // локальний перегляд зібраного dist/
}

4. Структура проєкту

my-app/
  index.html          ← точка входу (в корені, не в public!)
  package.json
  vite.config.js      ← конфігурація Vite
  public/             ← статика «як є» (favicon тощо)
  src/
    main.js           ← головний JS, підключений з index.html
    style.css

У Vite index.html — це точка входу, а не просто статичний файл, і лежить у корені. Саме з нього через <script type="module" src="/src/main.js"> Vite будує дерево залежностей.

5. Точка входу index.html

<!DOCTYPE html>
<html lang="uk">
  <head>
    <meta charset="UTF-8" />
    <title>Vite App</title>
  </head>
  <body>
    <div id="app"></div>
    <script type="module" src="/src/main.js"></script>
  </body>
</html>
