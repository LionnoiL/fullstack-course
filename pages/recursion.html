1. Рекурсія

Рекурсія — це прийом, коли функція викликає саму себе для розвʼязання задачі, зводячи її до простішого варіанту тієї ж задачі. Рекурсія особливо зручна там, де дані мають вкладену структуру: дерева, каталоги файлів, DOM, JSON.

Будь-яка рекурсивна функція складається з двох частин:

  • базовий випадок (base case) — умова, за якої рекурсія зупиняється;
  • рекурсивний крок — виклик себе з «меншими» даними.
function factorial(n) {
  if (n <= 1) {
    return 1;          // базовий випадок — виходимо без нового виклику
  }
  return n * factorial(n - 1); // рекурсивний крок
}

factorial(5); // 5 * 4 * 3 * 2 * 1 = 120

Якщо забути базовий випадок, функція викликатиме себе нескінченно, переповнить стек викликів і призведе до помилки RangeError: Maximum call stack size exceeded.

2. Як це працює у стеку викликів

Кожен виклик функції додає новий кадр (frame) у стек викликів. Рекурсія «занурюється» до базового випадку, а потім «розкручується» назад, повертаючи значення з найглибшого виклику до найпершого.

factorial(3)
 -> 3 * factorial(2)
      -> 2 * factorial(1)
           -> 1            // базовий випадок
      -> 2 * 1 = 2
 -> 3 * 2 = 6

3. Обхід вкладених структур

Саме тут рекурсія сяє. Порахуємо суму всіх чисел у вкладеному масиві:

function deepSum(arr) {
  let total = 0;
  for (const item of arr) {
    if (Array.isArray(item)) {
      total += deepSum(item); // елемент — масив, занурюємось глибше
    } else {
      total += item;
    }
  }
  return total;
}

deepSum([1, [2, 3, [4, 5]], 6]); // 21

Аналогічно обходять дерево коментарів, структуру папок або DOM-вузли.

4. Рекурсія проти циклу

Будь-яку рекурсію можна переписати циклом, і навпаки. Рекурсія читабельніша для деревоподібних даних, але цикл економніший за памʼяттю (не росте стек).

// Те саме факторіал, але ітеративно
function factorialLoop(n) {
  let result = 1;
  for (let i = 2; i <= n; i += 1) {
    result *= i;
  }
  return result;
}

Глибина стека в браузерах обмежена (кілька тисяч викликів). Для дуже глибокої рекурсії обирайте цикл або перетворюйте алгоритм на ітеративний з власним стеком у масиві.
