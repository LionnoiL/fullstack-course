1. Що змінилося в CSS

За останні роки CSS отримав можливості, заради яких раніше тягли препроцесори, JS чи хитрі хаки. Сьогодні це нативні засоби, доступні в усіх сучасних браузерах:

  • вкладеність прямо в CSS — без Sass;
  • :has() — «батьківський» селектор, про який мріяли роками;
  • container queries (@container) — адаптив за розміром контейнера, а не екрана;
  • каскадні шари (@layer) — керування пріоритетом стилів;
  • логічні властивості, aspect-ratio, clamp(), нативна темна тема.

2. Перевірка підтримки: @supports

Щоб застосувати нову фічу лише там, де вона працює, використовують feature query @supports:

@supports (container-type: inline-size) {
  /* стилі, якщо браузер уміє container queries */
}

/* заперечення */
@supports not (aspect-ratio: 1) {
  .box { height: 200px; }
}

Перш ніж використати свіжу властивість у продакшні, звіряйся з caniuse.com та поняттям Baseline (показує, чи фіча вже стабільно доступна в усіх основних браузерах). Усі теми цього розділу вже входять у Baseline.

3. Прогресивне покращення

Підхід «працює всюди, а де можна — краще»: базовий макет тримається на давно підтримуваних властивостях, а сучасні фічі додають зверху через @supports. Так сайт не ламається у старому браузері.

4. Зв'язок з іншими розділами

Ти вже проходив базовий CSS (селектори, flexbox, grid, адаптивність) і Sass. Цей розділ показує, що багато можливостей Sass (вкладеність, змінні) тепер є прямо в CSS — хоча препроцесор досі корисний для складнішої логіки.
