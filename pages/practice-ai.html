Практика: AI-інтеграція

Візьми Node/Next.js-проєкт і ключ провайдера (ANTHROPIC_API_KEY у .env, лише на сервері). Пройди шлях від першого виклику до маленького RAG-асистента. Ключ ніколи не потрапляє у фронтенд-код.

Завдання 1. Перший виклик через свій бекенд

Зроби ендпоінт POST /api/ask, що приймає question, викликає модель і повертає текст відповіді. На фронті — поле й кнопка, що показують результат. Переконайся, що ключ читається з env на сервері.

Рішення 
import Anthropic from '@anthropic-ai/sdk';
const client = new Anthropic();

app.post('/api/ask', async (req, res) => {
  const r = await client.messages.create({
    model: 'claude-opus-4-8',
    max_tokens: 1024,
    messages: [{ role: 'user', content: req.body.question }],
  });
  res.json({ answer: r.content.find((b) => b.type === 'text')?.text ?? '' });
});

Завдання 2. Стрімінг у чат

Переведи відповідь на стрімінг: сервер віддає токени через text/event-stream, клієнт дописує їх у UI по частинах. Історію повідомлень тримай на клієнті й надсилай усю.

Підказка

На сервері — client.messages.stream(...) + stream.on('text', ...). На клієнті читай res.body.getReader() і парси кадри data:. Або візьми useChat з Vercel AI SDK — і ручний парсинг не потрібен.

Завдання 3. Інструмент (function calling)

Додай інструмент get_time (повертає поточний час) і проведи агентний цикл: доки stop_reason === 'tool_use' — виконуй інструмент і повертай tool_result. Спитай модель «котра година?» і переконайся, що вона кличе інструмент.

Рішення 
const tools = [{
  name: 'get_time',
  description: 'Повертає поточний час ISO. Викликай, коли питають про час.',
  input_schema: { type: 'object', properties: {}, required: [] },
}];

while (true) {
  const res = await client.messages.create({ model: 'claude-opus-4-8', max_tokens: 512, tools, messages });
  messages.push({ role: 'assistant', content: res.content });
  if (res.stop_reason !== 'tool_use') break;
  const results = res.content
    .filter((b) => b.type === 'tool_use')
    .map((b) => ({ type: 'tool_result', tool_use_id: b.id, content: new Date().toISOString() }));
  messages.push({ role: 'user', content: results });
}

Завдання 4. Vercel AI SDK + useChat

У Next.js зроби чат: Route Handler зі streamText і клієнтський компонент на useChat. Переконайся, що відповідь стрімиться без ручного парсингу SSE.

Підказка

Сервер: return streamText({ model: anthropic('claude-opus-4-8'), messages }).toDataStreamResponse();. Клієнт: const { messages, input, handleInputChange, handleSubmit } = useChat();.

Завдання 5. Міні-RAG (виклик)

Візьми 5–10 своїх текстових нотаток. Порахуй їхні embeddings і збережи (у памʼяті або в pgvector). На запит: порахуй embedding питання, знайди топ-3 найближчі нотатки (косинусна подібність) і встав їх у промпт з інструкцією «відповідай лише за контекстом». Покажи джерела.

Підказка

Косинусна подібність двох векторів: скалярний добуток, поділений на добуток довжин. Для старту навіть не потрібна БД — тримай масив { text, embedding } у памʼяті й сортуй за подібністю.

Вбудуй одну AI-фічу у свій fullstack-проєкт: пошук за змістом по нотатках або асистента, що відповідає на основі твоїх даних (RAG). Не забувай про безпеку ключа, ліміти запитів і чесну відповідь «не знаю», коли контексту бракує.
