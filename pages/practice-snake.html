Проєкт: Snake

Класична змійка — ідеальний проєкт для закріплення Canvas API, масивів та ігрового циклу. Логіка руху побудована на черзі: додай голову, видали хвіст — і змійка «рухається».

Рахунок: 0 Рекорд: 0
← ↑ → ↓ — керування · P — пауза

Завдання 1. Константи та стан гри

Визнач константи: COLS = 20, ROWS = 20, CELL = 20 (пікселів). Стан гри — це обʼєкт із трьох полів: snake — масив обʼєктів { x, y } де [0] — голова; dir — поточний напрямок { x, y }; food — позиція їжі { x, y }. Напиши функцію createState() що повертає початковий стан: змійка з 3 сегментів по центру поля, напрямок вправо.

Рішення 
const COLS = 20;
const ROWS = 20;
const CELL = 20;

function createState() {
  const cx = Math.floor(COLS / 2);
  const cy = Math.floor(ROWS / 2);
  return {
    snake: [{ x: cx, y: cy }, { x: cx - 1, y: cy }, { x: cx - 2, y: cy }],
    dir: { x: 1, y: 0 },
    food: spawnFood([{ x: cx, y: cy }, { x: cx - 1, y: cy }, { x: cx - 2, y: cy }]),
  };
}

Завдання 2. Малювання поля

Напиши функцію draw(ctx, state): очисти Canvas темним фоном, намалюй кожен сегмент змійки (голова — яскравіший колір), намалюй їжу (червоне коло через arc). Легка сітка фону — опційно.

Рішення 
function draw(ctx, state) {
  // фон
  ctx.fillStyle = '#111';
  ctx.fillRect(0, 0, COLS * CELL, ROWS * CELL);

  // змійка
  state.snake.forEach(({ x, y }, i) => {
    ctx.fillStyle = i === 0 ? '#4ade80' : '#22c55e';
    ctx.fillRect(x * CELL + 1, y * CELL + 1, CELL - 2, CELL - 2);
  });

  // їжа
  const { x, y } = state.food;
  ctx.fillStyle = '#f87171';
  ctx.beginPath();
  ctx.arc(x * CELL + CELL / 2, y * CELL + CELL / 2, CELL / 2 - 2, 0, Math.PI * 2);
  ctx.fill();
}

Завдання 3. Генерація їжі

Напиши spawnFood(snake): зберери всі клітинки поля, відфільтруй ті що зайняті змійкою, обери одну випадково. Якщо вільних клітинок немає — поверни null (перемога).

Підказка

Склади Set з рядків типу "x,y" для всіх сегментів змійки, потім відфільтруй усі COLS × ROWS позицій.

Рішення 
function spawnFood(snake) {
  const occupied = new Set(snake.map(({ x, y }) => `${x},${y}`));
  const free = [];
  for (let y = 0; y < ROWS; y++)
    for (let x = 0; x < COLS; x++)
      if (!occupied.has(`${x},${y}`)) free.push({ x, y });
  if (!free.length) return null;
  return free[Math.floor(Math.random() * free.length)];
}

Завдання 4. Крок змійки

Напиши step(state) що повертає новий стан після одного кроку. Обчисли нову голову: { x: head.x + dir.x, y: head.y + dir.y }. Перевір колізію зі стінами і власним тілом — якщо є, поверни null (game over). Якщо нова голова збіглася з їжею — не видаляй хвіст (змійка росте) і спавни нову їжу. Інакше видали хвіст.

Рішення 
function step(state) {
  const head = state.snake[0];
  const newHead = { x: head.x + state.dir.x, y: head.y + state.dir.y };

  // колізія зі стінами
  if (newHead.x < 0 || newHead.x >= COLS || newHead.y < 0 || newHead.y >= ROWS)
    return null;

  // колізія з тілом (без хвоста — він зникне)
  const body = state.snake.slice(0, -1);
  if (body.some(({ x, y }) => x === newHead.x && y === newHead.y))
    return null;

  const ateFood = newHead.x === state.food.x && newHead.y === state.food.y;
  const newSnake = [newHead, ...state.snake.slice(0, ateFood ? undefined : -1)];

  return {
    snake: newSnake,
    dir: state.dir,
    food: ateFood ? spawnFood(newSnake) : state.food,
    grew: ateFood,
  };
}

Завдання 5. Керування клавіатурою

Підпишись на keydown. Стрілки задають новий напрямок, але заборони розворот на 180° (якщо змійка рухається вправо — не можна повернути ліворуч). Буферизуй наступний напрямок у змінній nextDir і застосовуй його на початку кожного кроку — це запобігає «подвійному повороту» за один тік.

Рішення 
const DIRS = {
  ArrowUp:    { x:  0, y: -1 },
  ArrowDown:  { x:  0, y:  1 },
  ArrowLeft:  { x: -1, y:  0 },
  ArrowRight: { x:  1, y:  0 },
};

let nextDir = null;

document.addEventListener('keydown', (e) => {
  const d = DIRS[e.key];
  if (!d) return;
  e.preventDefault();
  // заборона розвороту
  if (d.x !== -state.dir.x || d.y !== -state.dir.y) {
    nextDir = d;
  }
});

Завдання 6. Ігровий цикл

Запусти гру через setInterval або requestAnimationFrame з таймером. На кожному тіку: застосуй nextDir якщо є, викликай step(), перемалюй Canvas. Якщо step повернув null — зупини цикл і покажи екран «Гра закінчена». Швидкість: 150 мс на перших рівнях, зменшуй на 10 мс кожні 5 очок.

Рішення 
let timerId = null;
let score = 0;
let state = createState();

function tick() {
  if (nextDir) { state.dir = nextDir; nextDir = null; }
  const next = step(state);
  if (!next) { gameOver(); return; }
  if (next.grew) {
    score++;
    updateScore();
  }
  state = next;
  draw(ctx, state);
}

function startGame() {
  clearInterval(timerId);
  state = createState();
  score = 0;
  nextDir = null;
  draw(ctx, state);
  const interval = Math.max(80, 150 - Math.floor(score / 5) * 10);
  timerId = setInterval(tick, interval);
}

Завдання 7. Рахунок та екран завершення

Виводь поточний рахунок і рекорд у DOM поруч із Canvas. Зберігай рекорд у localStorage. Коли гра закінчується — намалюй напівпрозорий оверлей на Canvas з фінальним рахунком і підказкою «натисни пробіл або Enter для нової гри».

Рішення 
function gameOver() {
  clearInterval(timerId);
  timerId = null;

  const best = Math.max(score, parseInt(localStorage.getItem('snake-best') || '0', 10));
  localStorage.setItem('snake-best', best);

  ctx.fillStyle = 'rgba(0,0,0,0.6)';
  ctx.fillRect(0, 0, canvas.width, canvas.height);
  ctx.fillStyle = '#fff';
  ctx.font = 'bold 20px sans-serif';
  ctx.textAlign = 'center';
  ctx.fillText('Гра закінчена!', canvas.width / 2, canvas.height / 2 - 16);
  ctx.font = '15px sans-serif';
  ctx.fillText('Рахунок: ' + score, canvas.width / 2, canvas.height / 2 + 10);
  ctx.fillStyle = '#aaa';
  ctx.font = '12px sans-serif';
  ctx.fillText('Пробіл / Enter → нова гра', canvas.width / 2, canvas.height / 2 + 32);
}

document.addEventListener('keydown', (e) => {
  if ((e.key === ' ' || e.key === 'Enter') && !timerId) startGame();
});

Завдання 8. Прискорення та wrap-around (виклик)

Реалізуй два режими: Класичний — зіткнення зі стіною = смерть; Wrap-around — змійка виходить крізь стіну і зʼявляється з протилежного боку (x = (x + COLS) % COLS). Також динамічно перераховуй інтервал після кожного зʼїденого яблука без перезапуску setInterval — використай requestAnimationFrame з ручним відліком часу.

Підказка

Замість setInterval: зберігай lastTick, у requestAnimationFrame-колбеці перевіряй now - lastTick >= interval і тільки тоді роби крок. Так інтервал можна змінювати будь-коли.

Snake навчає ключового патерну ігрового циклу: незмінний стан + чиста функція переходу step(state) → newState | null. Цей підхід масштабується на будь-яку гру і є основою Redux-архітектури.
