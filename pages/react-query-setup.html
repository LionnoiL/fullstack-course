1. Встановлення

npm install @tanstack/react-query

2. QueryClient і Provider

Уся робота бібліотеки крутиться навколо QueryClient — він тримає кеш. Його створюють один раз і роздають застосунку через QueryClientProvider (механізм Context, який ми проходили в React).

// main.tsx
import { QueryClient, QueryClientProvider } from '@tanstack/react-query';

const queryClient = new QueryClient();

createRoot(document.getElementById('root')).render(
  <QueryClientProvider client={queryClient}>
    <App />
  </QueryClientProvider>
);

Створюй QueryClient поза компонентом (як тут) або через useState(() => new QueryClient()). Якщо створити його прямо в тілі компонента, він перестворюватиметься на кожному рендері й кеш скидатиметься.

3. Налаштування за замовчуванням

Спільні опції для всіх запитів задають при створенні клієнта:

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      staleTime: 60 * 1000,   // дані «свіжі» 1 хв
      retry: 2,               // 2 повторні спроби при помилці
      refetchOnWindowFocus: false,
    },
  },
});

4. Devtools

Офіційна панель показує стан кожного запиту, кеш і таймінги — незамінна під час розробки.

npm install @tanstack/react-query-devtools
import { ReactQueryDevtools } from '@tanstack/react-query-devtools';

<QueryClientProvider client={queryClient}>
  <App />
  <ReactQueryDevtools initialIsOpen={false} />
</QueryClientProvider>

5. Порядок роботи

  1. обгорнули застосунок у QueryClientProvider;
  2. читаємо дані хуком useQuery;
  3. змінюємо дані хуком useMutation;
  4. оновлюємо кеш через інвалідацію.

Далі — по кроку в кожному уроці.
