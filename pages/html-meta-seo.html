1. Вміст head

Тег <head> містить невидиму службову інформацію про сторінку: кодування, назву, опис, підключення ресурсів. Саме ці дані використовують браузер, пошукові системи та соцмережі.

2. Базові метатеги

<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<title>Заголовок сторінки (50–60 символів)</title>
<meta name="description" content="Короткий опис для пошуку">

<title> і description — це те, що бачить користувач у результатах пошуку Google. Роблячи їх точними й унікальними для кожної сторінки, ви прямо впливаєте на клікабельність.

3. Основи SEO

SEO (Search Engine Optimization) — оптимізація під пошукові системи. Що допомагає:

  • семантична розмітка й правильна ієрархія заголовків;
  • унікальні <title> та description;
  • атрибути alt у зображень;
  • швидке завантаження й адаптивність;
  • «людські» URL і внутрішні посилання.

4. Open Graph для соцмереж

Метатеги Open Graph керують тим, як виглядає посилання при поширенні у Facebook, Telegram, LinkedIn тощо.

<meta property="og:title" content="Назва статті">
<meta property="og:description" content="Опис">
<meta property="og:image" content="https://site.com/preview.jpg">
<meta property="og:url" content="https://site.com/article">

5. Іконка та мова

<link rel="icon" href="/favicon.ico">
<html lang="uk"> <!-- мова важлива для пошуку й читачів екрана -->
