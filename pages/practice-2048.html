Завдання 1. Стан гри

Визнач структуру стану гри: grid — двовимірний масив 4×4 (нуль — порожня клітинка), score — поточний рахунок, best — рекорд (зберігається в localStorage). Напиши функцію createGrid(), що повертає порожній масив 4×4.

Рішення 
const SIZE = 4;

let grid, score, best;

function createGrid() {
  return Array.from({ length: SIZE }, () => Array(SIZE).fill(0));
}

function initGame() {
  grid = createGrid();
  score = 0;
  best = parseInt(localStorage.getItem('2048-best') || '0', 10);
  addTile();
  addTile();
  render();
}

Завдання 2. Відображення сітки у DOM

Напиши функцію render(), яка синхронізує DOM із масивом grid. Для кожної клітинки встав значення (або порожньо якщо 0) та застосуй відповідний CSS-клас / data-атрибут для кольору. Оновлюй також відображення рахунку. Не перебудовуй весь DOM щоразу — просто оновлюй textContent та атрибути.

Підказка

Зручно створити 16 div.cell заздалегідь і посилатися на них через масив. У render() лише оновлюй cell.textContent і cell.dataset.v — CSS зробить все інше через [data-v="8"] тощо.

Рішення 
const gridEl = document.querySelector('.grid');
const cells = [];

// ініціалізація DOM-клітинок
for (let i = 0; i < SIZE * SIZE; i++) {
  const div = document.createElement('div');
  div.className = 'cell';
  gridEl.appendChild(div);
  cells.push(div);
}

function render() {
  grid.forEach((row, r) => {
    row.forEach((val, c) => {
      const cell = cells[r * SIZE + c];
      cell.textContent = val || '';
      cell.dataset.v = val || '';
    });
  });
  document.querySelector('#score').textContent = score;
  document.querySelector('#best').textContent = best;
}

Завдання 3. Додавання нової плитки

Напиши addTile(): знайди всі порожні клітинки (grid[r][c] === 0), обери одну випадково і постав туди 2 (90% ймовірності) або 4 (10%). Якщо порожніх немає — нічого не роби.

Рішення 
function addTile() {
  const empty = [];
  grid.forEach((row, r) => row.forEach((v, c) => { if (!v) empty.push([r, c]); }));
  if (!empty.length) return;
  const [r, c] = empty[Math.floor(Math.random() * empty.length)];
  grid[r][c] = Math.random() < 0.9 ? 2 : 4;
}

Завдання 4. Зсув і злиття одного рядка

Це ядро гри. Напиши функцію slideRow(row), що приймає масив із 4 елементів і повертає новий масив після зсуву ліворуч та злиття: спочатку видали нулі, потім злий сусідні однакові числа (подвоївши ліве і зробивши праве нулем), додай нулі в кінець до довжини 4. Функція повертає { result, gained } де gained — кількість очок набраних за злиття.

Підказка

Крок 1: row.filter(v => v !== 0).
Крок 2: у циклі якщо arr[i] === arr[i+1] — подвой arr[i], встав 0 замість arr[i+1].
Крок 3: знову filter і .fill(0) до довжини 4.

Рішення 
function slideRow(row) {
  let arr = row.filter((v) => v !== 0);
  let gained = 0;

  for (let i = 0; i < arr.length - 1; i++) {
    if (arr[i] === arr[i + 1]) {
      arr[i] *= 2;
      gained += arr[i];
      arr[i + 1] = 0;
      i++; // пропустити злитий елемент
    }
  }

  arr = arr.filter((v) => v !== 0);
  while (arr.length < SIZE) arr.push(0);
  return { result: arr, gained };
}

Завдання 5. Чотири напрямки

На основі slideRow() реалізуй функцію move(dir) для напрямків 'left' | 'right' | 'up' | 'down'. Для right — обернути рядок, зсунути, обернути назад. Для up/down — транспонуй сітку, зсунь, транспонуй назад (вертикальний рух стає горизонтальним). Якщо сітка змінилась — додай нову плитку, онови рахунок.

Рішення 
function transpose(g) {
  return g[0].map((_, c) => g.map((row) => row[c]));
}

function move(dir) {
  let g = grid.map((r) => [...r]);
  let rotated = false;

  if (dir === 'up' || dir === 'down') { g = transpose(g); rotated = true; }

  let gained = 0;
  const reverse = dir === 'right' || dir === 'down';

  g = g.map((row) => {
    if (reverse) row = [...row].reverse();
    const { result, gained: pts } = slideRow(row);
    gained += pts;
    return reverse ? result.reverse() : result;
  });

  if (rotated) g = transpose(g);

  // перевірити чи щось змінилось
  const changed = grid.some((row, r) => row.some((v, c) => v !== g[r][c]));
  if (!changed) return;

  grid = g;
  score += gained;
  if (score > best) { best = score; localStorage.setItem('2048-best', best); }
  addTile();
  render();
  checkEnd();
}

Завдання 6. Керування клавіатурою та свайпи

Підпишись на keydown і мапуй стрілки на move(dir). Для мобільних додай підтримку свайпів: запиши координати touchstart, порівняй з touchend і визнач напрямок за максимальною дельтою по осі X або Y.

Рішення 
const KEY_MAP = {
  ArrowLeft: 'left', ArrowRight: 'right',
  ArrowUp: 'up', ArrowDown: 'down',
};

document.addEventListener('keydown', (e) => {
  const dir = KEY_MAP[e.key];
  if (dir) { e.preventDefault(); move(dir); }
});

// Свайпи
let touchX, touchY;
document.addEventListener('touchstart', (e) => {
  touchX = e.touches[0].clientX;
  touchY = e.touches[0].clientY;
});
document.addEventListener('touchend', (e) => {
  const dx = e.changedTouches[0].clientX - touchX;
  const dy = e.changedTouches[0].clientY - touchY;
  if (Math.abs(dx) > Math.abs(dy)) {
    move(dx > 0 ? 'right' : 'left');
  } else {
    move(dy > 0 ? 'down' : 'up');
  }
});

Завдання 7. Перевірка кінця гри та перемоги

Напиши checkEnd(): якщо на полі є плитка 2048 — показуй повідомлення про перемогу (але дозволяй грати далі). Гра закінчена (програш) коли немає порожніх клітинок і жоден хід неможливий (немає сусідів з однаковим значенням). Перевір обидва напрямки по рядках і стовпцях.

Рішення 
function canMove() {
  for (let r = 0; r < SIZE; r++) {
    for (let c = 0; c < SIZE; c++) {
      if (grid[r][c] === 0) return true;
      if (c < SIZE - 1 && grid[r][c] === grid[r][c + 1]) return true;
      if (r < SIZE - 1 && grid[r][c] === grid[r + 1][c]) return true;
    }
  }
  return false;
}

function checkEnd() {
  const has2048 = grid.some((row) => row.some((v) => v === 2048));
  if (has2048) {
    showMessage('Перемога! 🎉');
    return;
  }
  if (!canMove()) {
    showMessage('Гра закінчена! Рахунок: ' + score);
  }
}

function showMessage(text) {
  document.querySelector('#message').textContent = text;
}

Завдання 8. Анімація та полірування (виклик)

Додай CSS-анімацію появи нової плитки (@keyframes pop-in: scale від 0 до 1). При злитті — коротка підсвітка (@keyframes merge-flash). Реалізуй кнопку «Відмінити» (undo): зберігай попередній стан гри у змінній і відновлюй його за кліком. Зроби адаптивний CSS щоб гра виглядала на мобільних.

Підказка

Для undo перед кожним ходом клонуй стан: prevGrid = grid.map(r => [...r]); prevScore = score;. Анімацію запускай через classList.add('new-tile') і видаляй через animationend або setTimeout.

2048 — класичний приклад де вся логіка зведена до однієї операції (slideRow), а решта — лише трансформації і симетрія. Усвідомлення цього патерну — ключовий навик декомпозиції задач.
