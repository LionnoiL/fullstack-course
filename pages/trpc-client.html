1. Клієнт, що знає сервер

Клієнт створюється з типу AppRouter — не з коду. Тому в редакторі працюють автодоповнення й перевірка типів: назви процедур, форма входу й тип результату «підказуються» самі.

// client/trpc.ts
import { createTRPCReact } from '@trpc/react-query';
import type { AppRouter } from '../server/router'; // лише ТИП

export const trpc = createTRPCReact<AppRouter>();

@trpc/react-query — це надбудова над TanStack Query з окремого розділу. tRPC генерує хуки useQuery/useMutation, а всю механіку кешу, статусів (isLoading, error) та інвалідації бере на себе React Query.

2. Провайдери

Потрібні два провайдери: QueryClientProvider (від React Query) і trpc.Provider з налаштованим лінком. httpBatchLink склеює кілька викликів, що сталися одночасно, в один HTTP-запит.

import { QueryClient, QueryClientProvider } from '@tanstack/react-query';
import { httpBatchLink } from '@trpc/client';
import { trpc } from './trpc';

const queryClient = new QueryClient();
const trpcClient = trpc.createClient({
  links: [httpBatchLink({ url: 'http://localhost:3000/trpc' })],
});

export function Providers({ children }) {
  return (
    <trpc.Provider client={trpcClient} queryClient={queryClient}>
      <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>
    </trpc.Provider>
  );
}

3. Читання: useQuery

Виклик повторює шлях у роутері. Вхід передається першим аргументом і перевіряється типом прямо в редакторі:

function TodoList() {
  const { data, isLoading, error } = trpc.todo.list.useQuery();

  if (isLoading) return <p>Завантаження…</p>;
  if (error) return <p>Помилка: {error.message}</p>;

  // data типізовано як Todo[] — виведено із серверної процедури
  return <ul>{data.map((t) => <li key={t.id}>{t.title}</li>)}</ul>;
}

// процедура зі входом:
const todo = trpc.todo.byId.useQuery({ id: 1 }); // { id: number } — обов'язково

4. Зміни: useMutation + інвалідація

Мутації повертають mutate/mutateAsync. Після успіху інвалідуємо відповідний запит, щоб список перечитався — через useUtils():

function AddTodo() {
  const utils = trpc.useUtils();
  const addTodo = trpc.todo.add.useMutation({
    onSuccess: () => {
      utils.todo.list.invalidate(); // перечитати список
    },
  });

  return (
    <button onClick={() => addTodo.mutate({ title: 'Нова задача' })}
            disabled={addTodo.isPending}>
      Додати
    </button>
  );
}

utils.todo.list.invalidate() — типізований аналог queryClient.invalidateQueries із TanStack Query, але tRPC сам знає ключ кешу для цієї процедури. Помилитися з ключем неможливо.

5. Підсумок

  • клієнт створюється з типу AppRouter — автодоповнення без кодогенерації;
  • два провайдери: React Query + tRPC з httpBatchLink;
  • useQuery для читання, useMutation + utils…invalidate() для змін.
