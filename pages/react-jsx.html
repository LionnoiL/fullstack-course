1. Що таке JSX

JSX — це розширення синтаксису JavaScript, що дозволяє писати HTML-подібну розмітку прямо в коді. Браузер його не розуміє: збірник (Vite, Babel) перетворює JSX на виклики React.createElement. 

// JSX
const element = <h1 className="title">Привіт</h1>;

// у що він перетворюється
const element2 = React.createElement('h1', { className: 'title' }, 'Привіт');

2. Вставка виразів

У фігурних дужках { } можна вставляти будь-який JavaScript-вираз.

const name = 'Ada';
const user = { age: 30 };

const el = (
  <p>
    {name}, тобі {user.age} років. Через рік буде {user.age + 1}.
  </p>
);

3. Атрибути та відмінності від HTML

JSX близький до HTML, але має відмінності, бо це JavaScript:

  • class → className (class — зарезервоване слово);
  • for → htmlFor;
  • атрибути пишуться в camelCase: onClick, tabIndex;
  • стилі задаються обʼєктом.
const box = (
  <div
    className="card"
    style={{ color: 'red', fontSize: 16 }}
    onClick={() => console.log('клік')}
  >
    Вміст
  </div>
);

4. Один кореневий елемент

Компонент має повертати один кореневий вузол. Якщо обгортка не потрібна, використовують порожній фрагмент <>...</>. 

function Info() {
  return (
    <>
      <h2>Заголовок</h2>
      <p>Текст</p>
    </>
  );
}

Теги, що не мають вмісту, у JSX обовʼязково самозакривні: <img />, <br />, <input />. Забутий слеш призведе до помилки.
