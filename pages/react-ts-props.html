1. Опис пропсів

Пропси описують окремим типом (через type або interface) і вказують його в сигнатурі компонента.

type UserCardProps = {
  name: string;
  age: number;
  city: string;
};

function UserCard({ name, age, city }: UserCardProps) {
  return (
    <div>
      <h2>{name}</h2>
      <p>{age} років, {city}</p>
    </div>
  );
}

type чи interface для пропсів — питання смаку; обидва працюють. Часта угода: interface для публічних API-компонентів, type — для локальних. Головне — однаково в межах проєкту.

2. Необов'язкові та значення за замовчуванням

type ButtonProps = {
  label: string;
  type?: 'button' | 'submit';   // ? — необов'язковий
  disabled?: boolean;
};

function Button({ label, type = 'button', disabled = false }: ButtonProps) {
  return <button type={type} disabled={disabled}>{label}</button>;
}

'button' | 'submit' — об'єднання літералів: TS дозволить лише ці два рядки, і редактор підкаже варіанти.

3. children

Найзручніший тип для вмісту компонента — React.ReactNode (він охоплює рядки, числа, елементи, масиви, null).

type CardProps = {
  title: string;
  children: React.ReactNode;
};

function Card({ title, children }: CardProps) {
  return (
    <section>
      <h3>{title}</h3>
      {children}
    </section>
  );
}

4. Пропси-функції (колбеки)

type SearchProps = {
  onSearch: (query: string) => void;   // нічого не повертає
  onClose?: () => void;
};

5. Розширення пропсів HTML-елемента

Щоб компонент-обгортка приймав усі стандартні атрибути (напр. кнопки), успадкуй їх через ComponentProps:

type Props = React.ComponentProps<'button'> & {
  variant: 'primary' | 'ghost';
};

function MyButton({ variant, ...rest }: Props) {
  return <button className={variant} {...rest} />;
}
// тепер працюють onClick, disabled, type — усе, що має <button>
