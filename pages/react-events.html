1. Обробники подій

Події в React підключають через пропси в camelCase: onClick, onChange, onSubmit. У проп передають функцію (а не її виклик).

function Button() {
  function handleClick() {
    console.log('Клік!');
  }

  return <button onClick={handleClick}>Натисни</button>;
}

Передавайте саме функцію: onClick={handleClick}. Якщо написати onClick={handleClick()} — функція викличеться одразу під час рендеру, а не при кліку.

2. Передавання аргументів

Щоб передати аргумент, обгортають виклик у стрілкову функцію.

function List() {
  function remove(id) {
    console.log('Видалити', id);
  }

  return <button onClick={() => remove(5)}>Видалити</button>;
}

3. Обʼєкт події

Обробник отримує синтетичну подію React — обгортку над нативною, з тим самим інтерфейсом (preventDefault, target тощо).

function Input() {
  function handleChange(event) {
    console.log('Значення:', event.target.value);
  }

  return <input onChange={handleChange} />;
}

4. Скасування дії за замовчуванням

function SearchForm() {
  function handleSubmit(event) {
    event.preventDefault(); // не перезавантажувати сторінку
    console.log('Пошук');
  }

  return (
    <form onSubmit={handleSubmit}>
      <input name="q" />
      <button>Знайти</button>
    </form>
  );
}

5. Зміна стану в обробнику

Найчастіше обробник події оновлює стан — це запускає перерендер.

function Toggle() {
  const [on, setOn] = useState(false);
  return (
    <button onClick={() => setOn((prev) => !prev)}>
      {on ? 'Увімкнено' : 'Вимкнено'}
    </button>
  );
}
