1. Вступ

У сучасному JavaScript з'явилася нова операція для роботи з ітеруючими об'єктами, такими як рядок, масив або об'єкт. Її функціонал і назва, на відміну від синтаксису, залежить від місця застосування.

2. Операція spread

... - spread, розпорошення. Дозволяє розпорошити колекцію елементів в іншу колекцію, зробивши копію оригінальної не зраджуючи її. При цьому, під час розпилення, якщо елемент колекції примітив - створюється копія елемента, в разі складного типу створюється посилання на оригінальний елемент.

Розпилення можна використовувати всього в 3-х ситуаціях:

  • Під час виклику функції, для передачі масиву елементів окремими аргументами
  • У літералі масиву, при створенні нового масиву
  • У літералі об'єкта, при створенні нового об'єкта

2.1. Розпилення аргументів

Уявімо ситуацію, коли у нас є масив температур за якийсь період, і необхідно програмно знайти найменшу температуру в масиві використовуючи метод Math.min (), який очікує кілька аргументів, а не масив.

Якщо передати просто масив, отримаємо NaN, тому щоMath.min ()не вміє працювати з масивом.

const temperatures = [18, 14, 12, 21, 17, 29];

const min = Math.min(temperatures); // NaN

В цьому випадку нам допоможе операція розпилення, щоб передати елементи масиву окремими аргументами при виконанні функції.

const temperatures = [18, 14, 12, 21, 17, 29];

const min = Math.min(...temperatures); // 12

Тобто запис Math.min (... [18, 14, 12, 21, 17, 29]) аналогічний Math.min (18, 14, 12, 21, 17, 29), операція spread застосувала масив елементів в аргументи функції.

2.2. Розпилення масивів

При роботі з масивами, можна скопіювати елементи одного масиву в інший. Масив copyOfHouses буде незалежною копією масивуhouses і відповідно зміни в будь-якому з них не відобразяться в іншому.

const houses = ['Arryn', 'Frey', 'Greyjoy', 'Stark', 'Lannister', 'Tyrell'];
const copyOfHouses = [...houses];

console.log(houses); // ['Arryn','Frey','Greyjoy','Stark','Lannister','Tyrell']
console.log(copyOfHouses); // ['Arryn','Frey','Greyjoy','Stark','Lannister','Tyrell']
console.log(houses === copyOfHouses); // false - різні посилання

Те ж саме можна було зробити використовуючи метод slice (), операція spread просто дозволяє записувати це більш коротко, особливо коли кілька розпилень.

const houses = ['Arryn', 'Frey', 'Greyjoy', 'Stark', 'Lannister', 'Tyrell'];
const slicedCopyOfHouses = houses.slice();

console.log(houses); // ['Arryn','Frey','Greyjoy','Stark','Lannister','Tyrell']
console.log(slicedCopyOfHouses); // ['Arryn','Frey','Greyjoy','Stark','Lannister','Tyrell']

При цьому можна додавати і видаляти елементи при створенні нового масиву.

const houses = ['Arryn', 'Frey', 'Greyjoy', 'Stark', 'Lannister', 'Tyrell'];
const completeHouses = [...houses, 'Targaryen'];

console.log(houses); // ['Arryn','Frey','Greyjoy','Stark','Lannister','Tyrell']
console.log(completeHouses); // ['Arryn','Frey','Greyjoy','Stark','Lannister','Tyrell','Targaryen']

Можна дуже зручно з'єднувати кілька масивів в один новий. Порядок розпилення вихідних масивів впливає на порядок елементів в результативному масиві.

const firstBatch = ['Arryn', 'Frey', 'Greyjoy'];
const secondBatch = ['Stark', 'Lannister', 'Tyrell'];

const houses = [...firstBatch, ...secondBatch];

console.log(houses); // ['Arryn','Frey','Greyjoy','Stark','Lannister','Tyrell']

Можна використовувати класичні методи масиву на кшталт slice () в комбінації з операцією spread. Всі хто дивився серіал Game of Thrones знають, що ніхто крім сім'ї Ланістерів не платить за борги. Зробимо масив, який містить всі сім'ї, крім Ланістерів.

const houses = ['Arryn', 'Frey', 'Greyjoy', 'Stark', 'Lannister', 'Tyrell'];
const housesInDebt = [...houses.slice(0, 4), ...houses.slice(5)];

console.log(housesInDebt); // ['Arryn','Frey','Greyjoy','Stark','Tyrell']

Можна оновлювати елементи НЕ змінюючи оригінальний масив, а створюючи новий з Оновлення значень.

const houses = ['Arryn', 'Frey', 'Greyjoy', 'Stark', 'Lannister', 'Tyrell'];

// Вертикальний запис зручніше для читання
const updatedHouses = [
  ...houses.slice(0, 1),
  'Frey of the Crossing',
  ...houses.slice(2),
];

console.log(updatedHouses);
// ['Arryn', 'Frey of the Crossing', 'Greyjoy', 'Stark', 'Lannister', 'Tyrell']

2.3. Розпилення об'єктів

Для об'єктів, у майбутніх стандартах мови, буде так само затверджена операція Spread. А в сучасних браузерах, і використовуючи такі інструменти як Babel, його можна застосовувати вже зараз. Він дозволяє розпорошувати властивості одного об'єкта в інший.

Розпилення можна використовувати як заміну Object.assign (), тобто коли необхідно створити новий об'єкт або оновити вже існуючий за результатом злиття декількох інших об'єктів.

const a = { x: 1, y: 2 };
const b = { x: 0, z: 3 };

const c = Object.assign({}, a, b);
console.log(c); // {x: 0, y: 2, z: 3}

// Те ж саме використовуючи операцію spread
const d = { ...a, ...b };

console.log(d); // {x: 0, y: 2, z: 3}

Під час злиття можна додавати властивості в довільне місце. Але слід пам'ятати, що властивості розпорошуючого об'єкта можуть перезаписати значення існуючої властивості, якщо імена ключів збігаються, а розпорошення відбувається після вказівки властивості

const a = { x: 1, y: 2 };
const b = { x: 0, z: 3 };

const c = { x: 5, j: 10, ...a, z: 15, ...b };

console.log(c); // {x: 0, j: 10, y: 2, z: 3}

Створюємо химеру :)

const lion = { hasTail: true, legs: 4 };
const eagle = { canFly: true };

const chimera = { ...lion, ...eagle };

console.log(chimera); // {hasTail: true, legs: 4, canFly: true}

3. Операція rest

... - rest, збір. Дозволяє скопіювати групу елементів колекції в нову колекцію, не змінюючи оригінальну. При цьому, під час збору, якщо елемент колекції примітив - створюється копія елемента, в разі складного типу створюється посилання на оригінальний елемент.

Використовується в підпису функції для збору аргументів або при деструктуризації, для зберігання залишку елементів.

деструктуризація масивів і об'єктів описана в наступному розділі, а функції розглянемо зараз.

Є функція add, яка складає довільну кількість аргументів. Отримати доступ до всіх аргументів можна використовуючи спеціальну змінну arguments, але в стрілкових функціях її немає, а в звичайних функціях вона псевдомасив. Використовуючи операцію rest можна зібрати всі аргументи в масив прямо в підпису функції.

const add = function (...args) {
  console.log(args); // масив всіх аргументів
};

add(1, 2, 3);
add(1, 2, 3, 4, 5);

Тепер припустимо, що функція add не просто рахує суму аргументів, а ще отримує першим аргументом число, яке необхідно додавати до кожного подальшого аргументу при обчисленні суми.

Використовуючи rest можна взяти тільки ту частину аргументів, яка необхідна, оголосивши параметри до rest. Всі аргументи, для яких будуть оголошені параметри, передадуть їм свої значення, всі інші будуть поміщені в масив Args.

Операція rest збирає решту аргументів і тому має йти останньою в підпису функції, інакше буде помилка. 

const add = function (value, ...args) {
  console.log(value); // перший аргумент
  console.log(args); // масив всіх інших аргументів
};

add(10, 1, 2, 3);
add(15, 1, 2, 3, 4, 5);
