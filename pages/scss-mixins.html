1. Міксини: @mixin і @include

Міксин — це набір стилів, який можна перевикористати в різних селекторах. Оголошують через @mixin, підключають через @include. 

@mixin flex-center {
  display: flex;
  align-items: center;
  justify-content: center;
}

.modal { @include flex-center; }
.hero  { @include flex-center; min-height: 100vh; }

2. Параметри й значення за замовчуванням

@mixin button($bg, $color: #fff) {
  background: $bg;
  color: $color;
  padding: .5rem 1rem;
  border-radius: 6px;
}

.btn-primary { @include button(#2563eb); }
.btn-warning { @include button(#f59e0b, #111); }

3. Практичний приклад: брейкпоінти

Часта задача — зробити зручні медіазапити:

@mixin respond($bp) {
  @if $bp == tablet {
    @media (min-width: 768px) { @content; }
  } @else if $bp == desktop {
    @media (min-width: 1024px) { @content; }
  }
}

.grid {
  grid-template-columns: 1fr;
  @include respond(tablet)  { grid-template-columns: 1fr 1fr; }
  @include respond(desktop) { grid-template-columns: repeat(4, 1fr); }
}

@content — це блок, який ви передаєте всередину міксина при виклику.

4. Функції: @function

Міксин вставляє стилі, а функція повертає значення.

@function rem($px, $base: 16) {
  @return ($px / $base) * 1rem;
}

.title { font-size: rem(24); } // 1.5rem

5. Наслідування: @extend і %placeholder

@extend дозволяє одному селектору перейняти стилі іншого. Найкраще — з плейсхолдером %, який сам по собі не потрапляє у CSS. 

%card-base {
  border-radius: 8px;
  box-shadow: 0 1px 3px rgba(0,0,0,.1);
  padding: 1rem;
}

.product { @extend %card-base; }
.article { @extend %card-base; }

Коли брати міксин, а коли @extend? Якщо потрібні параметри або медіазапити — міксин. Якщо просто ділите однаковий блок стилів між селекторами без параметрів — %placeholder + @extend дає компактніший CSS.
