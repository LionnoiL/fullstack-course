1. Кольори

Колір задають кількома способами:

color: red;                 /* назва */
color: #2563eb;             /* HEX */
color: rgb(37, 99, 235);    /* RGB */
color: rgba(0, 0, 0, 0.5);  /* з прозорістю */
color: hsl(217, 83%, 53%);  /* відтінок/насиченість/яскравість */

2. Фон

.hero {
  background-color: #f5f5f3;
  background-image: url("bg.jpg");
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
}

/* градієнт */
.card {
  background: linear-gradient(to right, #2563eb, #7c3aed);
}

3. Властивості шрифту

.text {
  font-family: -apple-system, "Segoe UI", Roboto, sans-serif;
  font-size: 16px;
  font-weight: 600;   /* 400 — звичайний, 700 — жирний */
  font-style: italic;
  line-height: 1.6;   /* міжрядковий інтервал */
}

У font-family вказують «стек» шрифтів через кому — браузер бере перший доступний. Наприкінці завжди ставлять загальний тип (sans-serif, serif) як запасний варіант.

4. Оформлення тексту

.title {
  text-align: center;         /* left | right | justify */
  text-decoration: underline; /* none — прибрати підкреслення */
  text-transform: uppercase;  /* ВЕЛИКІ літери */
  letter-spacing: 0.05em;     /* відстань між літерами */
}

5. Підключення шрифтів

<!-- Google Fonts у head -->
<link href="https://fonts.googleapis.com/css2?family=Inter&display=swap" rel="stylesheet">
body { font-family: "Inter", sans-serif; }
