Практика: CSS Modules та CSS-in-JS

Створи React-проєкт на Vite (CSS Modules працюють одразу). Для CSS-in-JS встанови styled-components. Мета — відчути обидва підходи на тому самому компоненті й порівняти.

Завдання 1. Кнопка на CSS Modules

Зроби компонент Button зі стилями у файлі Button.module.css: базовий вигляд + варіант primary. Підключи класи через імпортований обʼєкт styles і переконайся в інспекторі, що імена класів у розмітці унікальні (з хешем).

Рішення 
/* Button.module.css */
.button { padding: .6rem 1.2rem; border: none; border-radius: 6px; cursor: pointer; }
.primary { background: #2563eb; color: #fff; }

// Button.jsx
import styles from './Button.module.css';
export default function Button({ children }) {
  return <button className={`${styles.button} ${styles.primary}`}>{children}</button>;
}

Завдання 2. composes та умовні класи

Додай варіант danger через composes: button (щоб не дублювати базові стилі). Далі зроби «вкладку», що отримує проп active, і підключай клас active умовно через clsx.

Підказка

composes: button; усередині .danger. Для умовних класів: clsx(styles.tab, { [styles.active]: active }).

Рішення 
import clsx from 'clsx';
import styles from './Tab.module.css';

function Tab({ active, children }) {
  return <button className={clsx(styles.tab, { [styles.active]: active })}>{children}</button>;
}

Завдання 3. Та сама кнопка на styled-components

Перепиши Button через styled.button: базові стилі + :hover. Зроби варіант залежним від пропа $variant ('primary'/'danger'). Порівняй відчуття з CSS Modules.

Рішення 
import styled from 'styled-components';

const Button = styled.button`
  padding: .6rem 1.2rem;
  border: none; border-radius: 6px; color: #fff; cursor: pointer;
  background: ${(p) => (p.$variant === 'danger' ? '#dc2626' : '#2563eb')};
  &:hover { filter: brightness(0.9); }
`;
// <Button $variant="danger">Видалити</Button>

Завдання 4. Тема через ThemeProvider

Обгорни застосунок у ThemeProvider з обʼєктом теми (колір-акцент, радіус) і зроби так, щоб Button брав кольори з props.theme. Переконайся, що зміна теми міняє вигляд усіх кнопок.

Підказка

const theme = { colors: { accent: '#2563eb' }, radius: '6px' }; у стилях — ${(p) => p.theme.colors.accent}.

Завдання 5. Zero-runtime (виклик)

Спробуй vanilla-extract: опиши стилі кнопки у button.css.ts через style({...}) й підключи згенерований клас у компоненті (як у CSS Modules). Зверни увагу, що бібліотека не потрапляє в рантайм-бандл — у браузер іде готовий CSS.

Занотуй для себе: який підхід зручніший саме тобі й чому. У Vite-SPA життєздатні всі; у Next.js App Router віддавай перевагу CSS Modules або zero-runtime через Server Components.
