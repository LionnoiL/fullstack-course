1. Локатори — як знайти елемент

Локатор описує, як знайти елемент на сторінці. Playwright радить шукати так, як елемент бачить користувач — за роллю, текстом, підписом — а не за крихкими CSS-класами.

page.getByRole('button', { name: 'Увійти' });   // за ARIA-роллю + назвою
page.getByText('Ласкаво просимо');               // за текстом
page.getByLabel('Email');                        // поле за <label>
page.getByPlaceholder('Пошук...');               // за placeholder
page.getByRole('link', { name: 'Головна' });
page.getByTestId('cart-total');                  // за data-testid (запасний варіант)

Пріоритет: getByRole → getByLabel/getByPlaceholder → getByText → getByTestId. Пошук за роллю ще й перевіряє доступність: якщо кнопку не знайдено за роллю, можливо, вона недоступна для читалок екрана.

2. Дії з елементами

await page.getByRole('button', { name: 'Додати' }).click();
await page.getByLabel('Email').fill('ann@mail.com');   // ввести текст
await page.getByLabel('Згода').check();                // чекбокс
await page.getByRole('combobox').selectOption('ua');   // select
await page.getByRole('link', { name: 'Профіль' }).hover();
await page.keyboard.press('Enter');

3. Авто-очікування — головна суперсила

Перед кожною дією Playwright сам чекає, поки елемент існує, видимий, стабільний і готовий приймати події. Не треба вручну ставити sleep.

// НЕ роби так — крихко й повільно:
await page.waitForTimeout(3000);
await page.getByRole('button').click();

// достатньо просто:
await page.getByRole('button', { name: 'Зберегти' }).click(); // сам дочекається

waitForTimeout (фіксована пауза) — джерело «мерехтливих» (flaky) тестів: на швидкій машині зайве очікування, на повільній — замало. Довіряй авто-очікуванню й web-first перевіркам (наступний урок).

4. Кілька елементів і фільтри

Якщо локатор збігається з кількома елементами, уточнюй його, а не хапай «перший-ліпший»:

// уточнити фільтром за текстом усередині
page.getByRole('listitem').filter({ hasText: 'Молоко' });

// конкретний за індексом (уникай, якщо можна уточнити змістовно)
page.getByRole('listitem').first();
page.getByRole('listitem').nth(2);

// порахувати
const count = await page.getByRole('listitem').count();

5. Пошук усередині контейнера

Локатори ланцюжкові — можна звузити пошук до частини сторінки:

const card = page.getByRole('article').filter({ hasText: 'Замовлення #42' });
await card.getByRole('button', { name: 'Скасувати' }).click(); // кнопка саме в цій картці

Елементи знаходимо й діємо — далі навчимося перевіряти результат.
