1. Інтерфейси

Інтерфейс описує форму обʼєкта — які поля він має і якого типу. Це основний спосіб типізувати обʼєкти в TypeScript.

interface User {
  id: number;
  name: string;
  email?: string;      // необовʼязкове поле
  readonly createdAt: Date; // не можна змінити після створення
}

const user: User = {
  id: 1,
  name: 'Ada',
  createdAt: new Date(),
};

user.id = 2;        // ✅
user.createdAt = new Date(); // ❌ readonly

2. type — псевдонім типу

type дозволяє дати імʼя будь-якому типу: обʼєкту, обʼєднанню, примітиву.

type ID = number | string;

type Point = {
  x: number;
  y: number;
};

const id: ID = 'abc';
const p: Point = { x: 1, y: 2 };

3. interface чи type?

  • interface — для опису форми обʼєктів; можна розширювати (extends) і доповнювати;
  • type — універсальніший: обʼєднання, перетини, примітиви, кортежі.

Загальне правило: для форми обʼєктів беріть interface, для всього іншого (обʼєднання, псевдоніми примітивів) — type. У більшості випадків це справа смаку і команда обирає щось одне для консистентності.

4. Розширення та композиція

interface Animal {
  name: string;
}

interface Dog extends Animal {
  breed: string;
}

const rex: Dog = { name: 'Rex', breed: 'Хаскі' };

// Те саме через type і перетин (&)
type Cat = Animal & { indoor: boolean };

5. Методи та індексні сигнатури

interface Repository {
  save(item: string): void;       // метод
  count: number;                  // властивість
  [key: string]: unknown;         // індексна сигнатура — довільні ключі
}
