1. Коли localStorage замало

localStorage простий, але обмежений: лише рядки, ~5 МБ, синхронний (блокує потік) і без пошуку. Для великих обсягів структурованих даних, офлайн-кешу чи складних запитів потрібна повноцінна база — IndexedDB.

  • зберігає обʼєкти (не лише рядки), включно з Blob/файлами;
  • асинхронна — не блокує UI;
  • великий обсяг (сотні МБ і більше);
  • індекси для пошуку за полями.

«Сирий» IndexedDB API — багатослівний (події, транзакції). На практиці майже завжди беруть тонку обгортку idb (промісами замість подій) — приклад нижче. Але корисно розуміти, як воно влаштоване під капотом.

2. Поняття

  • база має версію; зміна схеми — через підвищення версії;
  • object store — аналог таблиці/колекції; зберігає обʼєкти за ключем;
  • транзакція — усі читання/записи йдуть у межах транзакції;
  • індекс — для пошуку за не-ключовим полем.

3. Створення бази (сирий API)

const request = indexedDB.open('notes-db', 1);

request.onupgradeneeded = (e) => {
  const db = e.target.result;
  // створюємо сховище один раз (або при новій версії)
  const store = db.createObjectStore('notes', { keyPath: 'id', autoIncrement: true });
  store.createIndex('by_tag', 'tag'); // індекс для пошуку за tag
};

request.onsuccess = (e) => {
  const db = e.target.result;
  // працюємо з db...
};

4. Простіше з бібліотекою idb

npm install idb
import { openDB } from 'idb';

const db = await openDB('notes-db', 1, {
  upgrade(db) {
    const store = db.createObjectStore('notes', { keyPath: 'id', autoIncrement: true });
    store.createIndex('by_tag', 'tag');
  },
});

// додати
await db.add('notes', { text: 'Купити молоко', tag: 'побут' });

// прочитати всі
const all = await db.getAll('notes');

// знайти за індексом
const home = await db.getAllFromIndex('notes', 'by_tag', 'побут');

// оновити / видалити
await db.put('notes', { id: 1, text: 'Оновлено', tag: 'побут' });
await db.delete('notes', 1);

5. Типові застосування

  • офлайн-дані: кеш API-відповідей, чернетки, черга дій для відправки при поверненні мережі;
  • важкі дані: збережені файли, зображення, великі списки;
  • PWA: разом із Service Worker дає повноцінну офлайн-роботу (наступні уроки).

IndexedDB живе у браузері користувача й не синхронізується сама. Це кеш/ локальне сховище, а не заміна серверній БД. Чутливих даних без шифрування там не тримай — інші скрипти сайту й користувач мають доступ.
