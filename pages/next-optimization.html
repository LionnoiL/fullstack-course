1. Вбудована оптимізація

Next.js бере на себе багато оптимізацій «з коробки»: розбиття коду по сторінках, оптимізацію зображень і шрифтів, префетчинг. Розробнику лишається користуватися вбудованими компонентами.

2. Компонент Image

next/image автоматично змінює розмір, стискає, конвертує у сучасні формати й ліниво завантажує зображення. 

import Image from 'next/image';

export default function Avatar() {
  return (
    <Image
      src="/avatar.png"
      alt="Аватар"
      width={64}
      height={64}
    />
  );
}

3. Компонент Font

import { Inter } from 'next/font/google';

const inter = Inter({ subsets: ['latin', 'cyrillic'] });

export default function RootLayout({ children }) {
  return (
    <html lang="uk" className={inter.className}>
      <body>{children}</body>
    </html>
  );
}

next/font завантажує шрифти локально під час збірки — без запиту до Google на боці користувача. Це швидше й краще для приватності.

4. Збірка

npm run build   // продакшн-збірка
npm run start   // запуск зібраного застосунку

5. Деплой

Найпростіший шлях — Vercel (творці Next.js): підключаєш Git-репозиторій, і кожен пуш автоматично збирається й публікується. Next.js також працює на інших платформах і в Docker (див. розділ «Деплой»). 

npm i -g vercel
vercel        // деплой у кілька команд
