Практика: Next.js

Створи застосунок командою npx create-next-app@latest або відкрий шаблон на StackBlitz (Next.js).

Завдання 1. Кілька сторінок

Додай маршрути /, /about і /blog через App Router та спільну навігацію у кореневому лейауті з компонентом Link.

Рішення (структура) 
app/
├─ layout.jsx      // <nav> з <Link> + {children}
├─ page.jsx        // /
├─ about/page.jsx  // /about
└─ blog/page.jsx   // /blog

Завдання 2. Динамічний маршрут із даними

Зроби динамічний маршрут /blog/[slug] (серверний компонент), що бере slug із params, серверно завантажує відповідний пост через fetch і показує його заголовок і текст. Переконайся, що дані тягнуться на сервері (без useEffect), а різні slug дають різні сторінки.

Рішення 
// app/blog/[slug]/page.jsx
export default async function Post({ params }) {
  const res = await fetch(`https://api.example.com/posts/${params.slug}`);
  const post = await res.json();
  return (
    <article>
      <h1>{post.title}</h1>
      <p>{post.body}</p>
    </article>
  );
}
