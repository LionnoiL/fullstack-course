Практика: E2E-тести (Playwright)

Візьми свій застосунок (напр. fullstack-нотатник або To-Do) і додай E2E-тести. Ініціалізуй Playwright (npm init playwright@latest), налаштуй baseURL і webServer у конфігу.

Завдання 1. Перший тест і запуск

Напиши тест, що відкриває головну сторінку й перевіряє заголовок або видимий елемент. Запусти його в UI-режимі (--headed/--ui) і подивись HTML-звіт.

Рішення 
import { test, expect } from '@playwright/test';

test('головна відкривається', async ({ page }) => {
  await page.goto('/');
  await expect(page.getByRole('heading', { level: 1 })).toBeVisible();
});

Завдання 2. Сценарій із формою

Протестуй додавання елемента: заповни поле, натисни кнопку й перевір, що новий елемент зʼявився у списку. Використай локатори за роллю/підписом, без waitForTimeout.

Рішення 
test('додавання нотатки', async ({ page }) => {
  await page.goto('/');
  await page.getByLabel('Текст нотатки').fill('Купити молоко');
  await page.getByRole('button', { name: 'Додати' }).click();
  await expect(page.getByText('Купити молоко')).toBeVisible();
});

Завдання 3. Codegen

Запусти npx playwright codegen на своєму застосунку, «клікни» сценарій вручну й отримай згенерований код. Почисти локатори й перетвори на повноцінний тест.

Підказка

npx playwright codegen http://localhost:5173. Заміни автозгенеровані загальні локатори на змістовні getByRole/getByLabel, додай expect-перевірки.

Завдання 4. Мокання мережі

Заміни реальний запит до API фіктивною відповіддю через page.route і переконайся, що застосунок показує саме ці дані. Так тест не залежить від бекенду.

Рішення 
await page.route('**/api/notes', (route) =>
  route.fulfill({ json: [{ id: 1, text: 'Тестова нотатка' }] }));
await page.goto('/');
await expect(page.getByText('Тестова нотатка')).toBeVisible();

Завдання 5. Авторизація + CI (виклик)

Зроби setup-проєкт, що логіниться один раз і зберігає сесію через storageState, а решта тестів стартують уже залогіненими. Додай GitHub Actions workflow, що ганяє тести на кожен PR і зберігає звіт як артефакт.

Підказка

Після входу — await page.context().storageState({ path: 'playwright/.auth/user.json' }); у конфігу — use: { storageState: '...' }. У CI не забудь npx playwright install --with-deps.

Покрий E2E-тестами ключові шляхи свого проєкту (вхід, створення/видалення запису), а дрібну логіку лиши unit-тестам із розділу «Тестування». Постав тести в CI — і кожен PR перевірятиметься автоматично.
