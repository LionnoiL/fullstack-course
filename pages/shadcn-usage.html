1. Ініціалізація

У проєкті на React + Tailwind (напр. Vite або Next.js) запусти майстер — він налаштує теми, шляхи й базові файли:

npx shadcn@latest init

2. Додавання компонентів

Кожен компонент «встановлюють» окремою командою — CLI кладе його код у components/ui/:

npx shadcn@latest add button
npx shadcn@latest add dialog input

3. Використання

Далі це звичайний імпорт із твоєї ж папки — не з node_modules:

import { Button } from '@/components/ui/button';

function App() {
  return (
    <div>
      <Button>За замовчуванням</Button>
      <Button variant="ghost" size="sm">Привид</Button>
    </div>
  );
}

4. Теми через CSS-змінні

Кольори shadcn/ui задаються дизайн-токенами (CSS-змінними) — міняєш їх і оновлюється весь UI. Темна тема — окремий набір значень.

:root {
  --primary: 222 47% 40%;      /* HSL-компоненти */
  --radius: 0.5rem;
}
.dark {
  --primary: 222 47% 60%;
}

Оскільки компоненти живуть у твоєму коді, кастомізація — це просто редагування файлу в components/ui/. Не подобається відступ у кнопки? Зміни клас прямо там — жодних обхідних шляхів навколо чужого API.

5. Редагуй сміливо

Згенерований компонент — стартова точка, а не догма. Додавай варіанти, прибирай зайве, підлаштовуй під свою дизайн-систему. Це і є суть підходу.
