1. Готові утилітарні типи

TypeScript має набір вбудованих дженерик-типів, які перетворюють один тип на інший. Вони економлять час і уникають дублювання описів.

interface User {
  id: number;
  name: string;
  email: string;
}

2. Partial і Required

Partial<T> робить усі поля необовʼязковими, Required<T> — навпаки, обовʼязковими.

// Усі поля необовʼязкові — зручно для оновлення
function update(id: number, changes: Partial<User>) { /* ... */ }

update(1, { name: 'Нове імʼя' }); // достатньо одного поля

3. Pick і Omit

Pick<T, K> залишає лише вказані поля, Omit<T, K> — усі, крім вказаних.

type UserPreview = Pick<User, 'id' | 'name'>;
// { id: number; name: string }

type UserWithoutId = Omit<User, 'id'>;
// { name: string; email: string }

4. Record

Record<K, V> описує обʼєкт із ключами типу K і значеннями типу V.

type Roles = Record<'admin' | 'user', boolean>;

const access: Roles = {
  admin: true,
  user: false,
};

// Словник будь-яких рядкових ключів
const prices: Record<string, number> = { apple: 10, pear: 15 };

5. Readonly, Exclude, ReturnType та інші

type Frozen = Readonly<User>;          // усі поля readonly

type T1 = Exclude<'a' | 'b' | 'c', 'b'>; // 'a' | 'c'
type T2 = Extract<'a' | 'b', 'b' | 'x'>; // 'b'
type T3 = NonNullable<string | null>;    // string

function make() {
  return { ok: true };
}
type Result = ReturnType<typeof make>;  // { ok: boolean }

Замість того щоб описувати схожі типи вручну, майже завжди можна скомбінувати utility types з базового. Це зменшує дублювання: змінили User — похідні типи оновилися самі.
