1. Object.groupBy — групування (ES2024)

Дуже частий сценарій — згрупувати масив за ознакою. Раніше писали reduce вручну; тепер є вбудований Object.groupBy(items, fn): fn повертає ключ групи, а результат — обʼєкт «ключ → масив елементів». 

const products = [
  { name: 'Молоко', type: 'їжа' },
  { name: 'Хліб', type: 'їжа' },
  { name: 'Мило', type: 'побут' },
];

const byType = Object.groupBy(products, (p) => p.type);
// { 'їжа': [Молоко, Хліб], 'побут': [Мило] }

Якщо ключі — не рядки (обʼєкти, числа з важливим типом), бери Map.groupBy: той самий принцип, але повертає Map і зберігає тип ключа.

2. structuredClone — справжня глибока копія

Трюк JSON.parse(JSON.stringify(obj)) ламається на Date, Map, Set і циклічних посиланнях. Вбудований structuredClone(value) робить глибоку копію правильно: 

const original = {
  date: new Date(),
  set: new Set([1, 2]),
  nested: { a: 1 },
};

const copy = structuredClone(original);
copy.nested.a = 99;
console.log(original.nested.a); // 1 — оригінал незалежний
console.log(copy.date instanceof Date); // true — Date збережено

structuredClone не копіює функції та DOM-вузли — кине помилку. Для даних (стан, конфіги) — ідеально; для обʼєктів із методами — ні.

3. Object.hasOwn — безпечна перевірка поля (ES2022)

Заміна незручному obj.hasOwnProperty(key): Object.hasOwn(obj, key) працює й для обʼєктів без прототипу та безпечніша. 

const obj = { a: 1 };
Object.hasOwn(obj, 'a');        // true
Object.hasOwn(obj, 'toString'); // false — успадковане не рахується

// проти старого способу, що ламається на Object.create(null):
const dict = Object.create(null);
dict.hasOwnProperty; // undefined — метод відсутній!
Object.hasOwn(dict, 'x'); // працює завжди

4. Нагадування: Object.entries / fromEntries

Разом із групуванням часто йдуть перетворення обʼєкт↔масив пар:

Object.entries({ a: 1, b: 2 });        // [['a',1],['b',2]]
Object.fromEntries([['a', 1], ['b', 2]]); // { a: 1, b: 2 }
// зручно фільтрувати/мапити обʼєкт:
const filtered = Object.fromEntries(
  Object.entries({ a: 1, b: 0 }).filter(([, v]) => v > 0),
); // { a: 1 }
