1. Партіали

Великі стилі розбивають на окремі файли-партіали. Ім'я партіала починається з підкреслення (_variables.scss) — це сигнал компілятору не робити з нього окремий .css, а лише підключати в інші файли. 

styles/
  _variables.scss   // змінні, палітра
  _mixins.scss      // міксини
  _buttons.scss     // компонент
  main.scss         // збирає все докупи

2. @use — підключення модуля

Сучасний спосіб підключати партіали — правило @use. Воно імпортує файл як модуль зі своїм простором імен. 

// main.scss
@use "variables";
@use "buttons";

// доступ через простір імен (ім'я файлу без _ і розширення)
.link { color: variables.$primary; }

Простір імен можна перейменувати або прибрати:

@use "variables" as v;      // v.$primary
@use "variables" as *;      // $primary без префікса

3. @forward — реекспорт

@forward робить вміст одного партіала доступним для тих, хто підключить поточний файл. Так будують «індексний» файл бібліотеки стилів. 

// styles/_index.scss
@forward "variables";
@forward "mixins";

// деінде достатньо одного рядка:
@use "styles"; // отримали і змінні, і міксини

4. Вбудовані модулі

Sass має стандартну бібліотеку — її модулі теж підключають через @use:

@use "sass:math";
@use "sass:color";

.box {
  width: math.div(100%, 3);
  background: color.adjust(#2563eb, $lightness: -10%);
}

Старе правило @import оголошено застарілим і поступово вилучається із Sass. У нових проєктах використовуйте @use / @forward: вони уникають конфліктів імен і не підключають один файл багато разів.
