1. Що таке декоратори

Декоратор — це функція, яку можна «навісити» на клас, метод, властивість чи параметр, щоб змінити або доповнити їхню поведінку. Декоратори активно використовують фреймворки на кшталт Angular і NestJS.

Синтаксис декораторів довго був експериментальним. У TypeScript 5+ реалізовано стандартні декоратори зі специфікації ECMAScript. Приклади нижче показують загальну ідею; конкретне API залежить від версії та налаштувань.

2. Увімкнення

Для «класичних» декораторів у tsconfig.json вмикають опцію:

{
  "compilerOptions": {
    "experimentalDecorators": true,
    "emitDecoratorMetadata": true
  }
}

3. Декоратор класу

Декоратор класу отримує конструктор і може його змінити чи розширити.

function sealed(constructor: Function) {
  Object.seal(constructor);
  Object.seal(constructor.prototype);
}

@sealed
class Product {
  constructor(public name: string) {}
}

4. Декоратор методу

Отримує доступ до дескриптора методу — можна «обгорнути» оригінальну логіку.

function log(target: unknown, key: string, descriptor: PropertyDescriptor) {
  const original = descriptor.value;
  descriptor.value = function (...args: unknown[]) {
    console.log(`Виклик ${key} з`, args);
    return original.apply(this, args);
  };
}

class Calculator {
  @log
  add(a: number, b: number) {
    return a + b;
  }
}

5. Фабрика декораторів

Щоб передати декоратору параметри, його загортають у функцію, що повертає декоратор.

function role(name: string) {
  return function (constructor: Function) {
    constructor.prototype.requiredRole = name;
  };
}

@role('admin')
class AdminPanel {}
