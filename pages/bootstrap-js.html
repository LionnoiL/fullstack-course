1. Інтерактивні компоненти

Частина компонентів (модалки, випадайки, акордеони, підказки) потребує JavaScript. Для них треба підключити JS-бандл Bootstrap. Керувати ними можна двома способами: через data-bs-* атрибути або з коду. 

<script src="https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/js/bootstrap.bundle.min.js"></script>

2. Модальне вікно

<!-- кнопка-тригер -->
<button class="btn btn-primary" data-bs-toggle="modal" data-bs-target="#myModal">
  Відкрити
</button>

<!-- саме вікно -->
<div class="modal fade" id="myModal" tabindex="-1">
  <div class="modal-dialog">
    <div class="modal-content">
      <div class="modal-header">
        <h5 class="modal-title">Заголовок</h5>
        <button class="btn-close" data-bs-dismiss="modal"></button>
      </div>
      <div class="modal-body">Вміст вікна</div>
    </div>
  </div>
</div>

3. Випадаюче меню

<div class="dropdown">
  <button class="btn btn-secondary dropdown-toggle" data-bs-toggle="dropdown">
    Меню
  </button>
  <ul class="dropdown-menu">
    <li><a class="dropdown-item" href="#">Пункт 1</a></li>
    <li><a class="dropdown-item" href="#">Пункт 2</a></li>
  </ul>
</div>

4. Акордеон / згортання

<button class="btn btn-outline-primary" data-bs-toggle="collapse" data-bs-target="#more">
  Показати більше
</button>
<div class="collapse" id="more">
  <div class="card card-body">Прихований вміст</div>
</div>

5. Керування з JavaScript

// створити й показати модалку програмно
const modal = new bootstrap.Modal('#myModal');
modal.show();
modal.hide();

// підказки треба ініціалізувати вручну
const tooltip = new bootstrap.Tooltip('#myBtn');

Без підключеного JS-бандла інтерактивні компоненти просто не працюватимуть, хоч і виглядатимуть правильно. Це часта причина «нічого не відкривається».
