1. Файловий роутинг

У Next.js маршрути не описують у коді — вони визначаються структурою папок усередині app/. Тека стає сегментом URL, а файл page.jsx робить її доступною сторінкою.

app/page.jsx          →  /
app/blog/page.jsx     →  /blog
app/blog/new/page.jsx →  /blog/new

2. Динамічні маршрути

Квадратні дужки в назві теки роблять сегмент динамічним. Значення приходить у проп params.

// app/blog/[slug]/page.jsx  →  /blog/будь-що
export default function Post({ params }) {
  return <h1>Стаття: {params.slug}</h1>;
}
// app/shop/[...all]/page.jsx  → перехоплює всі вкладені сегменти
// /shop/a/b/c  →  params.all === ['a', 'b', 'c']

3. Спеціальні файли маршруту

  • page.jsx — сама сторінка (публічний URL);
  • layout.jsx — спільна оболонка для сегмента й вкладених;
  • loading.jsx — стан завантаження;
  • error.jsx — обробка помилок;
  • not-found.jsx — сторінка 404.

4. Групи маршрутів

Тека в круглих дужках групує файли без впливу на URL — зручно для організації.

app/(marketing)/about/page.jsx  →  /about
app/(shop)/cart/page.jsx        →  /cart

Файл loading.jsx автоматично показується, поки серверний компонент завантажує дані — це вбудований Suspense без ручного налаштування.
