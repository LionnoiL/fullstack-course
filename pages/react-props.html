1. Передавання даних через props

Props (властивості) — це спосіб передати дані від батьківського компонента до дочірнього. Виглядають як атрибути тега, а всередині компонента доступні як обʼєкт-аргумент. 

function Greeting(props) {
  return <h1>Привіт, {props.name}!</h1>;
}

function App() {
  return <Greeting name="Ada" />;
}

2. Деструктуризація пропсів

Зазвичай пропси одразу деструктуризують у сигнатурі — так код чистіший.

function UserCard({ name, age, city }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>{age} років, {city}</p>
    </div>
  );
}

<UserCard name="Ada" age={30} city="Kyiv" />;

Рядки передають у лапках (name="Ada"), а числа, булеві значення, масиви й обʼєкти — у фігурних дужках (age={30}).

3. Значення за замовчуванням

function Button({ label, type = 'button' }) {
  return <button type={type}>{label}</button>;
}

<Button label="OK" />;          // type = 'button'
<Button label="Send" type="submit" />;

4. Props лише для читання

Компонент не має права змінювати свої пропси — це односторонній потік даних згори вниз. Щоб змінити дані, батько передає нове значення. 

function Bad({ count }) {
  count = count + 1; // ❌ не можна мутувати props
  return <p>{count}</p>;
}

5. Передавання функцій

Через пропси передають і функції — так дитина повідомляє батька про подію.

function ActionButton({ onAction }) {
  return <button onClick={onAction}>Дія</button>;
}

function App() {
  return <ActionButton onAction={() => alert('Спрацювало!')} />;
}
