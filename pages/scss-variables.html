1. Змінні

Змінна в SCSS починається з $ і зберігає значення, яке потім можна перевикористати. Змінив одне місце — оновилося всюди.

$primary: #2563eb;
$radius: 8px;
$font-base: "Inter", sans-serif;

.button {
  background: $primary;
  border-radius: $radius;
  font-family: $font-base;
}

2. Типи даних

  • числа: 10, 1.5rem, 50%;
  • рядки: "Inter", bold;
  • кольори: #fff, red, rgba(0,0,0,.5);
  • булеві: true, false;
  • списки: 1px solid red, Inter, sans-serif;
  • мапи: пари ключ–значення (див. нижче).

3. Математика й операції

$gap: 16px;

.grid {
  gap: $gap;
  padding: $gap / 2;      // 8px
  margin-bottom: $gap * 2; // 32px
}

У сучасному Sass ділення роблять функцією math.div($a, $b) (після @use "sass:math";), бо символ / у CSS тепер має інше значення. Старий запис $gap / 2 ще працює, але вважається застарілим.

4. Мапи

Мапа зручна, щоб зберегти пов'язані значення разом — наприклад, палітру:

$colors: (
  "primary": #2563eb,
  "danger":  #dc2626,
  "muted":   #6b7280,
);

.alert {
  color: map-get($colors, "danger");
}

5. Значення за замовчуванням і глобальність

// !default — задати, лише якщо змінна ще не визначена
// (так налаштовують теми/бібліотеки)
$primary: #2563eb !default;

// область видимості: змінна в блоці локальна;
// !global робить її глобальною
.box {
  $local: 10px;
  padding: $local;
}
