1. Навіщо Vercel AI SDK

Писати руками парсинг SSE, керування станом чату й перемикання провайдерів — рутина. Vercel AI SDK (пакет ai) дає єдиний API поверх різних провайдерів (Anthropic, OpenAI тощо) і готові React-хуки для чату зі стрімінгом. Особливо зручний у Next.js.

Головна ідея — абстракція над провайдером: логіка застосунку не залежить від того, чи це Claude, чи GPT. Змінити модель — це змінити один рядок. SDK активно розвивається, тож звіряйся з офіційною документацією щодо точних сигнатур.

2. Встановлення

npm install ai @ai-sdk/anthropic
# .env: ANTHROPIC_API_KEY=sk-ant-...

3. Разова генерація: generateText

Модель обираємо через провайдер-функцію. generateText повертає повний текст: 

import { generateText } from 'ai';
import { anthropic } from '@ai-sdk/anthropic';

const { text } = await generateText({
  model: anthropic('claude-opus-4-8'),
  prompt: 'Поясни, що таке замикання в JS, коротко.',
});
console.log(text);

4. Стрімінг: streamText

У серверному ендпоінті (напр. Route Handler у Next.js) streamText одразу віддає потік, який зручно повернути у відповідь: 

// app/api/chat/route.ts (Next.js App Router)
import { streamText } from 'ai';
import { anthropic } from '@ai-sdk/anthropic';

export async function POST(req) {
  const { messages } = await req.json();

  const result = streamText({
    model: anthropic('claude-opus-4-8'),
    system: 'Ти — асистент курсу. Відповідай українською.',
    messages,
  });

  return result.toDataStreamResponse(); // готовий SSE-відповідь для useChat
}

5. Чат на клієнті: useChat

Хук useChat бере на себе весь стан: історію повідомлень, поле вводу, сабміт і стрімінг відповіді. Ти лише малюєш UI. 

'use client';
import { useChat } from '@ai-sdk/react';

export default function Chat() {
  const { messages, input, handleInputChange, handleSubmit } = useChat();

  return (
    <div>
      {messages.map((m) => (
        <p key={m.id}><b>{m.role}:</b> {m.content}</p>
      ))}
      <form onSubmit={handleSubmit}>
        <input value={input} onChange={handleInputChange} placeholder="Запитай..." />
        <button>Надіслати</button>
      </form>
    </div>
  );
}

Порівняй із ручним SSE-парсингом з уроку про стрімінг — тут його немає взагалі. useChat сам стрімить токени в messages, тож відповідь зʼявляється по частинах без жодного коду з твого боку.

6. Інструменти та інше

SDK підтримує й tool calling (через параметр tools зі схемами, часто на Zod), структурований вивід (generateObject), а також роботу з іншими провайдерами через їхні пакети (@ai-sdk/openai тощо) — той самий код застосунку, інша модель.
