Проєкт: галерея зображень із лайтбоксом

Рівень: середній. Етап: після CSS Grid, DOM, подій. Тренує сітку, модальні вікна й делегування.

Що зробити

Адаптивна сітка мініатюр; клік по зображенню відкриває його на весь екран (лайтбокс) з навігацією «попереднє / наступне».

Вимоги

  • адаптивна сітка (grid-template-columns: repeat(auto-fit, minmax(...)));
  • лайтбокс — модальне вікно з затемненим тлом;
  • перемикання зображень стрілками й клавіатурою (←/→, Esc);
  • делегування кліків по мініатюрах;
  • плавні переходи (transition).
const grid = document.querySelector('.gallery');
const lightbox = document.querySelector('.lightbox');
let currentIndex = 0;

grid.addEventListener('click', (e) => {
  const img = e.target.closest('img');
  if (!img) return;
  currentIndex = Number(img.dataset.index);
  openLightbox(currentIndex);
});

document.addEventListener('keydown', (e) => {
  if (e.key === 'Escape') closeLightbox();
  if (e.key === 'ArrowRight') showNext();
  if (e.key === 'ArrowLeft') showPrev();
});
