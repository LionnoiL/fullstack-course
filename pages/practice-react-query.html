Практика: TanStack Query

Створи React-проєкт (Vite), встанови @tanstack/react-query і обгорни застосунок у QueryClientProvider. Як API візьми JSONPlaceholder (/todos, /posts). Постав і Devtools — стеж за станом кешу.

Завдання 1. Список через useQuery

Загорни застосунок у QueryClientProvider, тоді хуком useQuery завантаж /todos (задай queryKey і queryFn) і виведи список. Обовʼязково обробі стани isPending (показати «завантаження…») та isError (показати помилку) — не звертайся до data, поки він не готовий.

Рішення 
const { data, isPending, isError } = useQuery({
  queryKey: ['todos'],
  queryFn: () =>
    fetch('https://jsonplaceholder.typicode.com/todos?_limit=10')
      .then((r) => r.json()),
});

if (isPending) return <p>Завантаження…</p>;
if (isError) return <p>Помилка</p>;
return <ul>{data.map((t) => <li key={t.id}>{t.title}</li>)}</ul>;

Завдання 2. Деталі за параметром

Зроби компонент, що приймає id і завантажує один запис. Переконайся, що id входить у queryKey і зміна id перезавантажує дані.

Підказка

Ключ виду ['todo', id]; при потребі використай enabled: !!id.

Завдання 3. Мутація + інвалідація

Додай форму створення запису через useMutation. Після успіху інвалідуй ключ списку, щоб він оновився. Блокуй кнопку під час isPending.

Рішення 
const queryClient = useQueryClient();
const mutation = useMutation({
  mutationFn: (title) =>
    fetch('https://jsonplaceholder.typicode.com/todos', {
      method: 'POST',
      body: JSON.stringify({ title }),
    }).then((r) => r.json()),
  onSuccess: () => queryClient.invalidateQueries({ queryKey: ['todos'] }),
});

Завдання 4. Пагінація (виклик)

Додай кнопки «Назад/Далі» зі станом page, вклади page у ключ і застосуй placeholderData: keepPreviousData, щоб список не блимав при перемиканні сторінок.
