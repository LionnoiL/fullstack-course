1. Навігація в SPA

React будує односторінкові застосунки (SPA): сторінка не перезавантажується, змінюється лише вміст. Щоб різним URL відповідали різні екрани, використовують роутер. Стандарт де-факто — бібліотека React Router. 

npm install react-router-dom

2. Базове налаштування

import { BrowserRouter, Routes, Route } from 'react-router-dom';

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
        <Route path="*" element={<NotFound />} />
      </Routes>
    </BrowserRouter>
  );
}

3. Посилання через Link

Для переходів використовують Link замість <a> — так сторінка не перезавантажується. 

import { Link } from 'react-router-dom';

function Nav() {
  return (
    <nav>
      <Link to="/">Головна</Link>
      <Link to="/about">Про нас</Link>
    </nav>
  );
}

4. Динамічні параметри URL

Частину шляху позначають через :param і читають хуком useParams. 

<Route path="/user/:id" element={<User />} />;

import { useParams } from 'react-router-dom';

function User() {
  const { id } = useParams();
  return <p>Профіль користувача {id}</p>;
}

5. Програмна навігація

Хук useNavigate дозволяє перейти на іншу сторінку з коду — наприклад, після успішного входу. 

import { useNavigate } from 'react-router-dom';

function LoginForm() {
  const navigate = useNavigate();

  function handleLogin() {
    // ...авторизація...
    navigate('/dashboard');
  }
}

React Router спирається на history.pushState з BOM: URL змінюється, а браузер не робить повний перезапит сторінки. Це та сама технологія, що й у розділі про об'єктну модель браузера.
