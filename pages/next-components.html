1. Серверні компоненти

В App Router компоненти за замовчуванням серверні. Вони виконуються лише на сервері: їхній JavaScript не потрапляє в браузер, а результат приходить як готовий HTML. Це зменшує обсяг коду й прискорює завантаження.

// серверний компонент (за замовчуванням)
// може напряму звертатися до БД чи файлів
export default async function Page() {
  const posts = await db.post.findMany(); // прямо на сервері!
  return (
    <ul>
      {posts.map((p) => <li key={p.id}>{p.title}</li>)}
    </ul>
  );
}

2. Клієнтські компоненти

Коли потрібні інтерактивність, стан або хуки (useState, useEffect) чи події браузера — компонент має бути клієнтським. Його позначають директивою 'use client' на початку файлу.

'use client';

import { useState } from 'react';

export default function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}

Хуки стану, обробники подій та браузерні API (window, localStorage) працюють лише в клієнтських компонентах. Забутий 'use client' — найчастіша помилка при переході на App Router.

3. Що коли використовувати

  • Серверні — отримання даних, доступ до БД/секретів, статичний вміст;
  • Клієнтські — інтерактивність, стан, події, хуки, браузерні API.

4. Композиція

Серверний компонент може вкладати клієнтський. Гарний підхід — тримати інтерактивні «острівці» клієнтськими, а решту лишати серверною.

// серверна сторінка, що використовує клієнтський Counter
import Counter from './Counter';

export default async function Page() {
  const data = await getData();
  return (
    <div>
      <h1>{data.title}</h1>
      <Counter /> {/* інтерактивний острівець */}
    </div>
  );
}
