1. Що таке SVG

SVG (Scalable Vector Graphics) — це формат векторної графіки, описаний XML-розміткою. На відміну від растрових зображень (JPEG, PNG), SVG складається не з пікселів, а з фігур, заданих математично, тому масштабується без втрати якості й лишається чітким на будь-якому екрані, зокрема Retina.

SVG найкращий для іконок, логотипів, простих ілюстрацій, графіків і діаграм. Растр — для фотографій.

Оскільки SVG — це текст (розмітка), він мало важить для простих зображень, його можна редагувати руками чи кодом, стилізувати через CSS і анімувати.

2. Способи вставки

<!-- 1. Inline: розмітка прямо в HTML (можна стилізувати з CSS/JS) -->
<svg width="24" height="24" viewBox="0 0 24 24">
  <circle cx="12" cy="12" r="10" />
</svg>

<!-- 2. Як звичайне зображення -->
<img src="logo.svg" alt="Логотип" width="120">

<!-- 3. Як фон у CSS -->
<div class="icon"></div>
.icon {
  background: url("icon.svg") no-repeat center;
  width: 24px;
  height: 24px;
}

Inline дає повний контроль (стилі, анімація, зміна з JS), але роздуває HTML. <img> і CSS-фон простіші й кешуються, але не дають керувати внутрішніми елементами SVG.

3. Система координат і viewBox

Атрибут viewBox="minX minY width height" задає внутрішню систему координат. Фігури малюються в цих координатах, а SVG розтягується до реального розміру (width/height або CSS). Саме завдяки viewBox графіка масштабується. 

<svg viewBox="0 0 100 100" width="200" height="200">
  <!-- координати 0..100, але на екрані 200×200 px -->
  <rect x="10" y="10" width="80" height="80" />
</svg>

4. Базові фігури

<svg viewBox="0 0 200 100">
  <rect x="10" y="10" width="60" height="40" rx="6" />
  <circle cx="120" cy="30" r="25" />
  <ellipse cx="170" cy="30" rx="25" ry="15" />
  <line x1="10" y1="70" x2="190" y2="70" />
  <polyline points="10,90 50,80 90,95" />
  <polygon points="120,70 150,95 130,95" />
  <text x="10" y="55">Текст</text>
</svg>

Найгнучкіший елемент — <path> з атрибутом d: ним описують довільні криві й лінії. Складні шляхи зазвичай не пишуть руками, а експортують із Figma чи Illustrator. 

<path d="M4 12 L12 4 L20 12" fill="none" stroke="black" />

5. Стилізація

Колір заливки — fill, обведення — stroke і stroke-width. Їх задають як атрибути або через CSS. Спеціальне значення currentColor змушує SVG успадкувати колір тексту — базовий прийом для іконок. 

<svg viewBox="0 0 24 24" class="star">
  <path d="M12 2 l3 7 h7 l-5 5 2 8 -7-5 -7 5 2-8 -5-5 h7 z" />
</svg>
.star {
  width: 24px;
  height: 24px;
  fill: currentColor;   /* колір як у тексту поруч */
}
.star:hover {
  fill: gold;
}

6. SVG-спрайти

SVG-спрайт — це один файл (або один inline-блок), що містить багато іконок, кожну в елементі <symbol> з унікальним id. Замість десятків окремих файлів і запитів ви підключаєте спрайт один раз, а потрібну іконку вставляєте через <use>.

Навіщо: менше HTTP-запитів, одне кешування, кожну іконку можна стилізувати через CSS (зокрема currentColor), і не дублювати розмітку.

6.1. Inline-спрайт

Прихований <svg> зі <symbol> кладуть на початку <body>, а далі посилаються на іконки за id. Зверни увагу: viewBox задають на <symbol>. 

<!-- визначення спрайта (сховане) -->
<svg xmlns="http://www.w3.org/2000/svg" style="display: none">
  <symbol id="icon-home" viewBox="0 0 24 24">
    <path d="M3 12 L12 3 L21 12 M6 10 V20 H18 V10" fill="none" stroke="currentColor" />
  </symbol>
  <symbol id="icon-user" viewBox="0 0 24 24">
    <circle cx="12" cy="8" r="4" />
    <path d="M4 20 c0-5 16-5 16 0" />
  </symbol>
</svg>

<!-- використання будь-де на сторінці -->
<svg class="icon"><use href="#icon-home"></use></svg>
<svg class="icon"><use href="#icon-user"></use></svg>
.icon {
  width: 24px;
  height: 24px;
  fill: currentColor;   /* іконка переймає колір тексту */
}

6.2. Зовнішній файл спрайта

Спрайт зручно винести в окремий файл sprite.svg (кешується й не роздуває HTML) та посилатися на іконку через фрагмент #id. 

<svg class="icon"><use href="sprite.svg#icon-home"></use></svg>

Зовнішній спрайт із фрагментом працює в сучасних браузерах. Дуже старі (IE) потребували поліфіла (svg4everybody). Також файл має віддаватися з того самого джерела (CORS). Атрибут xlink:href застарів — використовуй href.

Такі спрайти й набори іконок зручно генерувати в IcoMoon — він збирає обрані іконки у спрайт або іконковий шрифт.

7. Оптимізація та доступність

  • проганяй SVG через SVGO (або SVGOMG) — прибирає зайві метадані й зменшує розмір;
  • для змістовних іконок додавай role="img" і <title> усередині SVG;
  • декоративні іконки ховай від читачів екрана: aria-hidden="true".
<svg class="icon" role="img" aria-labelledby="t1">
  <title id="t1">Головна</title>
  <use href="#icon-home"></use>
</svg>

8. Анімація та SVG у React

SVG можна анімувати звичайним CSS (напр. обертати спінер через @keyframes) або JS-бібліотеками (GSAP). У React inline-SVG — це просто JSX: атрибути пишуться в camelCase (strokeWidth, viewBox), а сам SVG зручно винести в окремий компонент-іконку. 

function IconHome(props) {
  return (
    <svg viewBox="0 0 24 24" width="24" height="24" {...props}>
      <path d="M3 12 L12 3 L21 12" fill="none" stroke="currentColor" />
    </svg>
  );
}
